# 0.5（unknown 边缘化）设计选项——待用户拍板后写入协议 v2

> 0.5 是方案 A 的 go/no-go。协议 v1 说"未注释区当作 unknown"，但没有说清**哪些**未注释区是 unknown。
> 如果把整个未注释基因组都当作 unknown，就没有负样本可学了。
> 所以必须事先固定 unknown 的定义，它决定了这个实验到底在检验什么。

## 共同部分（与 U 的定义无关，已按 0.4 结果确定）

- **骨干**：GENERanno-1.2b-cds，冻结，取第 23 层（0.4 中 lnc 外显子的最佳层）。
- **特征缓存**：从 hg38 chr1–19 中抽取约 2,000 个 24 kb 窗口（一半以 v41 lnc 基因为中心，一半随机），把第 23 层特征以 fp16 一次性缓存下来，约 33 GB。之后所有臂、所有 seed 都在缓存上训练小头，GPU 成本只付一次（A10G 约 20–30 分钟）。
- **小头**：与 coding 项目 M28 的头同量级，约 0.4M 参数（BiGRU + 卷积），输出逐碱基的 lnc 外显子 / lnc 内含子 / mRNA 外显子 / 背景，各臂结构相同。seed 取 {42, 123, 456}。
- **数据划分**：
  - 训练标签只用 GENCODE v41。
  - 内部验证用 chr18，标签同样是 v41，用于选 checkpoint 和阈值，每个臂用同一套程序。
  - chr20 每个臂只评一次。
- **解码**（最小版）：逐碱基 lnc 外显子后验 → 内部验证上选定阈值 → 连续片段 → 按 L1 计分。语法解码留给后续方法本身，不放进 0.5。
- **终点**（与协议 v1 相同）：
  - 主终点：chr20 上 Δ 集合（v50 中新增的 473 个 lncRNA 基因）的 L1 Sn。
  - 成立判据：U − F ≥ +5 个百分点，且配对 bootstrap 95% CI 不含 0。
  - 同时要求：U 在 v50 下的严格 Pr，相比 F 下降不超过 5 个百分点。

## U 的三种定义（请选一个作为主臂，另一个可作副臂）

| 选项 | unknown 区域 | 优点 | 缺点 / 风险 |
|---|---|---|---|
| **U-ev（推荐主臂）** | v41 未注释、但有**公开转录证据**的区域：<br>• 主证据：v41 发布之前就公开的 RNA-seq 剪接点（recount3 / Snaptron 汇总的人类剪接点；只保留在多个样本中出现、且不落在 v41 任何基因内的剪接点及其两侧外显子片段）<br>• 可选补充：v41 之前的 FANTOM5 CAGE TSS | 与 coding 项目 M30 的机制一致（M30 用证据定义 unknown，召回 +14–17 个百分点）；只用 v41 之前的证据，**时间上一致**，不会偷看未来；推理时仍然只用序列 | 需要下载和处理剪接点数据（几 GB，CPU 处理）；证据本身也不完整；GENCODE 扩充 lncRNA 时也用过 RNA-seq 和长读，即便时间一致，也要在论文里说明"证据会部分预示未来注释" |
| **U-pu** | 所有未注释区都当作"未标注"，用 nnPU（非负 positive-unlabeled 学习）训练；类先验 π 用注释增长率估计（v41 只覆盖 v50 的 49%） | 不需要任何额外数据，可以直接用于任何物种（对跨谱系最友好）；实现简单 | π 估计误差会直接影响结果；PU 在极度不平衡的数据上容易不稳定；与 M30 的机制不同，复用度低 |
| U-mix | U-ev 区域边缘化，其余未注释区按 PU 处理 | 理论上最完整 | 两个变量混在一起，0.5 作为最小验证不宜采用；建议留到方法阶段 |

## 我的建议

- **主臂选 U-ev（时间一致的剪接点证据）**，副臂选 U-pu，对照臂是 F（未注释区当背景）。共 3 臂 × 3 seed。
- gate 只按主臂判定，副臂作为补充报告。
- **为什么不选 PU 做主臂**：它检验的是"未标注里藏着正例"这种统计假设，信号可能被 π 的设定淹没。U-ev 检验的是更具体、更可证伪的问题：**有转录证据却没被注释的区域，不应被当作负样本**。这也是论文里最好讲清楚的一点。

## 成本估计

- **数据**：Snaptron 剪接点下载与处理，CPU，在 ont 上约 1–2 小时。
- **特征缓存**：A10G 约 0.5 小时（约 0.6 美元），或 ont 空闲时跑（免费）；smoke 先走 Kaggle。
- **小头训练**：9 次（3 臂 × 3 seed），基于缓存，每次约 10–20 分钟，单卡总计约 2–3 小时（约 3 美元）。
- **合计**：Modal 约 4 美元以内，不使用 Baobab。
