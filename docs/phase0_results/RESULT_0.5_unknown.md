- **特征**：GENERanno-1.2b-cds 第 23 层，PCA 降到 512 维（方差保留率 0.879）。在 Modal A10G 上提取。
  - 提取完成后 workspace 即被停用（额度用尽），特征下载到 ont。
- **小头**：3 臂 × 3 seed，在 ont 的 4090 上运行，等 GPU 空闲后才开始，共 57 分钟，零花费。
  - 代码：`train_05_core.py`（Modal 与 ont 共用）、`train_05_local.py`、`run_p05_ont.sh`
- **数据**：
  - unknown（U-ev）：Snaptron srav3h（recount3，2021 年发布），按预注册条件过滤。训练窗口中 10.6% 的 token 落在 unknown 区；以 chr1 为例，未注释区里有 32% 是 unknown。
  - U-pu 的类先验 π = 0.279。
- **打分**：`score_05.py`（预注册终点）、`explore_05_auprc.py`（事后探索）。
- **输出**：Baobab `outputs/PHASE0/0.5_unknown/`，含 `SUMMARY_0.5.json` 和 `EXPLORATORY_auprc.json`。

## 必须同时报告的局限：终点在这个设定下饱和了

- 最小化解码（单阈值 + 连续片段）在 chr20 上产生了约 2.4 万个片段：位点 Sn 约 0.8，而严格 Pr 只有约 0.14。
- 这样一来，L1 Sn 在所有臂上都接近天花板，对"未注释区如何处理"不敏感。
- 因此 0.5 的阴性结论是"**在这个最小设定下没有达到预注册幅度**"，而不是"unknown 处理无效"。

## 探索性分析（事后进行，不参与 gate）：不依赖阈值的排序质量

在 chr20 的 6 bp token 上，用保存的逐 token 后验计算 AUPRC：

| 臂 | Δ 外显子 vs 基因间区（先验 0.021） | 全部 v50 lnc 外显子（先验 0.026） |
|---|---|---|
| F | 0.122 ± 0.005 | 0.146 |
| U-ev | 0.132 ± 0.007（3 个 seed 全部为正，平均 +0.011） | 0.150（+0.003，2/3 为正） |
| U-pu | 0.135 ± 0.004（3 个 seed 全部为正，平均 +0.013） | 0.151（+0.005，2/3 为正） |

解读：
- 两种 unknown 处理都**稳定地**提高了对新增 lncRNA 外显子的排序，相对提升约 9–11%，但幅度小。
- 真正的瓶颈仍然是逐碱基信号弱：AUPRC 0.12–0.15，与 0.4 的结论一致。

## 对方案 A 的含义（供讨论）

1. "部分标签 / unknown 边缘化"**不宜作为方法的头号卖点**。它带来的是一致但小的增益，更适合作为方法的一个组件，加上一节消融分析。
2. coding 项目 M30 的大效应（+14–17 个百分点），是在完整基因语法约束下取得的；本实验是逐碱基、无结构的。unknown 处理的价值很可能要在结构化解码中才能充分体现（路径级边缘化），这一点需要在方法阶段重新检验，而不是在 Phase 0 下结论。
3. 结合 0.1a、0.3 与 0.4：
   - 领域现状是端到端 lncRNA 结构召回接近 0（GENATATOR 3.5% 位点 / < 1% 转录本）。
   - 逐碱基 lnc 信号弱，但并非没有：最佳骨干在冻结特征上的 AUPRC 约为先验的 2.4–6 倍。
   - 所以方案 A 的核心应当是**结构化的基因语法解码（编码 ⊗ lncRNA）+ 合适的骨干与训练**，把弱信号整合成完整的基因模型，并在 precision 可控的前提下给出明显不为 0 的结构召回。unknown 处理作为其中一个组件。
