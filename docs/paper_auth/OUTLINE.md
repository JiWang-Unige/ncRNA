## 0. 标题与一句话

- **标题（推荐）**：*Improved locus-level detection does not translate into improved transcript-end pairing with unlinked RNA-end evidence*
- 备选：*Detecting transcription is not defining transcription units: limits of unlinked RNA-end evidence for lncRNA annotation*
- **一句话**：用分开测得的 CAGE 起点和 3′ 端证据，模型能可靠地筛出有转录的候选区域；但同一个模型在「哪个起点和哪个终点属于同一条分子」上不比取最强终点更好，反而显著更差。

## 1. 故事线

| 部分 | 内容 |
|---|---|
| 问题 | lncRNA 注释依赖昂贵的长读长；很多样本只有便宜的端点证据。端点证据能把转录单位确定到什么程度？ |
| 关键区分 | 「区域检出」（这片有转录吗）和「分子配对」（这对起点、终点是不是同一条分子的两端）是两个不同的评价目标 |
| 发现 1 | 区域检出可学：模型远超规则和强基线（Fig. 1） |
| 发现 2 | 分子配对不随之改善：取最强终点就与所有学习方法打平，为区域训练的模型更差（Fig. 2） |
| 发现 3（核心） | 两种口径的「对」大量不重合；为区域优化的模型配对显著变差，而区域命中在同一批候选上并未显著提高（Fig. 3） |
| 外推 | 区域筛选能迁移到另一个细胞系，配对结论尚未跨细胞系验证（Fig. 4） |
| 意义 | 注释基准要分清评价粒度；廉价证据适合做区域筛选和排序，确定转录单位需要分子级两端连接 |

**主次**：AUTH 是铺垫，E1 + G11 是核心发现，v1 是有限外推。W24（DNA 模型）移到补充材料，在讨论里用一句话作旁证。

## 4. 各部分写法

- **摘要**：
  - 生物学意义 → 两个评价目标的区分 → 「Here we show…」→ 区域增益、配对无增益、同候选反转 → 意义（基准设计、证据分工）。
  - 不以「We developed AUTH」开头；AUTH 是检验假设的工具，不是产品。
- **引言**：
  - lncRNA 注释的三类证据（序列、短读长 / 端点、长读长）；
  - 已知「分开测的两端不能唯一决定结构」（TIF-seq / TIF-Seq2），以及 Bookend、FANTOM CAT、SQANTI3、Bambu、LRGASP；
  - 缺口：区域层面的进步常被当作结构重建能力的代理，两者在同一套数据上是否一致，没有直接检验。
  - 每段和 ChatGPT 逐段核实；文献在 PubMed 核实后才进 bib。
- **结果**：四节，对应四张图。小标题陈述发现。术语统一用 supported / unsupported / observed，不用 true / false。
- **讨论**：
  - 能做什么：区域筛选与排序，以及在只有端点证据的样本上的用法；
  - 对基准设计的启示：评价粒度要与训练目标一致；
  - 局限集中一段：E1 只有一个细胞系、长读长真值偏向高丰度、PacBio cDNA 5′ 端偏短、测试染色体多次使用、真值部分依赖 GENCODE（约 22% 是全新基因）；
  - 展望写方向，不承诺。
- **Methods**：数据、真值、候选、特征、模型、规则、评估、E1 标签、事后分析的范围（一句话 + Table S1）。
