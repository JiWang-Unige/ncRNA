## 3. 结论

1. **迁移成立**：在 WTC11 上学好、冻结的模型，换了细胞系（iPSC → ESC）、换了起点证据的来源（LRGASP ssCAGE → FANTOM5 CAGE，相隔约 9 年的培养），原样用到 H1，仍明显胜过只用证据的规则（T1）和最好的简单规则（T2）。
2. **幅度变小，但相对改善相近**：
   - H1 上精度提高 +0.177，WTC11 上是 +0.306；
   - 但 H1 的基线低得多（R0-DPI 只有 0.149），按倍数算，H1 是 2.2 倍（0.327 / 0.149），WTC11 是 2.1 倍（0.575 / 0.268）。
3. **学到的东西主要是共通的**：在 H1 上就地重新学习并不更好（S2）。最强的特征是跨度内的 QuantSeq 位点、终点信号和编码覆盖，在两个细胞系里含义相同。
4. **仍然不能替代长读长**：
   - H1 上模型的预测 59% 是「不确定」，严格精度只有 0.134；
   - 召回 0.33，也没有和 H1 的长读长组装比（计划决定不跑）。
   - 在 WTC11 上，rep1 IsoQuant 在召回和两种精度上都明显更好（`RESULT_AUTH.md`）。

## 4. 解释边界

- 两个都是多能干细胞，只说明相近细胞类型之间能迁移。GM12878 的 3′ 端数据不够，没能检验远的细胞类型。
- H1 的真值重复浅（0.67 M、1.34 M 读段），精度绝对值偏低，不能和 WTC11 的数字直接比；门槛比的是 H1 内部的相对差。
- FANTOM5 建 DPI 峰时用过 H1 样本，H1 的起点检测略占便宜，对模型和对照同样有利。
- 选 H1、DPI 峰和归一化方式，都是看过 H1 训练染色体后定的（`PLAN_V1.md` 第 2 节）。H1 测试集上的证据、候选和预测都在冻结后的这一次运行里才生成。
- P1 在 H1 上召回略有提高（CI 下限 0.003），在 AUTH 的 WTC11 测试里没有。这是只报告的次要项，不作结论。
