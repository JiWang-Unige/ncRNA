> 来源：`PLAN_AUTH.md` 第 6 节（G1、G2 通过 → v1）；`FEASIBILITY_V1.md`（只查元数据）；`CHECK_V1.md`（GM12878 / H1 描述性检查）。作者 2026-11-24「写 v1 计划」。

> 范围：只用 ont CPU，不用 GPU，不再下载（数据已在 ont `data/v1/`），不装新包。

## 1. 问题

AUTH 在 WTC11 上得到：只用廉价端点证据（CAGE 起点 + QuantSeq 终点）和简单基因组上下文，模型能把「错」挑出来，精度（剔除不确定）比 R0 高 0.306，比最佳规则高 0.188（`RESULT_AUTH.md`）。但这只是一个细胞系，起点证据还是 LRGASP 专门测的 ssCAGE。

**v1 要回答**：在 WTC11 上学好、冻结的模型，原样用到另一个细胞系（H1），证据来自另一套来源（FANTOM5 的 CAGE），还能不能胜过只用证据的规则？

这是「学到的东西能不能搬」，不是「在 H1 上能不能重新学会」。后者作为次要分析一并报告（第 5.5 节）。

## 2. 已经知道的（`CHECK_V1.md`，只看了训练染色体）

- **GM12878 不能用**：QuantSeq 只覆盖 17–30% 的真值终点，候选上限只有 0.20。
- **H1 可以用**：终点覆盖 0.685（WTC11 0.664），候选上限 K20 0.521（WTC11-DPI 0.486）。
- **起点证据要统一成同一种峰**：FANTOM5 只给单碱基起点计数（CTSS），峰要用 FANTOM5 的 DPI 峰集。WTC11 改用 DPI 峰后：
  - 起点覆盖从 0.610 降到 0.437；
  - 「峰宽」「主峰占比」「内部 CAGE 峰数」的区分力明显改变；
  - R0 召回从 0.372 降到 0.267、精度从 0.224 升到 0.330。
  所以 AUTH 冻结的模型（LRGASP 峰）不能直接搬，要在 WTC11 上用 DPI 峰重新开发。
- **H1 与 WTC11-DPI 很像**：单个特征区分「真 / 错」的 AUC 几乎一致。按第 5.2 节归一化后，18 个特征的平均值差都在 0.17 个标准差以内；不归一化时，「支持样本数」差 2.0 个，「CAGE 读段」差 0.6 个。
- **H1 的真值浅**：两个长读长重复只有 0.67 M 和 1.34 M 全长读段（WTC11 1.71 M 和 3.09 M）。训练染色体全部候选单位的「真 + 错」里，「错」占 69%（WTC11-DPI 44%）。所以 H1 的精度绝对值会偏低，门槛只比较 H1 内部的相对差。

**已经看过的东西**（写明，避免事后解释）：
- 检查看过 H1 训练染色体上的证据覆盖、候选上限、单特征 AUC 和 R0，以及上面的特征偏移；
- 看过 H1 测试、次要染色体上的真值个数（149 和 106）；
- 选 H1、选 DPI 峰、选归一化方式，都是在看过这些之后定的。
- H1 测试和次要染色体上的证据、候选、预测都还没生成过。之后 H1 训练染色体不再用于任何选择，只在冻结后的次要分析里用（第 5.5 节）。

## 5. 方法

### 5.1 证据（两个细胞系同一种定义）

- **起点**：每个 DPI 峰内，按样本累加 CTSS 读段；合计 ≥ 2 的峰算一个起点；起点位置取峰内合计读段最多的碱基（并列取最左）。与 `v1_check.py` 的 `dpi_clusters` 相同。
- **终点**：QuantSeq 位点，≥ 2/3 重复支持（两个细胞系都是 3 个重复）。
- **候选、标签、去重、编码过滤**：全部照搬 AUTH（`auth_lib`）：每个起点配下游同链 50 kb 内最近 20 个终点；标签分真 / 不确定 / 错；贪心去重；去掉与 v41 编码基因同链重叠的单位。

### 5.2 特征（AUTH 的 18 个，只改 3 个的量纲）

| 特征 | AUTH | v1 |
|---|---|---|
| 起点 CAGE 读段 | log(1 + 读段) | log(1 + CPM)，CPM = 读段 ÷ 该细胞系全部 CAGE 读段 × 10⁶ |
| 支持样本数 | 有读段的样本数（0–6） | 有读段的样本比例（0–1） |
| 500 bp 内反义读段 | log(1 + 读段) | log(1 + CPM) |
| 其余 15 个 | — | 不变 |

- 峰宽、主峰占比保留。在 DPI 峰下它们几乎不带信号，但两个细胞系的含义一致，交给正则化处理。
- QuantSeq 信号和支持重复数不改：两个细胞系的 QuantSeq 来自同一实验室同一流程，未归一化时的差别已经只有 0.08 和 0.03 个标准差。

### 5.3 模型与 q（同 AUTH 第 5.3 节修订后）

1. L2 逻辑回归，「真 vs 错」，「不确定」不参与训练；特征按 WTC11 训练行标准化，**H1 用同一组均值和标准差**。
2. 每个起点取得分最高的配对，按得分贪心去重，做 v41 编码过滤。
3. 保留每条染色体得分最高的前 q 比例。q 在 WTC11-DPI 训练染色体 LOCO 上选：召回 ≥ R0-DPI 的训练召回，同时精度（剔除不确定）最高。
4. 最终模型用 WTC11 全部 14 条训练染色体拟合，**系数、标准化参数和 q 一起冻结**，原样用到 H1。

另训「真 vs 其余」版本，只报告。

### 5.4 对照（与模型用同一套 DPI 证据、候选、真值、去重和编码过滤）

| 名称 | 内容 |
|---|---|
| **R0-DPI** | ev_farthest：最近 3 个终点里取最远的，按 CAGE 读段贪心；**主对照** |
| R1–R6 | 同 AUTH 第 5.4 节；R2、R6 的 q 在 WTC11-DPI 上按「召回 ≥ R0-DPI 训练召回 − 0.02」选，冻结后原样用到 H1 |
| 最佳规则 | R1–R6 中，WTC11-DPI 训练 LOCO 上满足上述召回约束且精度最高的一个；G2 型门槛的对照 |
| P1 | 只用模型分数选终点，其余同 R0-DPI；只报告 |

不跑长读长参照：H1 rep2 只有 0.25 M 读段，拿它跑 IsoQuant / StringTie 对长读长不公平，也不是本问题要回答的。

### 5.5 次要分析（冻结后与测试同一次运行，只报告，不判门槛）

- **S1 WTC11-DPI 测试**：冻结模型用到 WTC11 测试染色体（DPI 证据），与 AUTH 的测试结果并排。这几条染色体 AUTH 已读过一次，所以只作对照。
- **S2 H1 重新学习**：用同一流程在 H1 训练染色体上拟合并选 q，用到 H1 测试集。看「搬过去」比「就地学」差多少。
- **S3 校准**：冻结模型在 H1 上的概率分 10 箱，与实际「真」的比例（真 + 错中）对照。预计截距偏移，因为 H1 的「错」比例高。

## 9. 风险与解释边界

- **两个都是多能干细胞**（iPSC 与 ESC）。通过也只能说明在相近细胞类型之间能迁移，不能推到远的细胞类型。GM12878 本可以检验这一点，但它的 3′ 端数据不够。
- **起点证据不同批**：H1 的 CAGE 是 FANTOM5 约 2012 年的培养，QuantSeq 和 PacBio 是 LRGASP 约 2021 年的培养。这是现实使用场景（公开 CAGE + 新测的数据），也是额外的噪声来源。
- **DPI 峰集含 H1 样本**：FANTOM5 建峰时用了 H1，所以 H1 的起点检测略占便宜。这对模型和对照同样有利，不影响相对比较，但会抬高 H1 的召回。
- **H1 真值浅**：「错」里有更多没被测到的真实转录本，精度绝对值偏低。门槛只比相对差，不与 WTC11 的绝对数比。
- **检验力**：255 个真值时，精度差的 CI 约 ±0.07；只用 149 个约 ±0.09。AUTH 在 WTC11 上的增益是 +0.306；如果 H1 的增益只有一半左右，仍有较大把握通过 T1。
- **事后选择**：选 H1、DPI 峰和归一化都是看过 H1 训练染色体之后定的（第 2 节）。H1 测试集上的证据和预测在冻结前不生成。
