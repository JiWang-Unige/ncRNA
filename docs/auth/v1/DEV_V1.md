## 4. 模型变了什么

区分「真 / 错」的 AUC（候选单位，LOCO）：模型 0.877，只用 CAGE（CPM）0.718。AUTH 分别是 0.935 和 0.552。

标准化系数（「真 vs 错」），与 AUTH 并排：

| 特征 | v1（DPI） | AUTH |
|---|---|---|
| 跨度：内部 QuantSeq 位点数 | +0.985 | +1.366 |
| 跨度：v41 编码同链覆盖 | −0.973 | −1.121 |
| 起点：CAGE（v1 为 CPM） | +0.916 | +1.169 |
| 终点：QuantSeq 信号 | +0.861 | +0.967 |
| 终点：距离排名 | +0.705 | +0.639 |
| 起点：CpG 岛 | +0.332 | +0.065 |
| 跨度：长度 | −0.259 | −0.274 |
| 起点：±500 bp GC | −0.241 | −0.089 |
| 跨度：内部同链 CAGE 峰数 | +0.165 | +0.523 |
| 起点：主峰占比 | −0.164 | −0.429 |
| 起点：峰宽 | **−0.084** | **−1.358** |
| 其余 7 个 | 绝对值 ≤ 0.10 | 绝对值 ≤ 0.16 |

- 与 `CHECK_V1.md` 的预期一致：峰宽几乎失效，内部 CAGE 峰数、主峰占比减弱。
- QuantSeq 类和编码覆盖仍是主力，而它们在 H1 上的区分力与 WTC11-DPI 相同（检查时看过的单特征 AUC）。
- 起点 CpG 岛和 GC 的分量变大，部分替代了峰形状的信息。

## 5. 冻结前要知道的风险

- **召回容差**：模型 q 让 LOCO 召回刚好不低于 R0-DPI（差 +0.001）。训练集上召回差的置信区间约 ±0.025（842 个真值）。H1 测试集有 255 个真值，按真值数粗略换算，标准差约 0.024。即使两者召回实际相同，也约有 1/9 的机会仅因抽样使召回差低于 −0.03，导致 T1、T2 不过。这与 AUTH 冻结前的情况相同，计划没有为此再留余量。
- **H1 的「错」更多**：截距会偏，但门槛只比较排序后的相对差，概率校准作为 S3 报告。
- 其余见 `PLAN_V1.md` 第 9 节。
