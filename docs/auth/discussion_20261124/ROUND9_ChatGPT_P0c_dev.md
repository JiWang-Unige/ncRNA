## 结论：同意在冻结前停止 IDENT 主线

**决定性的是**：CEGIS 依赖的全局组合识别机制在真实数据上没有起作用。5 个阳性事件、只有 6 条定量增益都不是关键。

**它更正和补充的**（我核过，都成立）：
1. **软剪切比例写错了**：rep1 删掉约 70%（chr16 70.3%、chr22 72.0%），V 约 34%；我误把 V 的 34% 写成 chr16 rep1 的。「放宽只增加读段、不改变结构性事实」说过头了：它可能改变链长、嵌套比例和出现概率。已更正。
2. **嵌套只解释了一部分**：58.6% 是嵌套链，可以被长链替换；但 449 条非嵌套链同样没有简约增益。措辞已改。
3. **检查 1 实际比报告说的更弱**：「永远预测不出现」的 Brier 为 0.002227。Q1 为 0.002285（比它差 2.6%），Q2 几乎与它相同。AUC 的实现没有处理并列值。结论改为「没有建立有用的预测能力」。
4. **检查 1 的实现偏差**：
   - 长读段子路径代价相同，求解器不一定选最短的观测，0.22% 可能被低估；
   - 截短分布没有分层；
   - 每条链各自抽样，不是位点共用一批分子；
   - 只记录一个充分方案；
   - 按位点 10% 的预算不是全局优化预算。
5. **小实现错误**：V 索引缺染色体；A 的位点映射键缺链方向。另外，完全图外的 A 分子没有进入抽样池，可能高估而不是低估收益。
6. **注释校正的 BAM**：影响方向不定。它可能压低真实歧义，也可能只是消除技术噪声；不构成已证实的跨分子泄漏。不必为此重做。
7. **449 个单观测诊断**：说明没有出现需要多观测联合排除反例的情况。还不能证明 CEGIS 与所有简单规则的预算收益严格相等，但从资源分配看已是很强的停止信号。

**挽救路线**（主观估计恢复核心创新的可能性）：

| 路线 | 可能性 | 建议 |
|---|---|---|
| 修最短观测选择、AUC、索引 | 5–10% | 归档修复 |
| 放宽软剪切 | 10–20% | 可作最后的敏感性分析 |
| CAGE、polyA 可信端点 | 15–25% | 不推荐继续主线 |

- CAGE 端点：峰不等于知道连到哪条链；没有端点证据不代表转录本不存在；强制要求端点会退回「候选空间收缩造成的唯一性」。Bookend、SQANTI3 早已使用这些证据。
- 如果作者一定要排除 CAGE 方向的疑问，最多做一个极小的探索：chr16、chr22，不排除开放候选，看多观测诊断是否在 ≥ 20 个、且占 ≥ 20% 的合格位点上重新出现。这只是探索，不能替换预定门槛。它首选现在就停。

**合并冲一区**：反对强行把 AUTH / E1 和 IDENT 合并，那样只会是一篇很长的阴性分析论文。
- 唯一有一定潜力的组合：分层评价框架。把区域转录检测、独立端点、端点配对、内部剪接链、完整转录本、功能这几层分开，核心发现是「方法排名会随评价粒度反转」（G11 是初步证据）。
- 冲一区至少还需要：SIRV 真值、独立细胞系或协议复现、与 IsoQuant / Bambu / StringTie / Bookend 比较，并证明常用指标确实导致有实际影响的方法选择错误。
