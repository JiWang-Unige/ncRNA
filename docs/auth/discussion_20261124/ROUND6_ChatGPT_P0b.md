# 与 ChatGPT 商议 P0b（2026-11-24，第 6 轮）

- 对话：同前。它读了提交 eb86875 的 RESULT_P0b.md、ident_core.py、p0b.py、DEFS_P0a.md 与 P0B.json（静态审查，没有重跑）。思考 43 秒。

## 结论：P0b 有条件通过；先做 P0b-fix，再进 P0c

**它接受的**：基础三态 MILP；CEGIS 全局充分观测的基本思路。600 个随机图规模足够，不需要更多同分布图。

**它指出的问题**（我逐条核过，都成立）：
1. **定义版本不一致**：仓库里的 DEFS_P0a.md 仍是 v0。核实：v1 只改了本地，没有提交（我的疏漏），代码领先于仓库中的定义。
2. **B1 不完全独立**：穷举与方法共用路径枚举、`produces()`、覆盖观测、ETA/BIGM、HiGHS。验证的是「MILP 与穷举在同一语义下一致」，不是语义本身正确。需要一个不 import ident_core 的独立 oracle。
3. **B2 不完整**：只检查支持集存在可行丰度，没有直接用返回的 x 算定量残差。
4. **B3 最优性复核调用了同一个 `min_cost_cover()`**；UNRESOLVED 没有单独计数。需要穷举观测子集或 bitmask 动态规划。
5. **B4 有实质性数学问题（最重要）**：信息受限判定丢掉了现有定量约束，并把最低丰度改为 1e-3，解空间与三态判定不同。反例：已知 x11 = 1、总量 4 时，补测端点边际就能确定 x22；丢掉 x11 = 1 后，(1,1;1,1) 与 (0,2;2,0) 端点边际相同，被错判为信息受限。B4 的复核也用 `use_quant=False`，所以复核了一个已被改变的问题。758 / 657 例只能看作简化模型下的结果。
6. **「采样受限」含义过强**：找不到等价解只说明原则上可区分，不说明现实深度可区分（0.0100 vs 0.0101）。改名为 QUANTITATIVELY_DISTINGUISHABLE，或估计所需样本量。
7. **全长分子与读段对没有真正建模**：全长分子被拆成 sub + link，可由不同转录本分别满足；读段对被当成两个独立子路径。需要 `("full", s, nodes, t)` 与 `("paired", m1, m2, 片段范围)`。
8. 其他：`certificate_source` 超时可能误判；`min_cost_cover` 不区分失败与不可行；`_polish` 空支持集不查定量；oracle 不枚举空集；路径枚举无上限；协议按节点数而非碱基长度；通用丰度上下界尚未实现。

**P0b-fix 清单**（F1–F8）：独立语义 oracle；直接验证返回丰度；独立覆盖最优 oracle；保留定量约束的信息受限判定；三种协议状态独立复核；full / paired 联合观测；超时与空解状态；提交更新后的定义。另加 20–30 个对抗性构造案例。

**P0c 设计要点**：
- 不接受「建议的观测在验证分子中出现后歧义消除」作主检验：CEGIS 已保证这一点，是自证循环。真正要检验的是在不知道新增分子时，能否提前选到更有价值的证据。
- 按分子划分：发现集 D 20%（建图、诊断）、增量集 A 40%（模拟追加）、验证集 V 40%（评价）；也可用独立 PacBio 重复作验证集。
- 防泄漏：不用全深度建图、不从全深度 GTF 取端点、不挑验证集高支持目标、不事后挑读段、不随新增证据改 K、不删超时位点。
- 对照 R0–R6：随机、按丰度、按分支数、单反例最短区分（检验 CEGIS 是否必要）、最大分支间距、最易获得的区分观测、直接全长支持；R7 为 IDENT 全局充分集 + 可获得性预测。
- **最小观测代价 ≠ 最低测序预算**：要估计每种观测的出现概率 q_o，P(获得) = 1 − (1 − q_o)^n。
- 门槛：≥ 100 个歧义位点；≥ 80% 算完；≥ 20% 有不依赖全长分子的充分方案；同等新增分子预算（主分析 10%，另报 5%、25%）下，独立验证的新增结构比最强基线多 ≥ 20%，按位点或区块配对 bootstrap，95% CI 下限 > 0；不以错误结构或依赖简约换取确定性。
- 停止条件：CEGIS 与单反例规则收益相同；收益可被出现概率或复杂度简单复现；有效诊断大多是要全长读段；新增必然主要来自简约；模型内歧义消除而独立支持不改善；只有事后 oracle 策略有效。

**录用概率（Bioinformatics，主观）**：只完成现有功能约 20%；P0b-fix + P0c 通过约 35%；再加 SIRV 与独立协议验证约 50%；再证明可实施的证据预算优势约 60%。工程风险下降，创新性没有变化。

## 我的看法

- 八条都核实成立。第 5 条（信息受限判定改变了解空间）是真错误：我在定义里写了「不受现有定量约束的尺度影响」，本意是避免尺度问题，但做法是直接丢掉定量约束，这会把能由新增证据解决的问题错判为测不出。应在原可行域内找两个解，比较归一化后的 τ 观测。
- 第 7 条也重要：真实数据里全长分子和读段对是最主要的证据，必须先建模才能进 P0c。
- 我同意「P0b 零失败只是工具可用，不是科研阳性」；也同意 P0c 的主要效应要用「提前选证据」来定义，并加入观测可获得性。
- 工作量：P0b-fix 约 1–2 天（全在 ont CPU 上，不下载）；P0c 设计需要先写计划交作者批准。
