# 与 ChatGPT 商议 IDENT 计划（2026-11-24，第 4 轮）

- 对话：同前（「ncRNA项目评估」）。它读了提交 78bc469 的 `docs/ident/PLAN_IDENT.md`，并检索了文献。
- 问题：一区分量与新意、定义漏洞、门槛、期刊与录用概率、有无更好的方向。

## 结论：反对按原计划直接开工，但强烈支持「可识别性」这个方向

**原计划的新意已被覆盖大半**（我已在 Europe PMC 逐一核实下面几篇都存在）：
- *On the identifiability of the isoform deconvolution problem*（Bioinformatics 2022，PMID 34978563）：已从短读长出发判断结构是否可识别，直接比较了编码基因与 lncRNA，并给出建库片段长度建议（编码 400–600 nt，lncRNA 150–200 nt）。所以「首次量化 lncRNA 与编码基因的可识别性差距并指导测序设计」不能再说。
- *Identifiability of isoform deconvolution from junction arrays and RNA-Seq*（Bioinformatics 2009，PMID 19762346）。
- IsoTools（Bioinformatics 2023，PMID 37267159；2.0 版在 J Mol Biol 2025）：已经有长读长发现饱和分析和所需深度的预测，覆盖了原计划的累积曲线部分。
- 安全路径：Safe&Comp、Improving RNA Assembly via Safety and Completeness（J Comput Biol 2022，PMID 36288562）、SafeMFD（Bioinformatics 2023）；以及 Scallop / Scallop2、Bookend、preseq、LRGASP。
- 它对各版本的一区潜力打分（主观）：原计划 4–5/10；改造后 8/10。

**定义上的漏洞**
1. **循环性**：参考结构集来自全深度长读长。目录越不完整，越多结构会被误判为「唯一」，这对 lncRNA 尤其不利。改为三套评价：
   - T1：SIRV 绝对真值；
   - T2：独立平台目录；
   - T3：只用输入证据构建的剪接图，作为主实验。
   并且做「留一平台」：用一个平台建图，用另一个平台评价。
2. **「唯一相容路径」不等于可识别**：所有剪接点都被观察到，完整转录本仍可能不确定。应分三态：
   - 必然存在：出现在所有可行解里；
   - 可能存在：只出现在部分可行解里；
   - 不相容：不出现在任何可行解里。
   并给出丰度的上下界。
3. **「≥ 2 条全长读段」不是可识别性的定义**。要分开报告「直接支持」「证据约束」「外部验证」三种指标。
4. **端点聚类会改变结论**：起点、终点分别定义；避免链式合并；做 10–200 bp 的敏感性分析；单外显子转录本单独评价。
5. **SIRV 确实存在**：LRGASP 用了 Lexogen 5′ 加帽 SIRV-Set 4。还要核实下载的 BAM 是否保留了 SIRV 序列。
6. **lncRNA 与编码基因的比较严重混杂**：表达量、外显子数、长度、异构体数都不同。要逐层控制，不要预设 lncRNA 一定更难识别。

**门槛**
- P1 的「10%–80% 且相差 ≥ 10 个百分点」选的是一个希望看到的表型差异，而不是有研究价值的结果，应废除。
- 改为四关：
  - 新意：精读文献后写出数学定义；
  - 正确性：在 100–1,000 个人工小剪接图上和穷举比对，无噪声时错误证书必须为 0；
  - 生物学有效性：SIRV 和多异构体位点上的风险–覆盖率曲线；
  - 实用优势：同等精度下覆盖率比最强基线高 ≥ 10 个百分点，或提供现有方法给不出的歧义诊断。
- 外推：要和 preseq、IsoTools、饱和曲线比较，误差至少比最强基线低 20%。
- 拒答解码器：0.85 精度对「只输出能确定的」工具太弱，应在 1%、5%、10% 错误率下比较覆盖率。

**它建议的方向**（A 为主体，B 为应用，C 有余力再做）
- **A. 证据约束下的转录本识别与「歧义证书」**：
  - 对每个结构给出状态：必然、可能或不相容；
  - 定不下来的，给出一个同样能解释当前数据的替代结构（反例）；
  - 指出缺的是哪类证据：跨分支读段、跨多个剪接事件的读段、分子级两端连接，还是更多分子。
  - 新意在于给出拒答的结构性理由和可核查的反例，而不只是拒答。
- **B. 信息驱动的测序设计**：哪类新增读段最能消除歧义。要区分事后挑选的 oracle 上界，和只凭浅测序就能实施的策略。
- **C. 跨协议的 lncRNA 可观测性与注释偏差**。
- **AUTH / E1**：作为动机与先导实验，或独立成短文；不强制作为新文章的第一部分。

**它会批准的第一步**：只做低成本的 Phase 0，暂不下载 75 GB。
- 精读 2022 年那篇、SafeMFD、Bookend、IsoTools，写出数学定义；
- 人工小剪接图上的正确性检验；
- 用已有的 PacBio 数据和 SIRV 做生物学有效性检验。

## 我的看法

- 文献核查我同意，几篇关键文献都真实存在。原计划确实会撞上 2022 年那篇和 IsoTools，这是我写计划时漏查的。
- 方向 A 有真正的方法学内核（必然 / 可能 / 不相容三态、反例、证据增量诊断），比「做一个更大的基准」更像一区方法论文。它也自然解释了 E1：分开测的两端，在给定剪接图下产生的配对歧义可以给出反例。
- 风险：算法难度明显增加（可行解空间可能指数爆炸，需要 ILP 或流分解）；和安全路径一系文献的差异要讲清楚。Phase 0 的正确性和新意两关就是为此设的。
- 建议：重写计划为「方向 A + B 应用」，Phase 0 不下载新数据（人工图 + 已在 ont 上的 WTC11 PacBio；SIRV 是否保留在 BAM 中先核实）。
