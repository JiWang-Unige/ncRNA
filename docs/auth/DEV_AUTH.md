| 跨度：重复序列比例（软屏蔽） | −0.059 | +0.037 |

**解读**
- 最强的信号是「跨度内有没有转录活动」：跨度内 QuantSeq 位点多、同链 ssCAGE 峰多、终点信号强，都更像「真」。「错」的定义是与任何已观察转录本都不重叠，所以模型主要学的是：这段跨度本身有没有廉价证据显示在转录。
- 起点方面，读段多而峰窄更像「真」；宽而弱的峰更像「错」。
- 终点质量（A 含量、PAS 六聚体）和双向转录（反义读段）权重都很小。这与 R3、R4 规则表现不好一致。
- 这些特征都来自 ssCAGE / QuantSeq / 基因组 / v41 编码注释，没有用长读长、lncRNA 注释或序列模型。

## 8. 冻结时补上的实现细节（第 5、6 节没写死的部分）

| 项目 | 做法 |
|---|---|
| q 的用法 | 每条染色体内，在贪心去重、v41 掩码之后，保留得分最高的前 ⌈q × N⌉ 个单位。LOCO 每折是一条染色体，测试时也按染色体分别取 |
| 选终点 | 每个起点在 20 个候选里取模型分最高的；分数相同取最近的 |
| 贪心 | 与 `e3_anchor._greedy` 相同：按分（或读段）从高到低稳定排序，同链不重叠才接受；与 v41 编码基因同链重叠的单位删掉，且不占位 |
| 模型拟合 | 只用「真」与「错」配对（「不确定」不参与），包括之后会被编码掩码删掉的配对；每次拟合在拟合行上标准化；`simple_det.fit_logit`，C = 1.0 |
| R1 | W24 的 `pair`：最近的一个 QuantSeq 位点（K = 1） |
| R3 | 在 R0 的 3 个候选终点里，去掉下游 20 nt A 含量 > 0.6 或上游 10–35 nt 没有 AATAAA/ATTAAA 的终点，再取最远者；一个都不剩的起点不出单位 |
| R4 | 反义读段 = 起点 ±500 bp 内所有反链 ssCAGE 簇（不设读段下限）的合计读段；≥ 本起点读段的一半就去掉 |
| R5 | 起点 ±500 bp：GC ≥ 0.5 且 CpG o/e ≥ 0.6 |
| R6 | R3 的终点 + R4 的起点 + 按读段保留前 q |
| 「最佳规则」 | R1–R6 中 LOCO 召回 ≥ 0.3517 且精度（剔除不确定）最高者：**R2**（只有它合格） |
| P1 | 模型选的终点；按 ssCAGE 读段贪心；v41 掩码；不用 q |
| 配对标签「真」 | 与任一真值 lnc 位点跨度 reciprocal ≥ 0.5（同链） |
| 区块 | 每条染色体从 1 开始切 1 Mb 区块（长度取自序列）；真值位点和预测都按起点坐标归入区块；所有测试染色体的区块合在一起重抽样；各方法用同一组重抽样；CI 取 2.5% 与 97.5% 分位 |
| 门槛中的召回差 | 用点估计判定 ≥ −0.03（第 6 节没有要求召回差的 CI） |
| 长读长参照 | rep1 StringTie -L / IsoQuant de novo（同 `dev_longread.sh`，参考序列用 `outputs/AUTH/seq/<chr>.fa`），基因跨度 ≥ 200 bp，v41 同链掩码 |
| 次要集并排 | W24 真值（排除区 + chr12/13 的切点），Tiberius 与 v41 掩码各一份，旁边列出 W24 `RESULT.json` 的 ev_farthest / ours / pair / IsoQuant / StringTie；另外再按 AUTH 真值（184 个，不用排除区）算一份 v41 |
| 三类数量 | 全部配对；模型在掩码和 q 之前、掩码之后、最终；每个方法的最终预测 |
