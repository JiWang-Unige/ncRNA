## 1. 问题

M1 第 2–4 周（`RESULT_M1_W24.md`）在 WTC11 上得到：
- 只用证据的规则 ev_farthest（ssCAGE 起点 + 下游 50 kb 内最近 3 个 QuantSeq 位点中最远的一个）：S50 召回 0.436，与整套 rep1 长读长的 IsoQuant（0.430）相当；
- 但精度（剔除不确定）只有 0.220，IsoQuant 是 0.645；严格精度 0.048 对 0.176；
- 我们的序列先验过滤删掉了 37% 的预测，几乎全是「不确定」，精度只升到 0.225。

ev_farthest 的 1,495 个预测由三类组成（四条测试染色体合计，按冻结口径）：
- **真**（S50 匹配真值）约 72 个；
- **不确定**（没匹配真值，但与 rep2/rep3 某条转录本同链重叠）约 1,168 个；
- **错**（与 rep2/rep3 任何转录本都不重叠）约 255 个。

**本计划要回答**：只用证据本身和简单的基因组上下文，不用任何序列模型，能否学会：
1. 把「错」挑出来（提高剔除不确定的精度）；
2. 给每个起点选对终点（提高召回）；
并且做得比几条简单规则好。

**为什么不是旧路线的变体**：M1 用 DNA 模型「生成」或「过滤」单位，失败了。这里不用任何 DNA 模型；标签来自独立的长读长重复，不来自参考目录。

## 2. 先做的两项描述性检查（只用 CPU，不设门槛）

这两项是归档文档（`DECISION_ARCHIVE_20261121.md` 第 7 条）里「没做完的两项分析」。用的是 W24 已经读过的四条测试染色体（chr9/12/13/20），只做描述，**不影响第 6 节的门槛**。

**C-1：「不确定」到底是什么**
- 对象：ev_farthest 的约 1,168 个「不确定」，以及序列过滤删掉的约 544 个。
- 分成四类（按所重叠的 rep2/rep3 转录本，TALON 的 gene/transcript 注释）：
  - U-a：与真值 lnc 重叠但 S50 没过（端点错或一对一匹配被占）；另报是起点错（TSS 偏 > 1 kb）、终点错，还是两端都错；
  - U-b：与编码基因（V29 protein_coding）的转录本重叠，即 Tiberius 过滤漏掉的编码；
  - U-c：与没进真值的 lnc / 新转录本重叠（只在一个重复出现、ISM、Genomic 以外的类别）；
  - U-d：其他 biotype（假基因、snoRNA 宿主等）。
- 用途：U-a 多，说明「选对终点」那一半值得做；U-b 多，说明编码过滤不够；U-c 多，说明真值标准偏严。

**C-2：IsoQuant 漏掉、证据规则找到的 31 个真值位点**
- 对每个位点报告：rep1 在真值跨度内的读段数（`samtools view -c`）；IsoQuant 在该处有没有输出（有但没过 S50，还是完全没有）；rep2/rep3 的 TPM；长度、外显子数、起点是否在 CpG 岛。
- 用途：判断这 18.8% 是 rep1 深度不够，还是 IsoQuant 过滤掉的。

**产出**：`RESULT_AUTH_C.md`。预计半天，CPU。

## 5. 方法

### 5.1 候选

- 证据处理与 W24 冻结版相同（`w24_lib.evidence`）：ssCAGE 峰合计读段 ≥ 2，起点取峰内读段最多的碱基；QuantSeq 取 ≥ 2/3 重复支持的位点。
- **配对候选**：每个起点与下游同链 50 kb 内的所有 QuantSeq 位点（最多最近 20 个）各组成一个候选单位。
- 每个配对的标签（只用于训练与描述）：
  - 真：与某个真值 lnc 跨度 reciprocal overlap ≥ 0.5；
  - 不确定：不是真，但与 rep2/rep3 某条转录本同链重叠（Genomic 除外）；
  - 错：两者都不是。

### 5.2 特征（不用任何长读长、不用 lncRNA 注释、不用序列模型）

| 组 | 特征 |
|---|---|
| 起点 | ssCAGE 合计读段、支持样本数、峰宽与主峰占比；500 bp 内反义链 ssCAGE 读段（双向转录，PROMPT / eRNA 样）；是否在 CpG 岛（M1 实验 2 的规则：±500 bp GC ≥ 0.5 且 o/e ≥ 0.6）；±500 bp GC |
| 终点 | QuantSeq 支持重复数与信号（`w24_lib.quant_signal`）；下游 20 nt 基因组 A 含量（内部引物假象，SQANTI3 用 > 60%）；上游 10–35 nt 是否有 AATAAA / ATTAAA；在候选终点中的距离排名 |
| 跨度 | 长度；跨度内同链 ssCAGE 峰数与 QuantSeq 位点数（被跳过的）；与 v41 编码基因的同链 / 反义重叠比例；重复序列比例（软屏蔽） |

### 5.3 模型与流程

1. **配对打分**：L2 逻辑回归（numpy / scipy 实现，与 M1 实验 2 的 `fit_logit` 同法），目标「真 vs 错」，「不确定」不参与训练。
2. **选终点**：每个起点取得分最高的配对。
3. **去重**：按得分从高到低，接受同链互不重叠的单位，去掉与 v41 编码基因同链重叠的（与 W24 的贪心规则相同，只是排序依据从 ssCAGE 读段数换成模型得分）。
4. **阈值**：保留得分最高的前 q 比例。q 在训练集 LOCO 上选：在召回不低于 ev_farthest 训练集召回 − 0.02 的前提下，使精度（剔除不确定）最高。
5. 最终模型用全部训练染色体拟合，q 不变，在测试集上运行一次。

另训一个「真 vs 其余」的版本（目标是严格精度），只报告，不判门槛。

### 5.4 对照（同一套候选、真值、去重与编码过滤）

| 名称 | 内容 |
|---|---|
| **R0 ev_farthest** | W24 冻结规则，编码过滤换成 v41；**主对照** |
| R1 nearest | 取最近的 QuantSeq 位点（W24 的 pair） |
| R2 CAGE 阈值 | 按 ssCAGE 读段数保留前 q（训练集选 q） |
| R3 终点质量 | 去掉下游 A 含量 > 60% 的终点，要求有 PAS 六聚体，然后再取最远者 |
| R4 去双向 | 去掉 500 bp 内反义 ssCAGE 读段 ≥ 本链一半的起点 |
| R5 CpG 起点 | 只保留起点在 CpG 岛的单位（M1 的强零基线） |
| R6 规则组合 | R2 + R3 + R4 |
| IsoQuant / StringTie | rep1 长读长，不给注释，同样做编码过滤；只作参照 |

R1–R6 中，在训练集 LOCO 上同一召回约束下精度最高的，记为「最佳规则」，作为门槛 G2 的对照。

## 9. 风险与已有工作

- **SQANTI3**（Nature Methods 2024）已经用 CAGE、polyA 位点和 ML 过滤转录本；**Bambu** 用 NDR 控制新转录本发现率；**LAPA** 处理 3′ 端；**TIF-Seq2**（NAR 2020）直接测同一分子的两端，能在实验上解决配对问题。
  - 本计划可能的新意只在于：对**分开测得、没有分子级连接**的廉价端点证据，用独立长读长重复作标签，评估能否判别真伪。不能声称解决了物理配对。
  - SQANTI3 和 Bambu 需要完整的转录本模型（含剪接），不能直接用在我们的跨度候选上，所以不作对照；结果文档里要写明这一点。
- **只有一个细胞系**：WTC11。即使通过，结论也只限 WTC11；跨细胞系需要另一套同时有 CAGE、3′ 端测序和长读长重复的数据（v1 再查）。
- **真值偏向稳定表达**：rep2 ∩ rep3 偏向表达较高的转录本；「错」类里会有真实但低表达的转录本。这一点对所有方法相同，但会压低精度的绝对值。
- **「不确定」口径**：分母去掉「不确定」后，删掉「不确定」不会改变精度；所以 G1/G2 衡量的是去掉「错」的能力。严格精度同时报告。
