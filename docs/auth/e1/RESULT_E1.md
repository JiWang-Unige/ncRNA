## 3. 结论

1. **现有廉价证据里的「配对信息」，基本就是「哪个终点最强」**：一条只看终点 QuantSeq 信号的简单规则，就能达到所有学习方法的水平。
2. **AUTH 模型学到的是区域可检出性，不是端点配对**：它在区域筛选上明显胜过规则（AUTH G1、G2，v1 T1、T2），但在同一起点内选终点时，显著差于只看终点强度的基线（−0.096）。这正是 ChatGPT 提出的担心，现在有了测试集上的直接证据。
3. **合起来的结论**：用分开测得的 CAGE 和 3′ 端证据，能可靠地判断「这片区域有没有转录」，但不能比「取最强终点」更好地确定转录单位的两端如何配对。这就是「检出转录 ≠ 界定转录单位」。

**按计划的下一步**：判为「停止」→ 不再沿配对方向优化模型；把 W24（DNA 先验无增益）、AUTH、v1、E1 连起来，重新评估是否写一篇短的分析类文章（等作者决定）。
