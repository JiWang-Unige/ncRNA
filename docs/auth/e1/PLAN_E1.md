# AUTH-E1 计划：模型学到的是「端点配对」，还是「区域可检出性」？（2026-11-24 作者批准）

> 来源：ChatGPT 审阅（`10_AUTH/discussion_20261124/ROUND1_ChatGPT_and_synthesis.md`）提出的唯一实验，作者 2026-11-24 要求写成计划。
> 范围：只用 WTC11 现有数据，ont CPU，不下载，不装新包，不用 GPU。
> 状态：**2026-11-24 作者按第 10 节建议批准**（「按照建议批准」）。冻结与测试读取另需作者确认。

## 1. 问题

AUTH 与 v1 证明：模型能把「没有长读长覆盖」的跨度去掉。但训练标签只分「真」（与真值位点 S50 匹配）和「错」（与任何已观察转录本都不重叠），97% 的候选是「不确定」，不参与训练。最强的特征（跨度内 QuantSeq 位点数、起点 CAGE 读段、终点信号）也正是长读长容易测到的区域特征。

所以要回答：**在同一个起点、同一片有转录的区域里，模型能不能选对与这个起点属于同一条分子的终点？**

- 能：模型里有配对信息，值得继续。
- 不能：区域筛选的能力没有转化为配对能力。这本身就是一个清楚的分析结论（「检出转录 ≠ 界定转录单位」）。

## 2. 真值：单条长读长分子的两端

- 来源：WTC11 PacBio rep1 比对文件 ENCFF373TKM（ont 上已有，带索引）。AUTH 只用它跑 IsoQuant / StringTie 参照，没有用它做标签。
- **先核对来源**（只看文件头和 ENCODE 元数据，不统计两端）：
  - 确认读段是全长非嵌合（FLNC）且经过 TranscriptClean，方向可靠；
  - 记录过滤条件（比对质量、是否去掉次要比对、补剪切）。
  - 核对不过（例如不是 FLNC），本计划停止，回到作者。
- **分子支持**：一条读段的 5′ 端在起点 ±100 bp 内、3′ 端在候选终点 ±100 bp 内，且同链，就算支持这对端点。至少 2 条读段支持，才算「已观察配对」。
- **竞争终点**：同一起点的其他候选终点，与该起点没有任何读段连接。只称「未观察配对」，不称「错误配对」，因为低丰度的真实异构体可能没测到。
- 注意：PacBio cDNA 的 5′ 端可能因降解而偏短。±100 bp 的窗口和「至少 2 条」的要求就是为了减少这种影响；±50 / ±200 bp 只作稳健性报告。

## 3. 入选的起点组（事先写定）

候选沿用 AUTH 的缓存：每个起点最近 20 个终点，长度 ≥ 200 bp，去掉与 v41 编码基因同链重叠的配对（与最终输出一致，避免编码捷径）。

一个起点组入选主分析，需要同时满足：
1. 至少 1 个候选终点有分子支持（≥ 2 条）；
2. 至少 1 个候选终点没有任何分子连接（有竞争）；
3. 起点 ±100 bp 内，同链 5′ 端的 rep1 读段 ≥ 10 条（局部覆盖够深）。

- **主分析**：所有满足条件的起点组，不限于 lnc 真值。原因是 lnc 表达低，只用 lnc 可能凑不够样本；而配对问题本身不分 lnc 与否。
- **次要分析**：起点组的已观察配对与 AUTH 真值 lnc 位点重叠的子集，只报告。

## 4. 比较的方法（都在同一个起点组、同一组候选终点上排序）

| 编号 | 方法 | 说明 |
|---|---|---|
| E0 | 距离规则 | 取最近 K 个里最远的一个；K ∈ {1, 2, 3, 5, 10, 20} 在训练染色体上选 |
| E1 | 几何 | 只用长度和终点距离排名，组内条件逻辑回归 |
| E2 | 信号与密度 | 终点 QuantSeq 信号和支持重复数、长度、跨度内 QuantSeq 位点数、跨度内 CAGE 峰数，组内条件逻辑回归 |
| **E3** | 冻结的 AUTH 模型 | 原样用 `outputs/AUTH/dev/MODEL.json` 的「真 vs 错」分数，不重新拟合 |
| **E4** | 组内排序模型 | AUTH 的 18 个特征，组内条件逻辑回归（同一起点内「已观察 vs 未观察」），只在训练染色体拟合 |

- 「最强基线」= E0、E1、E2 中训练染色体上 Top-1 最高的一个（留一染色体交叉验证），事先确定后不再改。
- E1、E2、E4 用同一个实现（组内 softmax 的 L2 逻辑回归，正则化强度 C = 1，与 AUTH 相同）。

## 5. 指标

- **主指标 Top-1**：组内排第一的终点有分子支持的比例。
- 次要指标：MRR（第一个有支持终点的倒数排名的平均）；排第一的终点与最近的有支持终点的距离；组内候选的有支持比例（随机基线）。
- 置信区间：1 Mb 区块自助 2,000 次（种子 0），方法之间配对。

## 6. 染色体、冻结与读取

- 开发：AUTH 的 14 条训练染色体。
- 测试：AUTH 的测试染色体 chr2、6、10、16、22。它们在 AUTH 里读过一次（S50 口径），所以 E1 的测试只能称为「预先冻结的新指标验证」，不是没见过的外部数据。E1 的标签（分子连接）在测试染色体上从没生成过。
- 流程：
  1. 核对 rep1 读段来源（第 2 节）。
  2. **可行性门槛（只看训练染色体）**：统计入选起点组数。AUTH 测试与训练的真值比例是 312 : 842，按此换算，测试组数预计约为训练组数的 0.37 倍。训练组数 < 162（换算后测试 < 60）就停止，判为「证据不足」，执行归档，不读测试。
  3. 训练染色体上开发 E0–E2、E4，选最强基线；写 `DEV_E1.md`。
  4. 冻结（代码、模型、选定的 K 和最强基线记 sha256），作者确认后读测试一次，写 `RESULT_E1.md`。

## 7. 判定（事先写定，读取后不改）

在测试集上，分别比较 E3、E4 与最强基线的 Top-1 差：

| 结果 | 条件 | 下一步 |
|---|---|---|
| **继续** | E3 或 E4 的差 ≥ +0.10，且 95% CI 下限 > 0 | 模型里有配对信息；再议是否沿配对方向做 |
| **停止，写分析结论** | E3 和 E4 的差，95% CI 上限都 < +0.05 | 区域筛选能力没有转化为配对能力；连同 W24、AUTH、v1 重新评估是否写短的分析类文章 |
| **证据不足** | 测试组 < 60，或不属于上面两种 | 归档（选项 A），不降低门槛、不换指标、不换模型 |

另报告（不判定）：
- 高覆盖分层（局部读段 ≥ 30）、跨度长度分层；±50 / ±200 bp 窗口。
- 同一批起点组上 AUTH 原来的 S50 精度增益，与配对增益并排，直接显示「区域」和「配对」的落差。

## 9. 风险

- **样本量**：lnc 表达低，入选组可能主要来自其他非编码转录，结论讲的是「配对能力」，不专属 lnc。
- **5′ 端偏短**：会让部分真实配对得不到支持，对所有方法相同，但会降低 Top-1 的绝对值。
- **rep1 也是 IsoQuant 的输入**：E1 不和 IsoQuant 比，不存在冲突。
- **多重比较**：E3、E4 两个方法对同一个基线，任一通过就算「继续」；这一点事先写明。
