# 分析小结：廉价端点证据拼出的转录单位，真伪能学，也能迁移（AUTH + v1，2026-11-24）

> 范围：AUTH（WTC11）与 v1（迁移到 H1）两项实验的合并小结。所有数字来自各自只读一次的测试集；细节和偏差见文末的文件索引。
> 用途：项目内部的分析记录。按 2026-11-21 的决定，不投稿。

## 一句话结论

只用 CAGE 起点和 QuantSeq 终点这两种廉价证据，再加简单的基因组上下文，一个逻辑回归就能把「落在没有转录的地方」的单位挑出来：
- 在 WTC11 上，精度（剔除不确定）从 0.182 升到 0.488；
- 同一个模型冻结后原样用到 H1，从 0.149 升到 0.327；
- 两处都明显胜过最好的简单规则，召回也不降。

但它**不能替代长读长**：多数预测仍是「不确定」，严格精度只有 0.13–0.16，WTC11 上 rep1 IsoQuant 在召回和两种精度上都更好。结论目前只限两个多能干细胞系。

## 1. 问题从哪来

- M1 第 2–4 周（W24）发现：只用证据的规则 ev_farthest（CAGE 起点 + 下游最近 3 个 QuantSeq 位点中最远的一个）召回与长读长 IsoQuant 相当，但精度很低。用 DNA 模型「生成」或「过滤」单位都没有带来改进，于是 2026-11-21 归档。
- 2026-11-23 三方讨论提出转向：不用 DNA 模型，直接问**廉价端点证据拼出的单位，真伪能不能学**。标签来自独立的长读长重复，不来自参考注释。

## 2. 设计要点

- **真值**：同一细胞系两个 PacBio 重复都观察到的 lnc 位点（W24 规则）。另有一个长读长重复留作 IsoQuant / StringTie 的输入。
- **三类预测**：
  - 真：与真值一对一匹配，S50，即两两重叠 ≥ 50%；
  - 不确定：没匹配真值，但与真值重复里某条转录本同链重叠；
  - 错：与任何已观察转录本都不重叠。
- **主指标**是「精度（剔除不确定）」= 真 ÷（真 + 错），也就是去掉「错」的能力；严格精度（真 ÷ 全部）一并报告。
- **候选**：每个 CAGE 起点配下游 50 kb 内最近 20 个 QuantSeq 位点，去掉与 GENCODE v41 编码基因同链重叠的单位。
- **模型**：18 个特征（起点、终点、跨度三组），L2 逻辑回归，目标「真 vs 错」。每个起点选得分最高的终点，贪心去重，保留前 q 比例；q 在训练染色体上留一染色体交叉验证（LOCO）选，要求召回不低于 ev_farthest。
- **对照**：R0 = ev_farthest（主对照）；R1–R6 六条简单规则，其中开发时最好的一条记为「最佳规则」，两次都是 R2（按 CAGE 读段数保留前 q）。
- **评估纪律**：
  - 染色体划分事先写定（训练 14 条，测试 chr2、6、10、16、22，次要 chr9、12、13、20）；
  - 门槛事先写定；代码和模型冻结（记 sha256）后，测试集只读一次；
  - 置信区间：1 Mb 区块自助 2,000 次，方法之间配对。

## 3. 结果

### 3.1 WTC11（AUTH，测试 312 个真值）

| 方法 | 召回 | 精度（剔除不确定） | 严格精度 | 预测数（真 / 不确定 / 错） |
|---|---|---|---|---|
| **模型** | 0.330 | **0.488** | 0.157 | 658（103 / 447 / 108） |
| R0 ev_farthest | 0.298 | 0.182 | 0.071 | 1,316（93 / 805 / 418） |
| R2（最佳规则） | 0.295 | 0.300 | 0.101 | 910（92 / 603 / 215） |
| rep1 IsoQuant（参照） | 0.401 | 0.749 | 0.236 | 530 |
| rep1 StringTie（参照） | 0.420 | 0.476 | 0.112 | 1,174 |

- G1（对 R0）：精度 +0.306 [0.247, 0.368]，召回 +0.032 → 通过。
- G2（对 R2）：精度 +0.188 [0.132, 0.248]，召回 +0.035 → 通过。
- 只用模型选终点（P1）对召回没有可靠贡献；强档（精度 ≥ 0.48 且召回 ≥ 0.40）没达到，因为召回只有 0.330。
- 模型把「错」从 418 个降到 108 个（−74%），「真」从 93 个增加到 103 个。

### 3.2 「不确定」和「漏掉」是什么（AUTH 描述性检查，W24 的 4 条染色体）

- ev_farthest 的 1,168 个「不确定」里：
  - 62%（719 个）是编码基因；
  - 322 个是没进真值的 lnc（只在一个重复出现，或新的单外显子）；
  - 只有 93 个（8%）是端点错了的真 lnc。
  所以「选对终点」的空间本来就小，与 P1 无贡献一致。
- IsoQuant 漏掉、证据规则找到的 31 个真值位点，rep1 同链读段中位数只有 2（IsoQuant 找到的位点是 13）。这是 rep1 测序深度的问题，不是证据规则更灵敏。

### 3.3 模型学到了什么

| 特征 | AUTH（LRGASP 峰） | v1（FANTOM5 DPI 峰） |
|---|---|---|
| 跨度内 QuantSeq 位点数 | +1.366 | +0.985 |
| 与编码基因同链重叠 | −1.121 | −0.973 |
| 起点 CAGE 读段 | +1.169 | +0.916（CPM） |
| 终点 QuantSeq 信号 | +0.967 | +0.861 |
| 终点距离排名 | +0.639 | +0.705 |
| 起点峰宽 | −1.358 | −0.084 |

数字是标准化系数。

- 主力是**这段跨度本身有没有转录活动**：跨度内有 QuantSeq 位点，起点读段多，终点信号强。
- 事先猜测的「内部引物终点」「双向转录起点」两类规则几乎没用：WTC11 测试集上 R3、R4 的精度是 0.186 和 0.206，R0 是 0.182。
- 起点峰形状（峰宽）在 AUTH 里很强，但它依赖峰的定义；换成 FANTOM5 的通用峰集后几乎失效，其余特征照样起作用。

### 3.4 跨细胞系：先查可行性

- **没有第二个细胞系像 WTC11 那样，三种证据来自同一批细胞**：LRGASP 只公开了 WTC11 的 CAGE。
- **能拼出来的里面，H1 可用，GM12878 不可用**：
  - H1：LRGASP 的 QuantSeq 和 PacBio，加 FANTOM5 的 CAGE；
  - GM12878：QuantSeq 只能覆盖 17–30% 的真值终点（全部位点都算上也只有 30%），候选上限 0.20。
- 起点覆盖下降主要来自峰的定义，不是细胞系：WTC11 自己换成 DPI 峰，起点覆盖就从 0.610 降到 0.437。
- 因此 v1 先在 WTC11 上改用 DPI 峰重新开发并冻结。特征里 CAGE 读段换成 CPM、样本数换成比例；归一化后，H1 与 WTC11-DPI 的特征分布差都在 0.17 个标准差以内。

### 3.5 迁移到 H1（v1，测试 255 个真值，9 条染色体）

| 方法 | 召回 | 精度（剔除不确定） | 严格精度 | 预测数（真 / 不确定 / 错） |
|---|---|---|---|---|
| **冻结的 WTC11 模型** | 0.329 | **0.327** | 0.134 | 627（84 / 370 / 173） |
| R0-DPI | 0.294 | 0.149 | 0.070 | 1,076（75 / 574 / 427） |
| R2（最佳规则） | 0.263 | 0.201 | 0.087 | 768（67 / 434 / 267） |

- T1（对 R0-DPI）：精度 +0.177 [0.139, 0.218]，召回 +0.035 → 通过。
- T2（对 R2）：精度 +0.126 [0.085, 0.168]，召回 +0.067 → 通过。
- 9 条染色体上模型的精度都最高；「错」从 427 个降到 173 个（约 −60%）。
- 同一冻结模型在 WTC11 测试染色体上（DPI 证据）：精度 0.575 对 R0-DPI 0.268（+0.306）。
- **绝对增益在 H1 上较小，相对改善相近**：H1 的精度是 R0-DPI 的 2.2 倍，WTC11 是 2.1 倍。H1 基线低，主要因为它的真值重复浅，被算作「错」的单位更多。
- 在 H1 上就地重新学习并不更好：精度只高 +0.026，区间跨 0；召回反而低 0.043。学到的东西主要是两个细胞系共通的。
- 模型概率在 H1 上整体偏高，但排序单调。门槛只用排序；要当概率用，需要重新校准。

## 4. 这能说明什么，不能说明什么

**能说明**
1. 对分开测得、没有分子级连接的两端证据，真伪可以从独立长读长重复的标签里学到，而且超出简单规则。
2. 学到的判别在相近细胞类型之间可以原样迁移：换了细胞系，也换了 CAGE 的来源和年代。
3. 起作用的是「跨度内有没有转录信号」和「是否与编码基因重叠」这类通用信息，不是某个数据集特有的峰形状。

**不能说明**
1. 不能替代长读长：
   - 模型的预测 59–68% 是「不确定」，严格精度 0.13–0.16；
   - 在 WTC11 上 rep1 IsoQuant 明显更好（召回 0.401、精度 0.749）；
   - H1 上没有做长读长对照。
2. 不能推到远的细胞类型：两个都是多能干细胞；GM12878 的数据不够检验。
3. 没有解决两端的物理配对：两端是分开测的，配对靠距离规则加打分。
4. 不能与 SQANTI3、Bambu 直接比：它们需要带剪接的完整转录本模型，这里的单位只是跨度。
5. 精度的绝对值依赖真值深度：真值重复越浅，「错」里混入的真实低表达转录本越多。所以两个细胞系的绝对数不能直接比。

## 5. 与已有工作的关系

- **SQANTI3**（Nature Methods 2024）用 CAGE、polyA 位点和机器学习过滤转录本；**Bambu** 用 NDR 控制新转录本的发现率。两者都作用在长读长组装出的完整转录本上。
- **LAPA** 处理 3′ 端；**TIF-Seq2**（NAR 2020）在实验上直接测同一分子的两端。
- 本工作可能的新意只在于：**没有长读长组装、只有分开测得的廉价两端证据时**，用独立长读长重复当标签，评估并学习真伪判别，并在第二个细胞系上冻结检验迁移。
