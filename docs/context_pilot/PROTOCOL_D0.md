# D0 协议：lncRNA 核 / 质定位的 gene × cell 交互信号审计（v1，2026-11-25，下载完成、计算之前冻结）

> 来源：`16_new_methods_20261124/20261125_ncRNA-new-models_SYNTHESIS.md` 第 4 节；作者 2026-11-25：「Run pilot」。
> 目的：只回答一件事——同一个 lncRNA 在不同细胞系间的核 / 质比变化（交互项 δ_{g,c}），是不是可重复、可预测的信号。不训练深度模型。过不了就永久关闭方向 D。
> 状态：作者 2026-11-25 批准「D0 + B0-lite」。本文件在任何标签或模型结果计算之前冻结（sha256 见 `PROTOCOL_D0.md.sha256`）。

## 数据（全部 ENCODE 公开，GRCh38，GENCODE V29 RSEM 基因定量）
- lncATLAS 网站 2026-11-25 维护中、无法下载，改用其原始来源：ENCODE Gingeras 实验室 polyA+ RNA-seq 核 / 胞质分级。
- 13 个细胞系，每个分级通常 2 个重复：A549、GM12878、H1（各 1 个重复）、HT1080、HeLa-S3、HepG2、IMR-90、K562、MCF-7、NCI-H460（胞质 1 个重复）、SK-MEL-5、SK-N-DZ、SK-N-SH。
- 只取 V29 注释的 gene quantifications：49 个文件，530 MB（清单 `data/context_pilot/encode/manifest.tsv`，md5 已核对，sha256 记在 `SHA256SUMS`）。
- 同一细胞系的 Lécuyer total RNA-seq（K562、HepG2，已在 ont）只作外部一致性检查，不进主分析。
- 细胞系协变量 z_c：全细胞表达近似 = 核与胞质 TPM 的平均（两重复平均，log2(TPM+1)），取 RBP 的表达。RBP 名单 = ENCODE 全部人类 eCLIP 实验的靶标（168 个，`data/context_pilot/eclip_rbps.txt`，2026-11-25 从 ENCODE API 取得）。z_c = 这些 RBP 表达在**训练细胞系内**拟合的 PCA 前 8 个主成分（留出细胞系只做投影）。
- 基因顺式特征 x_g：沿用 RNA_fate E1 的特征表（`data/rna_fate/e1_features.tsv.gz`，与细胞系无关：长度、外显子数、跨度、内含子、异构体数、CpG、到编码基因距离、单外显子，以及 GC、1–5-mer、U1 / PAS 基序、重复元件）。标准化后用 PCA 降到 20 维（无监督，在全部 lncRNA 上拟合，不用标签）。

## 标签与基因集
- CN-RCI_{g,c} = log2((胞质 TPM + 0.1) / (核 TPM + 0.1))，每个重复单独算，再取平均。
- 基因：GENCODE v41 lncRNA（与 V29 按无版本 gene_id 对齐），chr1–22、X；在某细胞系两分级平均 TPM ≥ 1 才计入该细胞系；至少在 6 个细胞系中合格的基因进入主分析。
- 阳性对照（不进门槛）：同样流程跑 protein_coding。

## 第一步：方差分解（信号是否存在）
- 两向模型 y_{g,c} = μ_g + α_c + δ_{g,c} + ε（缺失单元格用交替最小二乘估计主效应）。
- 重复噪声：有两个重复的细胞系，用重复间差的方差估计 ε 的方差（按表达量分层）。
- 报告：μ、α、δ、ε 各自的方差占比；δ 的方差是否显著大于 ε（按表达分层的重复噪声，置换检验）。

## 第二步：δ 能否预测（留一细胞系）
- 目标：留出细胞系 c 中每个基因的 δ̂_{g,c} = y_{g,c} − μ̂_g(训练细胞系) − α̂_c。α̂_c 用留出细胞系所有基因的中位数（只用该细胞系的 y，不用基因标签信息之外的东西）；另报 α_c 用协变量预测的版本。
- 模型（按复杂度）：
  - M0 零交互（预测 δ = 0）；
  - M1 最近细胞系迁移（最强简单基线）：用 z_c 欧氏距离最近的 3 个训练细胞系的 δ（距离倒数加权）作为预测；
  - M2 双线性 ridge：特征 = x_g（20 维）⊗ z_c（8 维）外积 160 维，ridge（α 在训练细胞系内部留一细胞系选择，候选 10^-2…10^4）；
  - M3 反应规范核：核岭回归，K = K_gene(RBF，带宽 = 中位数启发) ⊗ K_cell(线性)，正则同上。为控制计算量，每个留出折从训练对中随机抽 6,000 对（种子 0；核矩阵求解的内存与时间限制）。
- 超参数只在训练细胞系内部做嵌套交叉验证。
- 打乱对照：在细胞系之间打乱 z_c 后重跑 M2、M3。

## 门槛（冻结时写死，不在看结果后修改）
- **D-G1 信号存在**：
  - 重复噪声：只用两个分级都有 2 个重复的 11 个细胞系，噪声方差 σ²_ε(mean) = var(r1 − r2)/4（按基因表达五分位分层后加权）。
  - 真实交互方差 = var(δ̂) − σ²_ε(mean)；占比 = 真实交互方差 / var(y − μ̂_g)。
  - 通过条件：基因 bootstrap（2,000 次）下真实交互方差的 95% CI 下限 > 0，且占比 ≥ 20%。不过 → STOP。
- **D-G2 可预测**：M2 或 M3 在留一细胞系下，δ 的 Pearson r（13 个留出细胞系的中位数）≥ 0.30；并且交互 R²（1 − SSE/Σδ²，所有留出细胞系合并）比 M0（=0）和 M1 都高 ≥ 0.05。
- **D-G3 非假象**：打乱 z_c 后性能下降（配对置换 p < 0.01）；去掉任一单个细胞系后结论不变。
- 判定：
  - G1 + G2 + G3 全过 → GO，写 D 的立项计划；
  - G1 过、G2 / G3 不过 → 交互信号存在但当前协变量预测不了，只作描述性结果，D 不立项；
  - G1 不过 → STOP，方向 D 永久关闭，不换架构挽救。

## 已知局限（事先写明）
- 基因层面的定位变化可能来自异构体比例变化（Tani 2026，PMID 42645529）；本审计不分异构体，结论只适用于基因层面。
- 13 个细胞系来自不同组织和癌症状态，细胞系差异与批次混杂；不同年份测序批次无法完全分开。
- 两重复只够估计重复噪声的量级。
