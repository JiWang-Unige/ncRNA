## 一句话
**按冻结门槛：G0 不过，G2 + G3 通过 → 按协议可以申请 B0-full 补 G1。**但有两点必须一起看：
- G0 不过：处理后的 icSHAPE 数据里几乎没有 lncRNA（两区室共同观测的只有 16 个基因），所以这只能是一般 RNA 方法，不是 ncRNA 方法；

- 规模：868,285 个核苷酸、1,302 个基因；其中 lncRNA 只有 16 个基因、5,906 个核苷酸。

## 事后消融（不进门槛，2026-11-25）：增益从哪里来
同样 5 折、同样 HGB 设置，只换输入：

| 输入 | 染色质 → 核质 | 核质 → 胞质 | in vitro → in vivo |
|---|---|---|---|
| 只用参考（线性） | 0.377 | 0.426 | 0.488 |
| 参考 + 参考表达（非线性） | 0.378 | 0.439 | 0.490 |
| + 未配对概率 + GC | 0.452 | 0.465 | 0.500 |
| 全部（+ ±12 nt 序列 one-hot 等） | 0.517 | 0.537 | 0.628 |

- 增益**不是**来自参考值的非线性均值回归，也不是来自覆盖度：这两项几乎没贡献。
- 大部分来自**局部序列窗口**（+0.07 到 +0.13）。

## 为什么还不能当真（主持人判断）
处理后数据只有一份合并值，Δr = r_target − r_ref 里同时含两个区室的测量噪声。局部序列至少能用两条路「预测」Δr，而都和区室生物学无关：
1. **参考噪声的收缩**：序列能估计参考反应性「本来该是多少」，于是能识别出观测参考值里的噪声，而这部分噪声在 Δr 里以负号出现。
2. **化学与逆转录偏好的批次差异**：icSHAPE 的信号依赖碱基种类和局部序列（NAI 修饰、逆转录停顿偏好）。两个区室的文库若在这方面有系统差异，序列就能预测「技术性的」Δr。

只有用独立重复构造输入和标签（G1，B0-full）才能把这两种伪信号与真实的区室结构变化分开。in vitro → in vivo 的增益最大（+0.14），也和「技术差异」解释相容。

## 对方向 B 的含义
- 按冻结门槛，可以申请 B0-full：约 94 GB 原始数据，HEK293 核质与胞质的 in vivo 实验，再在 ont 上重处理 1–2 天，用重复检验 G1。
- 但即使 G1 通过，**这也是一般 RNA 的结构方法，不是 ncRNA 方法**：icSHAPE 对 lncRNA 的覆盖太低（人 16–20 个基因，小鼠 39 个）。若作者的目标仍是「研究 ncRNA 的新方法」，B 的价值会大打折扣。
