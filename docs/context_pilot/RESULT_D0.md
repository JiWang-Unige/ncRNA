## 数据规模
- 13 个细胞系（ENCODE Gingeras 核 / 胞质 polyA+，V29 定量），49 个文件。
- 主分析：1,243 个 lncRNA（至少 6 个细胞系合格），12,214 个 基因 × 细胞 观测，每个基因中位 10 个细胞系。
- 对照：12,102 个蛋白编码基因。

## G1：交互信号是否存在（通过）
| 量 | lncRNA | 蛋白编码（对照） |
|---|---|---|
| 基因主效应 μ_g 方差 | 2.81 | 1.58 |
| 细胞系主效应 α_c 方差 | 0.32 | 0.08 |
| 去掉 μ_g 后的方差 | 1.38 | 0.66 |
| 交互项 δ 的估计方差 | 1.06 | 0.58 |
| 重复噪声方差（两重复均值，11 个细胞系估计） | 0.46 | 0.20 |
| **扣除噪声后的真实交互方差** | **0.60**（95% CI 0.54–0.67） | 0.38（0.37–0.39） |
| 占去掉 μ_g 后方差的比例 | **44%**（门槛 ≥ 20%） | 57% |

同一 lncRNA 在不同细胞系间的定位变化，超出重复噪声。蛋白编码基因同样如此，所以这不是 lncRNA 特有的现象。

## G2：交互项能否预测（不通过）
留一细胞系，预测 δ（13 个留出细胞系）：

| 模型 | Pearson 中位数 | 交互 R²（合并） |
|---|---|---|
| M0 零交互 | 0 | 0 |
| M1 最近 3 个细胞系迁移 | 0.159 | −0.105 |
| M2 双线性 ridge（基因特征 × RBP 表达主成分） | 0.028 | −0.018 |
| M3 反应规范核 | 0.106 | −0.028 |

- 门槛：M2 或 M3 中位 r ≥ 0.30，且交互 R² 比 M0 / M1 高 ≥ 0.05。最好的 M3 只有 0.106，R² 为负 → **不通过**。G3 未进行。
- 各细胞系差别很大：H1 上 M1–M3 都有 0.35–0.42，其余多在 −0.2 到 0.2 之间。H1 只有 1 个重复，可能偶然。

## 解读
- 「同一个 lncRNA 在不同细胞里定位不同」是可测的真实现象，量级不小。但用细胞系的 RBP 表达加上基因的顺式特征，在 13 个细胞系上学不出可迁移的规律。
- 可能原因（未检验）：
  - 只有 13 个独立细胞系，自由度太少；
  - RBP 的 mRNA 表达不代表结合活性；
  - 基因层面的变化混有异构体比例变化（Tani 2026，PMID 42645529）；
  - ENCODE 2 不同细胞系的测序批次与细胞系混杂，「真实交互方差」里可能含批次效应（重复只能估计同批次噪声）。
- **按冻结协议，方向 D 不立项，不再换模型挽救。**交互信号的存在可以作为描述性发现写进其他工作。
