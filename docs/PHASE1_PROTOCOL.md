| # | 决定 | 推荐 | 备选 |
|---|---|---|---|
| D1 | **语法核心的实现** | **G1：Tiberius 式可微 HMM-CRF**。逐碱基状态，编码 / lnc / 基因间区三条通路的并集，正反链都建模，剪接 motif 门控转移；前向算法求 log Z、Viterbi 解码、前向–后向求后验，全部在 GPU 上精确计算。 | **G2：沿用 M28 的稀疏事件半马尔可夫**。用学到的 TSS / TES / 剪接头产生候选事件，再在候选格上精确求和。最接近 M28 代码，但召回受候选剪枝上限限制，并且依赖 CPU DP（M28 的 GPU 利用率只有 11%）。 |

关于 D1 的说明：coding 项目里**可以原样复用**的有：
- C0 / SharedContext 头（6-mer 特征 + DNA 卷积 → 逐碱基势）；
- M30 的"允许状态集"部分观测训练：log Z_observed − log Z；
- 基因后验、温度 τ 校准、只在内部验证上选阈值的流程（M29-A2 / M33）；

**不能原样复用**的是 M28 的事件格本身：它依赖 ATG / 终止子 / ORF 的稀疏性，而 lncRNA 没有这些约束。G1 把"语法"表达为带约束的状态转移，是同一思想的线性时间实现。

## 2. 模型

**骨干**：GENERanno-eukaryote-1.2b-cds-annotator-preview，冻结。
- 取第 17 和第 23 层的隐状态拼接（4,096 维；23 是 0.4 中 lnc 最佳层，17 提供较浅层特征），不做 PCA。
- 特征一次性缓存为 fp16，放在 ont 本地 NVMe：3,000 个训练窗口约 100 GB；chr18、chr20、T2T chr20 三条整染色体合计约 290 GB（ont 剩余约 2 TB）。
- LoRA 列为 Phase 2 的消融，Phase 1 不做。

**头**：C0 / SharedContext（从 coding 项目复制并注明出处；不 import 冻结代码）。
- 结构：Linear(4096→256) → BiGRU(256) → 上采样到碱基（×6）⊕ DNA 卷积 → 逐碱基状态势。
- 参数量约 1–2M。

**语法 G1（逐碱基，正反两条链，共 13 个状态）**：
- `IG`：基因间区（两链共享）
- 每条链各 6 个状态：
  - `mE`、`mI`：mRNA 外显子、mRNA 内含子
  - `lE`、`lI`：lnc 外显子、lnc 内含子
  - `D`、`A`：2 bp 的剪接供体 / 受体子状态
- 转移约束（正链；负链取镜像）：
  - IG → mE 或 lE（转录起点）；mE / lE → IG（转录终点）
  - mE → D → mI，lE → D → lI：只允许在 GT 或 GC 位点进入 D
  - mI → A → mE，lI → A → lE：只允许在 AG 位点
  - **不允许**在 mRNA 和 lnc 通路之间直接转移：一个基因从头到尾只属于一种类型
- 转移打分：转移得分（可学习的标量）+ 逐碱基状态势。
- 最小内含子长度与外显子长度先验：v1 不加入；若 0.2 smoke 显示碎片化严重，再按 §5 的预案加入，作为协议 v1.1。

**训练目标**（M30 的部分观测 CRF）：loss = log Z − log Z_obs。
- Z_obs 是只允许"与标签相容的状态"的前向求和。
- **未注释区的处理是唯一的变量**：
  - 主模型：v50 未注释、且落在 U-ev 证据区内的位置，允许 {IG、lE、lI、D、A}（两条链）；其余未注释位置只允许 IG。
  - 消融：全部只允许 IG（即 F）。
- AdamW，学习率 1e-3，最多 8 个 epoch。用 chr18 上 lnc L1 F1（解码后，v50）选 checkpoint。

**解码与输出**：
- Viterbi 路径：每段"IG → 外显子 … 外显子 → IG"成为一个基因，类型就是它所在的通路。
- 基因置信度 = 该基因 Viterbi 片段的后验质量，即前向–后向边缘的几何平均。
- 温度 τ 在 chr18 上按 ECE 选取（网格与 M33 相同）；基因过滤阈值在 chr18 上按 lnc L1 F1 选取。
- 输出 GFF3：gene / lnc_RNA | mRNA / exon，带 `confidence`。
- 小 ncRNA 由 0.6 的 Rfam / tRNAscan 组件写入同一个 GFF3（按 0.6 的整合规则），不参与本节的 gate。

## 3. 终点与判据（chr20，ruler v1.3，分链，v50 真值）

| 级别 | 判据（3 个 seed 平均；对 GENATATOR 做按基因配对 bootstrap 2,000 次） |
|---|---|
| **Go（可行）** | lnc L1 Sn ≥ **0.20**，**且** lnc L1 严格 Pr ≥ **0.40**，**且** L1 Sn 相对 GENATATOR（hg38 chr20，Sn 0.028 / Pr 0.42）提升的 95% CI 下界 > 0 |
| **Strong（论文主张）** | 在 Go 之外再满足：lnc L2（内含子链）Sn ≥ 0.05（GENATATOR 0.012）；在 T2T chr20 官方 metric（k = 250）下，lnc_RNA 的 segmentation recall 高于 GENATATOR（0.007）且 precision 不低于它（0.037）；非同源子集上 L1 Sn ≥ 0.15 |
| 护栏 | mRNA L1 Sn ≥ 0.80；被报成 mRNA 的 lnc 基因数少于 GENATATOR（46 个） |
| No-go | 上述 Go 不满足 → 回到 D1，改用 G2 或调整骨干；不在测试集上调参 |

**次要终点（只报告）**：
- L3–L6；单外显子 lnc 的 L5；
- 按 lnc 长度、外显子数、表达支持度分层；
- Δ（v50 新增）子集；
- 校准：ECE 与可靠性曲线；
- 推理速度：Mb / GPU-h。

## 偏离与澄清记录

- **2026-10-20，P1.0 实现阶段，尚无任何训练结果**：
  - G1 状态数从草案的 13 个改为 **17 个**：IG，加上每条链、每种类型各 {E, L, I, R}。原因是剪接边界子状态必须按类型区分，才能保证 §2 的"不允许在 mRNA 与 lnc 通路间直接转移"。这不是科学设计上的变化。
  - 剪接 motif 按基因组从左到右书写：+ 链 L ∈ {GT, GC}、R = AG；− 链 L = CT、R ∈ {AC, GC}。正反链的转移参数按镜像绑定，保证 log Z 在反向互补下不变。
  - 单元测试（29 项）全部通过：log Z、后验边缘、Viterbi 与暴力枚举逐项一致；部分观测配分正确；反向互补不变；2 万 bp 随机输入下 Viterbi 路径全部合法。
- **2026-10-22，v1.6 实现阶段（尚无任何 G1B / G2 结果）**：
  - **Kaggle 拆分**：`p1s-data + p1s2-data + chr18 特征` 同时挂载（约 24 GB）的 kernel 今天无法启动（空日志 ERROR；单独挂载均正常，约 14 GB 以下可启动）。因此每个 seed 拆成“训练 kernel”（p1s-data + p1g-data）和“chr18 评估 kernel”（p1s2-data + chr18 特征 + 训练输出，代码内嵌）。训练、选 checkpoint、评估的设置都不变。
  - **G1 后验的 float32 精度**：后验边缘在 float32 下逐碱基求和偏离 1（3 kb 时约 0.02%，24.5 kb 窗口约 1.8%；float64 下严格为 1），来源是块扫描中 log 值随长度累积。R 与 G1B 使用同一实现，彼此可比，因此本轮不改 G1；G2 的动态规划与前缀和全部用 float64。
  - **G2-0 的后验计算在 Kaggle GPU 上进行**：CPU 上每个窗口约 200 秒，不可行。
  - **G2 实现细节**（`grammar/g2.py`，均写于任何 G2 结果之前）：
    - 片段标签按基因组位置分为 单 / 最左 / 中间 / 最右 外显子与内含子，参数按转录本角色（单 / 首 / 内部 / 末）做正反链镜像绑定。
    - 转移分挂在相邻外显子的闭合端（IG→单、单→IG、IG→首、末→IG、供体、受体），转移矩阵只保留结构约束。
    - 窗口两端为开放端：开放端不计事件、转移、长度分，也不施加最短长度。
    - **基因间区不设分桶长度分**（偏离 §13 的 G2-2 描述）：IG 长度普遍超出训练窗口和 256 个候选的回看范围，只能用线性（几何）长度并用无上限的累加器实现。长度分只用于外显子各角色和内含子。
    - G2-3 的片段 MLP 隐藏宽度为 16（输入为片段内与两侧 50 bp 的 C0 隐藏特征均值经线性投影后的前缀和）。
    - 端点候选的平滑窗为 21 bp（与正例 ±10 bp 一致），峰的非极大值抑制半径为 25 bp。
    - 正确性：与独立的暴力枚举逐项一致（log Z、观测配分、损失、Viterbi，以及对全部参数和输入的梯度；19 项测试）。
- **2026-10-21，v1.5 诊断执行**：§12 写的是在 ont CPU 上解码。ont 负载约 60/32 核，CPU 上势能计算预计约 5 小时，因此改在 Kaggle castwj GPU 上运行同一解码与诊断脚本（kernel `ncrna-diag-l2-r-123`）。设置与 P1-S2 相同，lnc 预测数与 L1 Pr 完全复现。另外加做了一个标注为“探索性”的补充分析（跨度比、跨基因合并、跨度内 / 外内含子），不参与 A / B / C 判定。结果见 `results/RESULT_DIAG_L2.md`。

## 8. 代理路线筛选阶段 P1-S（v1.1 新增，2026-10-20，在任何 P1-S 结果之前冻结）

**背景**：用户 2026-10-20 设定资源优先级为 TE > coding RNA > ncRNA，ncRNA 只在不冲突时运行，并希望先完成耗时的路线筛选这类偏思考的任务，正式运行等 credits 刷新后再推进。P1-S 用 Phase 0 已缓存的代理特征，在 Kaggle（jiunige / castwj）上便宜地筛选路线，不占 ont 的 GPU，不读 chr20。**P1-S 的结论都是代理结论**，进入 P1.3 及以后的正式流程后会在完整特征上复核，不直接写进论文主张。

**数据**：
- 特征：Phase 0 0.5 的缓存，GENERanno-1.2b-cds 第 23 层，PCA 降到 512 维，fp16（`data/p05_feat/`）。
- 窗口：2,000 个训练窗口和 chr18 上的 300 个验证窗口，与 0.5 完全相同。
- 标签：用本协议 §1 的 G1 分链规则，为这些窗口重新生成允许状态掩码（v50 / v41 × U-ev / F）。

**模型**：C0Head(512)，G1，AdamW 1e-3，6 个 epoch，batch 8，seed 42。

**验证**：
- 300 个 chr18 窗口各自做 Viterbi，预测映射回 chr18 坐标。
- 真值取完全落在任一验证窗口内的 v50 基因。
- 用 ruler v1.3（分链）计算 lnc L1 F1，以及 L2 Sn。
- 选 checkpoint 用 lnc L1 F1。

**筛选臂**：

| 臂 | 训练标签 | 语法 | 解码 |
|---|---|---|---|
| R（参照） | v50 + U-ev | 并集（17 状态） | Viterbi |
| S1 | 与 R 共用同一个模型 | – | 后验边缘 argmax，再取连续片段（不加语法约束） |
| S2 | v50 + U-ev；mRNA 标签视为 IG | 只有 lnc（mRNA 状态的势设为 NEG） | Viterbi |
| S4 | v50 + F | 并集 | Viterbi |
| S5 | v41 + U-ev | 并集 | Viterbi |

**预先声明的决策规则**（都看 chr18 窗口上的 lnc L1 F1）：
1. R − S1 ≥ 0.02：保留语法解码。否则重新审视 D1，考虑 G2 或加入时长状态。
2. R ≥ S2 − 0.01：保留并集语法。否则只保留 lnc 通路，编码作为外部 offset，并记入 v1.2。
3. S4 > R + 0.02：主模型改用 F。否则保留 U-ev。
4. S5 只作为 AB4 的预期参考，不设决策。
5. 碎片化检查：若 R 预测的 lnc 基因数超过窗口内真值 lnc 基因数的 5 倍，或 R 的 lnc L1 Pr < 0.2，就实现最小内含子 / 外显子时长状态（S3），并在同样设定下重新筛选 R 与 S3。
6. 若两个臂的差距在 ±0.02 之内，补跑 seed 123 再判定。

## 9. v1.2：标签与语法的可行性修复（2026-10-20，实现层修复；判据与筛选臂不变）

**发现**：P1-S 第一轮的 R 臂中，每碱基 loss 一直约为 7（17 状态的每碱基熵上限约 2.8），L2 始终为 0。

**诊断**：
- 把发射设为 0、带标签掩码跑 Viterbi，发现 400 个训练窗口中有 **242 个（60%）的标签在 G1 语法下不可行**，平均每个窗口 2.0 处违例。每处违例罚 1e5，摊到每碱基恰好约 7–8 nats，与观察到的 loss 一致。
- 违例主要出现在外显子/内含子边界上，剪接 motif 门控不满足：多个 isoform 合并成并集后，边界落在了转录起点或其他 isoform 的外显子端点上，而不是真正的剪接位点。次要来源是同链嵌套基因和非经典剪接位点。

**修复**（`labels.py`）：
1. 确定标签只取每个基因的 **Ensembl_canonical** 转录本。其他 isoform 的外显子中，代表转录本不认为是外显子的位置，设为该基因的 unknown：{IG} 加上该类型和链的全部状态。
2. **可行性修复**：仍有违例时，在违例点 ±50 bp 内允许全部状态，迭代直到可行。修复只增加允许的状态，不删除。放松的碱基比例记录在 `repair_stats.json` 中，并写进报告。

**处置**：
- P1-S 第一轮（R、S2、S4，以及 R 附带的 S1）是在不可行目标上训练的，**结果作废，只作诊断用**；S5 未运行。
- 用 v1.2 标签重跑全部筛选臂，决策规则不变。
- §1 的 P1.1 数据（`data/p1`）同样需要按 v1.2 重新生成。

## 10. v1.3：S3（时长约束）的具体实现（2026-10-21；写于任何 S3 结果之前）

**触发**：P1-S v1.2 的 R 臂（已看到其结果）满足规则 5（lnc 预测数是真值的 8 倍，严格 Pr 0.09），同时满足规则 1 的"重新审视"条件（S1 比 R 高 0.068）。探索性分析显示，两种解码的输出都以成熟长度 < 200 nt 的短碎片为主。

**为什么只在解码阶段加约束**：如果把时长链放进训练，状态数会从 17 增加到约 280，而 block scan 的开销随 S³ 增长，在 T4 上不可行。

**S3 的定义**（只改解码，训练与 R 完全相同，用 R 的最佳 checkpoint）：
1. 在扩展状态空间上做 Viterbi：每种类型和链的外显子至少 **20 bp**，内含子（含 L、R 边界碱基）至少 **50 bp**。
   - 链中的内部转移沿用原状态的自环分数，进入和离开的转移与 G1 相同，发射与原状态相同。
2. 再过滤：去掉成熟长度 < **200 nt** 的 lnc 转录本（lncRNA 的定义）。mRNA 不做此过滤。

**比较与规则**：
- 在相同的 chr18 验证窗口上比较 S3 与 R、S1，沿用规则 1 和规则 5 的阈值。
- 同时报告探索性的位点合并 Pr（同链重叠的预测先合并成位点）。由于 L1 指标会被碎片化抬高，用 L1 比较"碎片化解码"和"结构化解码"有偏；这一点在判读时写明，但不改动预先声明的规则。
- 若 S3 满足规则 1（S3 − S1 ≥ 0.02）且碎片化消失（预测数不超过真值的 5 倍）→ 保留 G1，并采用解码期时长约束。
- 否则 → 筛选 G2（稀疏事件半马尔可夫，可以直接建模长度），作为 v1.4。

## 11. v1.4：重新设计的代理筛选 P1-S2（2026-10-21，用户批准；在任何 P1-S2 结果之前冻结）

**原因**：P1-S（§8–10）的统计功效不足——验证集只有 86 个 lnc 基因，选 checkpoint 的噪声占主导，L1 F1 还会被碎片抬高。因此**§8 和 §10 的形式判定都不采纳**（见 `results/RESULT_P1S.md`），由本节取代。

**特征**：与 P1-S 相同的代理特征（GENERanno-1.2b-cds 第 23 层，用 Phase 0 的 PCA 降到 512 维）。
- 训练：2,000 个窗口，同 P1-S。
- **验证：整条 chr18**。chr18 的特征在 Kaggle T4 上提取（fp16 计算；训练特征是在 A10G 上用 bf16 算的）。
- 提取时做一致性检查：在 T4 上重新计算 20 个训练窗口，与缓存特征比较余弦相似度并报告。若中位数 < 0.99，就停下来先处理精度差异，不做判读。

**标签**：v1.2 版（canonical + 修复）；各臂与 P1-S 一致：R = v50 + U-ev，S2 = 只有 lnc，S4 = v50 + F。

**训练**：
- 12 个 epoch，AdamW，学习率 1e-3，余弦衰减到 1e-5，batch 8。
- 每个臂 3 个 seed：{42, 123, 456}。
- **选 checkpoint**：用 P1-S 的 300 个 chr18 验证窗口上的每碱基 NLL，即 (log Z − log Z_obs) / L，标签变体与该臂的训练标签相同。这个量稳定，并且与下面的判定指标无关。

**最终评估**（每次运行只做一次，用选出的 checkpoint，在整条 chr18 上）：
1. **解码**：
   - R、S2、S4 用 S3（外显子 ≥ 20、内含子 ≥ 50、lnc ≥ 200 nt；S2 屏蔽 mRNA 状态）。
   - S1 用 R 的同一个模型，取后验 argmax 后得到连续片段，同样过滤 lnc < 200 nt。
2. **基因置信度**：解码出的每个基因，在其全部碱基（外显子 + 内含子）上取"解码状态的后验边缘概率"的平均值。后验在 24,576 bp 的窗口上用前向–后向计算（步长 20,472，只保留中心部分）。
3. **主指标 AUPRC_lnc**：
   - 预测的 lnc 转录本按置信度从高到低排序，阈值逐步放宽，每一步计算：
     - Sn = 被保留预测命中的 v50 lnc 基因比例（L1，同链外显子重叠；真值为整条 chr18 的 v50 lnc 基因）；
     - Pr = 位点合并后的 precision（同链重叠的保留预测先合并成一个位点，位点命中任一 v50 lnc 基因即为正确）。
   - 由此得到 PR 曲线，AUPRC 按阶梯积分计算。
4. **次要指标**：
   - 最优阈值下的位点合并 F1；
   - L2 内含子链 Sn 与 Pr；
   - mRNA 的 L1 Sn 与 Pr（S2 不适用）；
   - 预测数与真值数之比。

**判定规则**（主指标都用 AUPRC_lnc 的 3 个 seed 均值；Δ 是 seed 配对的差值）：
1. R 对 S1：若 R ≥ S1 − 0.01 → 保留 G1 + S3 解码。若 S1 > R + 0.01 且 3 个 seed 同号 → 重新审视结构化解码，进入 G2 设计评估。
2. R 对 S2：若 R ≥ S2 − 0.01 → 保留并集语法。若 S2 > R + 0.01 且 3 个 seed 同号 → 改为只保留 lnc 通路，编码作为外部 offset。
3. R 对 S4：只有当 S4 > R + 0.01 且 3 个 seed 同号时，主模型才改用 F；否则保留 U-ev。
4. 若某项差值的 3 个 seed 不同号，则判为"无法区分"，保留当前设计（R），并在正式特征阶段（P1.4 消融）复核。

**算力与优先级**：只用 Kaggle castwj（同时最多 2 个会话）；chr18 的特征提取和每个 run 的最终评估都在同一账户内进行。不使用 ont 的 GPU，不使用 jiunige（让给 TE 项目）。

## 12. v1.5：内含子链（L2）失败诊断（2026-10-21，用户批准；在看到任何诊断结果之前写定）

**目的**：P1-S2 中 lnc 的 L2 Sn ≈ 0，而位点 Sn 约 0.1、Pr 约 0.5。需要先搞清楚失败来自哪里，再决定是否进入 G2。

**材料**：
- 每个臂取 AUPRC 中位的那个 seed（R 是 seed 123，AUPRC 0.0609），用它的 checkpoint 在 ont 的 CPU 上对整条 chr18 做 S3 解码（与 P1-S2 相同的设置），写出 GFF。
- 同一个 GFF 也用于 mRNA 的对照分析。
- 只用 CPU 和 Kaggle，不读 chr20。

**诊断项**（只针对 L1 命中的预测：每个预测转录本只与它重叠最多的那一个真值 isoform 配对）：
1. **单外显子**：预测是单外显子、但配对的真值是多外显子的比例。
2. **剪接点精度**：预测的每个内含子，与配对真值中最近的内含子比较供体 / 受体的位置偏差。分档统计：0 bp、1–5、6–20、21–100、> 100 / 无对应。
3. **外显子覆盖**：配对真值的外显子中，被预测外显子覆盖（≥ 1 bp）的比例；以及预测中多出来的外显子数。
4. **两端**：预测 TSS / TES 与真值 TSS / TES 的距离分布；真值转录本跨度被预测跨度覆盖的比例。
5. **链与类型**：命中位点但链或类型错误的比例。
6. **真值构成**：chr18 上 v50 lnc 基因中单外显子与多外显子的比例，以及内含子长度分布与预测的对比。

**预先声明的决策规则**（只根据诊断 2–4 判定 lnc）：
- **A. 边界精度问题**：若预测内含子中 ≥ 50% 的偏差落在 1–20 bp（有对应但不精确），说明结构基本正确、只是剪接点位置不准 → **不需要 G2**。在 G1 内加强剪接位点打分（剪接头 / motif 上下文特征）后复测。
- **B. 结构缺失问题**：若配对的多外显子真值中，预测为单外显子的比例 ≥ 50%，或外显子覆盖率中位数 < 0.5 → 长度与结构建模不足 → **进入 G2**（基因级与外显子片段级打分）。
- **C. 两端问题**：若真值跨度覆盖率中位数 < 0.5，或 TSS / TES 偏差中位数 > 1 kb → 转录本边界不足 → **G2 的 TSS / TES 候选机制**，或在 G1 里加入边界头。两种做法都写进 v1.6 后再比较。
- A、B、C 可能同时成立：按 B → C → A 的优先顺序处理，结构问题优先于边界精度。
- 若都不成立（例如偏差分布很分散），就报告"无单一主因"，不进入 G2，先等正式特征的结果。

## 13. v1.6：G1 + 边界头 对照 与 G2 分级实现（2026-10-22，用户批准并冻结；冻结时没有任何 v1.6 结果）

**触发**：v1.5 诊断规则 B + C 成立、A 不成立（`results/RESULT_DIAG_L2.md`）。主因是 lnc 预测“停不下来”（跨度中位数为真值的 2.8 倍，72% 预测内含子在真值跨度外，预测内含子中位 18 kb，真值 4 kb）。按规则 C，G2 与“G1 + 边界头”两种做法都写进 v1.6 再比较。

**共同设定**（与 P1-S2 相同）：代理特征（第 23 层 PCA-512），2,000 个训练窗口，v50 + U-ev 标签（v1.2 canonical + 修复），12 epoch、AdamW 1e-3 余弦到 1e-5、batch 8，seed {42, 123, 456}；选 checkpoint 用 300 个 chr18 验证窗口上各模型自身的每碱基 NLL；最终在整条 chr18（929 个 v50 lnc 基因）上评估一次，主指标 AUPRC_lnc（位点合并 Pr）。不读 chr20。**G1 + S3 的基线直接复用 P1-S2 的 R 臂三个 seed**，不重跑。

**新增标签（P1-G0，CPU）**：从 v50 canonical 转录本生成每个窗口的 8 个事件通道（每条链：供体、受体、TSS、TES）。正例 = canonical 事件 ±10 bp；同一基因其他 isoform 的事件 ±50 bp 内不计损失；U-ev unknown 区间内不计负例损失。

**臂 1：G1B（G1 + 边界头）**
- C0 头增加 TSS / TES 输出通道（每链 2 个），用 BCE 辅助损失（权重 1）与 CRF 损失联合训练。
- 边界 logit 作为**位置相关的转移分**加到“基因间区 → 外显子”和“外显子 → 基因间区”两类转移上（+ 链：进入 = TSS、离开 = TES；− 链相反），每种类型一个可学习系数，正反链镜像绑定。log Z 的块扫描本来就逐位置构造转移张量，改动很小；numba Viterbi 与 S3 解码同步扩展；新增与暴力枚举对照的单元测试。
- 基因置信度与 R 相同（后验均值）。

**臂 2：G2（稀疏事件半马尔可夫 / GHMM），按优先级分三级实现，每级累加**
- **G2-1：TSS/TES 事件与基因级结构**。片段类型：基因间区、内含子、外显子分为 单 / 首 / 内部 / 末 四类（每种类型 k ∈ {m, l}、每条链）；片段边界只能落在候选事件上；片段分 = G1 同款逐碱基势能的前缀和 + 进入事件分（TSS / TES / 供体 / 受体 logit）。本级长度分为线性（等价几何分布）。
- **G2-2：+ 长度分**。内含子、基因间区、四类外显子各自的分桶 log 长度分（每类约 20 个桶参数）。
- **G2-3：+ 外显子片段分**。对每个候选外显子片段，用前缀和取片段内 C0 上下文特征的均值（加两侧各 50 bp 的均值），经小 MLP 得到片段级分。
- **候选事件**：取同 seed 的 G1B checkpoint（冻结）。供体 / 受体 = 满足 motif 且 G1B 的 L / R 后验 ≥ θ 的位点；TSS / TES = 平滑后边界 logit 的峰。θ 在训练窗口上设定：剪接事件召回 ≥ 99%，边界 ±50 bp 召回 ≥ 95%。训练时真实事件强制加入候选。每个片段向前最多考虑 256 个候选，内含子 ≤ 500 kb。G2 的 C0 头从头训练（不继承 G1B 权重），训练目标仍为 log Z − log Z_obs。
- 基因置信度 = 该基因各片段后验边缘概率的平均值。
- **G2-0 可行性门**（看任何 G2 性能指标之前）：在 300 个验证窗口上报告候选召回上限。若 lnc canonical 内含子（供体与受体都在候选中）召回 < 90%，把目标召回提高到 99.5% 重测一次；仍 < 90% 则停止 G2，报告不可行。同时在 1 Mb 区段上测 DP 吞吐量；若单个 seed 预计 > 4 T4 小时，先优化再上 Kaggle。

**运行顺序**：P1-G0（CPU）→ G1B × 3 seed（Kaggle，可与 G2 实现并行）→ G2-0 门 → G2-3（完整版）× 3 seed → 判定 → 如触发，再跑分级消融 G2-1、G2-2 各 3 seed。

**判定规则**（Δ 为 seed 配对的 AUPRC_lnc 差值，取 3 个 seed 均值）：
1. **G1B 对 R**：Δ ≥ +0.01 且 3 个 seed 同号 → G1B 作为改进的 G1 基线；否则基线仍为 R。
2. **G2-3 对较好的 G1 基线**：Δ ≥ +0.02、3 个 seed 同号，且 lnc L2 Sn 均值 ≥ 0.01 并在 3 个 seed 中都高于基线 → G2 替换 G1。
3. **mRNA 保护**：若 mRNA L1 F1 均值比 R 低 > 0.05，即使满足规则 2 也不替换，并报告。
4. **简约原则**：若 G2 对 R 满足规则 2，但对 G1B 的 Δ < +0.01 → 采用 G1B（更简单、更便宜），G2 留到正式特征阶段再比较。
5. **都不优于 R** → 保留 G1 + S3，结论为代理特征下 L2 失败主要受特征限制；G1B / G2 作为消融臂进入 P1.3 正式特征复核。
6. **分级消融**（仅在 G2 替换后）：某一级组件若去掉后 Δ 不低于 −0.01（或 3 个 seed 不同号），则删除该组件以简化模型。
7. 3 个 seed 不同号的差值一律判为“无法区分”；Kaggle 端基础设施错误可重试一次。

**机制核对**（次要，报告不判定）：每臂取 AUPRC 中位 seed，复跑 v1.5 诊断：跨度比、TSS / TES 偏差、跨度外内含子比例、精确接头比例、mRNA 碎片化程度。预期 G2 / G1B 应使跨度比接近 1、TSS / TES 偏差下降。

**算力**：只用 Kaggle castwj（最多 2 个并发会话）与 ont / 本地 CPU（nice，低优先级）；不用 ont GPU，不用 jiunige。估计：G1B 约 5 T4 小时，G2-3 约 6–10 T4 小时，分级消融（如触发）再约 12–20 T4 小时；本周 castwj 已用约 17.5 小时，预计跨越一次周配额刷新。实现工作量：G1B 约 0.5–1 天，G2 约 3–4 天（含暴力枚举单元测试）。
