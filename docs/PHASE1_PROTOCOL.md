## 0. 设计决定（已确认，均采用推荐方案）

| # | 决定 | 推荐 | 备选 |
|---|---|---|---|
| D1 | **语法核心的实现** | **G1：Tiberius 式可微 HMM-CRF**。逐碱基状态，编码 / lnc / 基因间区三条通路的并集，正反链都建模，剪接 motif 门控转移；前向算法求 log Z、Viterbi 解码、前向–后向求后验，全部在 GPU 上精确计算。 | **G2：沿用 M28 的稀疏事件半马尔可夫**。用学到的 TSS / TES / 剪接头产生候选事件，再在候选格上精确求和。最接近 M28 代码，但召回受候选剪枝上限限制，并且依赖 CPU DP（M28 的 GPU 利用率只有 11%）。 |
| D2 | **主模型的训练标签** | **GENCODE v50**（最完整），v50 未注释区用 U-ev 证据掩码。时间切分（只用 v41 训练）作为消融，专门回答"真值不完整"的问题。 | 全部用 v41 训练（与 Phase 0 一致，但主模型的标签会少一半）。 |
| D3 | **Phase 1 的物种范围** | **只用人类训练、人类评测**，以建立可行性；用 4 个面板物种做零样本描述性评测，不设 gate。多物种训练放到 Phase 2。 | 一开始就多物种训练（数据和算力成倍增加，可行性未知时风险高）。 |

关于 D1 的说明：coding 项目里**可以原样复用**的有：
- C0 / SharedContext 头（6-mer 特征 + DNA 卷积 → 逐碱基势）；
- M30 的"允许状态集"部分观测训练：log Z_observed − log Z；
- 基因后验、温度 τ 校准、只在内部验证上选阈值的流程（M29-A2 / M33）；
- 配对 bootstrap 与报告格式。

**不能原样复用**的是 M28 的事件格本身：它依赖 ATG / 终止子 / ORF 的稀疏性，而 lncRNA 没有这些约束。G1 把"语法"表达为带约束的状态转移，是同一思想的线性时间实现。

## 1. 数据与划分（人类，hg38）

| 用途 | 染色体 | 说明 |
|---|---|---|
| 训练 | chr1–17、19、21、22、X | 抽 3,000 个 24,576 bp 窗口：40% 以 lnc 基因为中心，30% 以编码基因为中心，30% 均匀随机；N 占比 > 10% 的窗口丢弃；seed 0 |
| 内部验证 | chr18 整条 | 用于选 checkpoint、τ、阈值；可以多次读取 |
| **最终测试** | **chr20 整条** | 每个冻结模型只读一次（3 个 seed 一起读）；所有选择都在读取之前完成 |
| GENATATOR 可比测试 | T2T-CHM13 chr20（NC_060944.1） | 用 leaderboard 真值和官方 metric（k = 250），与其公开预测直接对比；只在最终模型冻结后读一次 |
| 零样本面板（描述性） | 鸡 5、斑马鱼 22、果蝇 2L、线虫 I | Ensembl 116；ruler v1.3 |

- **同源隔离（新增）**：chr20 的 lncRNA 外显子序列与训练染色体的 lncRNA 外显子做 BLASTn（e < 1e-10，identity ≥ 80%，覆盖 ≥ 50%）。命中的 chr20 基因记为"同源"，结果按"全部 / 非同源"分别报告。
- **标签**：
  - 逐碱基、分链。按并集 isoform：外显子优先于内含子，lnc 优先于 mRNA（与 0.5 一致）。
  - 同一位置在两条链上都有注释时，允许状态取两链状态的并集。
  - 编码基因暂不区分 CDS 与 UTR，统一为 mRNA 外显子 / 内含子（见 §2）。

## 2. 模型

**骨干**：GENERanno-eukaryote-1.2b-cds-annotator-preview，冻结。
- 取第 17 和第 23 层的隐状态拼接（4,096 维；23 是 0.4 中 lnc 最佳层，17 提供较浅层特征），不做 PCA。
- 特征一次性缓存为 fp16，放在 ont 本地 NVMe：3,000 个训练窗口约 100 GB；chr18、chr20、T2T chr20 三条整染色体合计约 290 GB（ont 剩余约 2 TB）。
- LoRA 列为 Phase 2 的消融，Phase 1 不做。

**头**：C0 / SharedContext（从 coding 项目复制并注明出处；不 import 冻结代码）。
- 结构：Linear(4096→256) → BiGRU(256) → 上采样到碱基（×6）⊕ DNA 卷积 → 逐碱基状态势。
- 参数量约 1–2M。

**语法 G1（逐碱基，正反两条链，共 13 个状态）**：
- `IG`：基因间区（两链共享）
- 每条链各 6 个状态：
  - `mE`、`mI`：mRNA 外显子、mRNA 内含子
  - `lE`、`lI`：lnc 外显子、lnc 内含子
  - `D`、`A`：2 bp 的剪接供体 / 受体子状态
- 转移约束（正链；负链取镜像）：
  - IG → mE 或 lE（转录起点）；mE / lE → IG（转录终点）
  - mE → D → mI，lE → D → lI：只允许在 GT 或 GC 位点进入 D
  - mI → A → mE，lI → A → lE：只允许在 AG 位点
  - **不允许**在 mRNA 和 lnc 通路之间直接转移：一个基因从头到尾只属于一种类型
- 转移打分：转移得分（可学习的标量）+ 逐碱基状态势。
- 最小内含子长度与外显子长度先验：v1 不加入；若 0.2 smoke 显示碎片化严重，再按 §5 的预案加入，作为协议 v1.1。

**训练目标**（M30 的部分观测 CRF）：loss = log Z − log Z_obs。
- Z_obs 是只允许"与标签相容的状态"的前向求和。
- **未注释区的处理是唯一的变量**：
  - 主模型：v50 未注释、且落在 U-ev 证据区内的位置，允许 {IG、lE、lI、D、A}（两条链）；其余未注释位置只允许 IG。
  - 消融：全部只允许 IG（即 F）。
- AdamW，学习率 1e-3，最多 8 个 epoch。用 chr18 上 lnc L1 F1（解码后，v50）选 checkpoint。

**解码与输出**：
- Viterbi 路径：每段"IG → 外显子 … 外显子 → IG"成为一个基因，类型就是它所在的通路。
- 基因置信度 = 该基因 Viterbi 片段的后验质量，即前向–后向边缘的几何平均。
- 温度 τ 在 chr18 上按 ECE 选取（网格与 M33 相同）；基因过滤阈值在 chr18 上按 lnc L1 F1 选取。
- 输出 GFF3：gene / lnc_RNA | mRNA / exon，带 `confidence`。
- 小 ncRNA 由 0.6 的 Rfam / tRNAscan 组件写入同一个 GFF3（按 0.6 的整合规则），不参与本节的 gate。

## 3. 终点与判据（chr20，ruler v1.3，分链，v50 真值）

| 级别 | 判据（3 个 seed 平均；对 GENATATOR 做按基因配对 bootstrap 2,000 次） |
|---|---|
| **Go（可行）** | lnc L1 Sn ≥ **0.20**，**且** lnc L1 严格 Pr ≥ **0.40**，**且** L1 Sn 相对 GENATATOR（hg38 chr20，Sn 0.028 / Pr 0.42）提升的 95% CI 下界 > 0 |
| **Strong（论文主张）** | 在 Go 之外再满足：lnc L2（内含子链）Sn ≥ 0.05（GENATATOR 0.012）；在 T2T chr20 官方 metric（k = 250）下，lnc_RNA 的 segmentation recall 高于 GENATATOR（0.007）且 precision 不低于它（0.037）；非同源子集上 L1 Sn ≥ 0.15 |
| 护栏 | mRNA L1 Sn ≥ 0.80；被报成 mRNA 的 lnc 基因数少于 GENATATOR（46 个） |
| No-go | 上述 Go 不满足 → 回到 D1，改用 G2 或调整骨干；不在测试集上调参 |

**次要终点（只报告）**：
- L3–L6；单外显子 lnc 的 L5；
- 按 lnc 长度、外显子数、表达支持度分层；
- Δ（v50 新增）子集；
- 校准：ECE 与可靠性曲线；
- 推理速度：Mb / GPU-h。

## 5. 执行顺序与预案

| 步骤 | 内容 | 算力 | 预计 |
|---|---|---|---|
| P1.0 | 实现 G1：前向 / Viterbi / 前向–后向 / 观测掩码。单元测试：在小序列上与暴力枚举的 log Z 和 Viterbi 结果完全一致；状态路径的合法性（motif、类型不混）；两链对称性 | CPU | 1–2 天 |

| P1.2 | smoke：20 个窗口、1 个 epoch，跑通端到端 GFF3 和打分；**Kaggle**（jiunige）或 ont | 免费 | 半天 |
| P1.3 | pilot：1 个 seed 完整训练，只看 chr18 | ont | 1 天 |
| P1.4 | AB1–AB4 筛选（1 个 seed，只看 chr18） | ont | 1–2 天 |

- **算力**：ont 优先（免费，遵守"一次一个 GPU 任务"）；smoke 走 Kaggle（jiunige）；Modal 当前已停用，co-author workspace 需要你另外批准；Baobab 不用。
- **监控**：后台事件 waiter + 50 分钟心跳；训练脚本每个 epoch 写一行 JSONL 指标。
