## 1. 对象

**剪接图**：单链、单位点上的有向无环图 G = (V, E)，只用输入证据构建。
- 外显子片段：由所有剪接位点、起点、终点切出的最大不分割区间，作为普通节点。
- 每个起点簇 a 是一个虚拟源点 s_a，连向它所在的片段；每个终点簇 b 是一个虚拟汇点 t_b，由它所在的片段连入。起点、终点簇分别聚类，用最大簇直径限制，避免链式合并。
- 边分两种：相邻片段的连续边，以及剪接边。

**转录本**：从某个 s_a 到某个 t_b 的一条路径 p，同时决定内含子链和两端。只要内含子链、不管端点的粒度，记为 p̄。

**观测**：每个观测 o 对应 G 上的一条子路径 π_o，代表这条读段或证据所跨的连续结构：
- 短读长：剪接边，或读段对覆盖的短子路径；
- 长读段：较长的子路径，可能截短；
- 全长分子：从 s_a 到 t_b 的整条路径；
- 端点证据：只确定 s_a 或 t_b 的存在，不给配对。
- 可选的覆盖量：每条边的观测丰度 w_e。

## 2. 可行解

一个解是带权转录本集合 𝒫 = {(p_1, x_1), …, (p_k, x_k)}，x_i > 0，满足：
- **(C1) 覆盖**：每个观测的子路径 π_o，都被某条 p_i 完整包含。
- **(C2) 端点**：每个被观测到的起点簇、终点簇，至少被一条 p_i 使用。
- **(C3) 定量（可选）**：对每条边 e，|Σ_{i: e∈p_i} x_i − w_e| ≤ ε·w_e + ε₀。
- **(C4) 简约**：k ≤ k* + δ，k* 是满足 C1–C3 的最小转录本数；主分析 δ = 0，敏感性分析用 δ = 1、2。

各种组合对应的问题：
- 只有 C1、C2、C4：带子路径约束的最小路径覆盖；
- 加上 C3：带子路径约束、允许误差的最小流分解。

**必须明说的假设**：没有 C4 时，几乎任何相容路径都「可能」，判定失去意义。所以全部结论都是「在简约假设下」。δ 的敏感性要报告。

## 3. 三态判定

对候选转录本 p，记 ℱ 为全部可行解：
- **必然（NECESSARY）**：∀𝒫 ∈ ℱ，p ∈ 𝒫；
- **不相容（INCOMPATIBLE）**：∀𝒫 ∈ ℱ，p ∉ 𝒫；
- **可能（POSSIBLE）**：其余情况。

同样的定义也用于内含子链粒度 p̄（端点不计）。

在有 C3 时，另外给出丰度界：
- L_p = min_{𝒫∈ℱ} x_p（p 不在解中时记 0）；
- U_p = max_{𝒫∈ℱ} x_p。
- L_p > 0，等价于 p 必然存在且有正的下界。

**和「安全路径」的关系**：
- 安全路径文献定义的是子路径 π 的安全性：π 被每个解中的某条路径包含。
- 本研究判定的是整条转录本是否作为解中的一员出现，并且包含两端，要求更强。
- 必然转录本的所有子路径都安全；反过来，所有子路径都安全的转录本不一定必然。E1 的配对歧义就是例子：各段都安全，配对不唯一。
- 这一点是要和文献对照的核心差异，待精读确认。

## 4. 证书与反例

**必然的证书**，分两层：
1. **结构证书**（可读）：存在一个观测 o，它的子路径 π_o 在 G 中向左只能唯一延伸到某个源点，向右只能唯一延伸到某个汇点，并且延伸结果就是 p。由 C1，p 必然在解中。全长分子是它的特例。
2. **求解器证书**（可复核）：在 C1–C4 之外加上「p ∉ 𝒫」，整数规划不可行。可以输出不可行证明，或者交给独立求解器复核。这一层用来覆盖靠计数、简约性才成立的必然。

**可能的反例**：给出两个可行解，一个含 p，一个不含 p，两者都满足 C1–C4。任何人都可以逐条检查它们是否真的解释了全部观测。

**不相容的证书**：在 C1–C4 之外加上「p ∈ 𝒫」，整数规划不可行。

## 5. 缺失证据诊断

对一个「可能」的 p，取不含 p 的可行解 𝒫⁻，在 p 上找一条最短的子路径 σ，要求它不被 𝒫⁻ 中任何路径包含。观察到 σ，就能排除 𝒫⁻。按 σ 的形状归类缺什么证据：

| σ 的形状 | 需要的新观测 |
|---|---|
| 两个相邻剪接事件之间，转录本坐标跨度 ≤ 片段长度 | 更多短读长或成对读段（现有深度不够） |
| 跨度超过短读长片段，跨多个分支点 | 跨多个剪接事件的长读段 |
| 包含 s_a 和 t_b、中间没有分支，只是两端配对不定 | 分子级两端连接（全长读段，或 TIF-seq 一类） |
| 不存在这样的 σ：𝒫⁻ 覆盖了 p 的全部子路径 | 只能靠定量（丰度）区分；补「更多分子」 |

多个 𝒫⁻ 时取全部最短 σ 的并集，报告最便宜的一类。「最便宜」按事先写定的成本顺序：短读长 < 长读长 < 分子两端。

## 6. 证据增量（方向 B，草图）

- 对位点 ℓ 和证据类型 τ，定义期望歧义消除量 Δ(ℓ, τ)：在当前可行解里随机取一个作为「真相」，按 τ 的观测模型模拟新观测，重新判定后，「可能」状态减少的数量取期望。
- 预算分配：按 Δ 除以成本排序。
- 验证：用全深度数据做事后 oracle 上界，用浅测序数据做可实施策略；对照是按深度、按丰度、平均分配。

## 7. 计算

- 小图：枚举全部 s–t 路径和全部解，作为 P0b 的绝对真值。
- 中图：整数规划。
  - 变量：每条候选路径是否入选、权重；
  - 约束：C1 写成「每个观测至少被一条入选路径包含」；C3 用线性不等式；
  - 先求 k*，再对每个候选 p 各解两次（强制含、强制不含）；
  - 求解器用 scipy 自带的 HiGHS。
- 大图：候选路径限制为「至少出现在一个最优解中」的路径，用逐次加不重复约束的方式枚举；超过时间上限的位点记为「超出计算范围」，单独报告，不硬算。
- 复杂度：最小流分解是 NP 难；带子路径约束的最小路径覆盖在一般图上的复杂度，待文献确认。

## 8. P0b 将检验的性质（事先写定）

1. 无噪声时，所有「必然」「不相容」判定与穷举一致，错误证书为 0。
2. 每个「可能」都附有两个可复核的可行解。
3. 结构证书一定是正确的（它是必然的充分条件）；报告它覆盖了多少「必然」。
4. 缺失证据诊断：按诊断补上那一类观测后，该歧义在穷举中确实被消除的比例。
5. 覆盖的场景：多起点 / 多终点（含 E1 型配对歧义）、外显子跳跃、内含子保留、截短长读段、δ = 0 / 1 / 2，以及有、无定量约束。

## 9. 与已有工作的差异（据 `notes/LITERATURE_P0a.md`；关键编号已在 Europe PMC 核实）

| 本方法的功能 | 最接近的已有工作 | 是否已被做过 |
|---|---|---|
| 三态判定 + 丰度上下界 | Zheng, Ma, Kingsford 2022（J Comput Biol，PMID 35041494）：在所有最优估计下求每条转录本的丰度范围，含相位路径；Khan 2022（PMID 36288562）、SafeMFD（Bioinformatics 2023，PMID 37862229）：所有流分解或最小流分解下必然存在的安全路径，SafeMFD 已支持子路径约束 | **大部分已做**。他们没有简约带（最小值 + δ，SafeMFD 只提为未来工作）、没有分开测得的端点证据、不输出反例 |
| 证书与反例 | 只在证明里隐含构造；没有工具输出 | **部分**：输出可复核的反例和结构证书是新的，但单独不足以成文 |
| 缺失证据诊断 / 测什么 | Ferrer-Bonsoms 2022（PMID 34978563）：基因级的读长、片段长度、双文库组合排序，假设端点已知；Shannon（bioRxiv 2016）：读长下界；IsoTools（PMID 37267159）：只有检出深度 | **最新的一项**：没有人按每一处歧义给出「缺哪类证据」 |
| 分开测得的起点、终点的配对（E1 型） | Bookend（PMID 35768836）用端点标签但只给一种贪心配对；Scallop2（PMID 36713932）推断真假端点；Ferrer-Bonsoms 把所有起止组合当已知候选；TIF-seq 是解决它的实验 | **没有论文显式处理**，与 E1 直接衔接 |

**怎么定位**：
- 以「缺失证据诊断」和「分开测得的端点下的配对可识别性」为主打。
- 三态判定和丰度范围写成对 Zheng 2022 和安全路径框架的推广：把它们作为特例纳入（无端点约束、δ = ∞ 或只取最优解），并证明在端点分开测得的证据下，判定结果有实质差别。
- 审稿人最可能的反驳是「Zheng 2022 + SafeMFD 已经覆盖」，所以 P0b / P0c 必须量化：
  - 在真实位点上，加入端点约束和简约带后，有多少转录本的状态改变；
  - 缺失证据诊断按建议补数据后，歧义是否真的消除。

## 10. P0a 门槛判定

门槛：能写出至少一项已有方法不提供、可实现的功能。

- **通过，但新意比预期窄。** 有两项清楚的新功能：
  1. 按歧义给出缺失证据诊断；
  2. 分开测得端点时的配对可识别性（含反例输出）。
- 三态和丰度范围本身已被 Zheng 2022 和 SafeMFD 覆盖，只能作为框架的一部分，不能当卖点。
- 未核实项：
  - Williams 2023、Caceres 2022 的全文；
  - SafeMFD 之后是否有人实现了「最小值 + δ」；
  - 2026 年是否有新的后续工作。
