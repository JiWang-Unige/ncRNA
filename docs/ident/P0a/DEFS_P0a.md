# P0a：定义与算法（v1，2026-11-24）

> 计划：`PLAN_IDENT.md`（作者 2026-11-24 批准）。v0 的文献差异与 ChatGPT 第 5 轮意见（`10_AUTH/discussion_20261124/ROUND5_ChatGPT_P0a.md`）已并入。v0 留在 git 历史里（提交 32af17d）。
> **核心问题**：要消除某一处转录结构歧义，什么样的新观测是充分的？哪些歧义靠加深度就能解决，哪些是某种测序方式原理上区分不了的？
> 三态判定、丰度范围、简约带、反例都是已有工作的推广（Zheng 2022、SafeMFD），在本研究里是基础设施，不是卖点。

## 1. 图与转录本

- **剪接图**：单链位点上的有向无环图 G = (V, E)，只用输入证据构建。节点是外显子片段，边是连续边或剪接边。
- **边界**：每个起点簇是虚拟源点 s，每个终点簇是虚拟汇点 t。每个边界都有类型：
  - **观测到的**：有端点证据（CAGE、3′ 端测序、带帽或带 polyA 的全长读段），可行解必须用到它；
  - **开放的**：只是读段在这里截止，真实端点未知。允许被使用，但不要求用到；在结论里单独标注，不当作已知端点。
- **候选转录本**：从某个源点到某个汇点的路径 p = (s, v₁ … v_m, t)。P0b 中候选集合是全部这样的路径；真实数据中做限制，见第 7 节。

## 2. 观测与协议

**结构观测** o 有三种：
- **子路径**：v_i … v_j，来自短读段、读段对的单个读端、截短或完整的长读段。p 产生 o，当且仅当 o 是 p 节点序列中连续的一段。
- **端点连接**：(s, t)，来自分子级两端连接，例如全长分子或 TIF-seq。p 产生 o，当且仅当 p 的源点是 s、汇点是 t。
- **端点存在**：s 或 t 本身，来自 CAGE、3′ 端测序。

**约束分硬和软**：
- 硬约束必须被某条转录本产生；
- 软约束允许违反，但计入惩罚。
- 噪声数据中，单条读段、低支持的端点默认为软约束。P0b 是无噪声检验，全部取硬约束。

**协议 τ 与观测算子**：每种测序方式 τ 能产生的观测集合记为 Ω_τ。给定丰度向量 x，它在 τ 下的期望观测计数为 B_τ x：
- B_τ[o, p] = p 产生 o 的方式数，即 o 在 p 中出现的次数；
- 观测分布是 B_τ x 归一化后的结果。

P0b 用到四种协议：

| 协议 | Ω_τ | 代表 |
|---|---|---|
| ends | 端点存在 | CAGE + 3′ 端测序 |
| short(L) | 长度 ≤ L 个节点的子路径（L = 2：单个剪接；L = 3：跨两个剪接） | 短读长、读段对 |
| long | 任意连续子路径，包括截短的 | 长读长 |
| link | 端点连接 (s, t) | 分子级两端连接 |

## 3. 可行解（对支持集 Z 定义）

一个解由支持集 Z（入选的候选路径）和丰度 x 组成。
- 每条路径有二元变量 z_p 和丰度 x_p，满足 η·z_p ≤ x_p ≤ M·z_p，其中 η 是最低有效丰度。
- 约束：
  - **(C1) 覆盖**：每个硬观测都被某条 z_p = 1 的路径产生。
  - **(C2) 边界**：每个「观测到的」边界被某条入选路径使用。
  - **(C3) 定量（可选）**：|B_τ x − y_τ| ≤ ε·y_τ + ε₀，y_τ 是协议 τ 的观测计数。
  - **(C4) 简约**：Σ z_p ≤ K，其中 K = k* + δ，k* 是满足 C1–C3 的最小支持集大小。
- **非生物学状态**：
  - C1–C3 无解时，记为 INFEASIBLE_MODEL（证据冲突），不做三态判定；
  - 求解超时或无法证明最优 / 不可行时，记为 UNRESOLVED，不做判定。

## 4. 三态判定与证书来源

对候选 p，在可行支持集族 ℱ_K 上：
- NECESSARY：所有 Z ∈ ℱ_K 都含 p；
- INCOMPATIBLE：所有 Z ∈ ℱ_K 都不含 p；
- POSSIBLE：其余情况。

三态针对支持 z_p；丰度范围 [L_p, U_p] 针对 x_p，由线性规划求出。两者分开报告，不把 NECESSARY 等同于 L_p > 0。

**证书来源**分三类，按由强到弱判定：
1. **证据迫使**：只用 C1、C2（K 不限、不用定量）就已 NECESSARY；
2. **定量迫使**：加上 C3（K 不限）才 NECESSARY；
3. **依赖简约**：只有加上 C4 才 NECESSARY。

另外报告 δ_break(p) = k*(禁止 p) − k*：至少要多允许几条转录本，这个「必然」才失效。

**证书与反例的命名**：
- **结构证书**（可直接验证）：某个硬观测只能唯一延伸成 p；
- **反例**（可直接验证）：两个可行解，一个含 p，一个不含 p，可逐条检查约束；
- **求解器核验证书**：整数规划返回不可行，保存模型、容差、状态，并用独立方法复核（P0b 用穷举）。不称为数学证明。

## 5. 充分观测诊断（核心）

对一个 POSSIBLE 的 p，记 ℱ⁻(p) 为 ℱ_K 中不含 p 的全部支持集。

**定义**：一组观测 O ⊆ ∪_τ Ω_τ 对 p **条件充分**，当且仅当：
1. O 中每个观测都由 p 产生（如果 p 真的存在，这些观测原则上能测到）；
2. 对每个 Z ∈ ℱ⁻(p)，O 中至少有一个观测不能由 Z 中任何路径产生；
3. 比较前后时，K 固定为原来的 k* + δ，不在加入观测后重新计算 k*，避免把「解空间重新放大」误当成信息变化。

满足这些条件后，所有剩下的可行解都含 p。这是「如果拿到这些观测，就足以确定」的条件性结论；它不保证新测序一定能产生这些观测。

**最小代价充分观测集**：在条件 1–3 下，使 Σ_o cost(o) 最小。这是一个覆盖问题：每个反例都必须被至少一个观测排除。
- 算法用反例引导的约束生成，循环到没有反例为止：
  1. 找一个 ℱ⁻(p) 中、未被当前 O 排除的反例 Z；
  2. 加入反例集；
  3. 在 p 能产生的候选观测上解最小代价覆盖；
  4. 更新 O。
- 代价可配置，不预设普遍的成本顺序；也按协议分别求解，报告每种协议是否单独充分。

**按协议的歧义类型**（对 p 和协议 τ）：
- **结构可解**：存在只用 Ω_τ 的条件充分集。用这种协议、拿到对的观测，就能确定。
- **信息受限**：存在可行的 (Z₁ ∋ p, x₁) 与 (Z₂ ∌ p, x₂)，两者的 τ 观测分布完全相同，即 B_τ x₁ 与 B_τ x₂ 归一化后相等。这时用 τ 测多深都区分不了，必须换协议。
- **采样受限**：既非结构可解，也非信息受限。单个 τ 观测排除不了所有反例，但每对竞争解的 τ 观测分布都不同，所以加深度能在统计上区分。

P0b 中「分布相同」的检验不受现有定量约束的尺度影响：两个解各自归一化为 τ 总观测量 = 1，再要求 B_τ x₁ = B_τ x₂。这是一个线性可行性问题。

## 6. 评价与基线（P0c、P1 用）

- 要和这些简单规则比：按深度、按图分支数、按最短区分子路径（v0 的做法）、按最大分支间距、SafeMFD 的安全路径。端点配对另加「按顺序配对」的生物学基线（Science 2025，PMID 41066574）。
- 诊断质量的标准：建议的观测在未参与建图的独立分子中出现后，歧义是否真的消除；同等分子预算下比最强基线多消除多少。

## 7. 计算

- 小图（P0b）：候选路径全部枚举；绝对真值用穷举得到：枚举全部支持子集，每个子集用线性规划判定可行性。
- 方法本身：混合整数规划，求解器用 scipy 自带的 HiGHS。
  - k*：最小化 Σz；
  - 三态：每个 p 解两次，分别强制 z_p = 0 和 z_p = 1；
  - 反例引导诊断：反复「找反例 → 解覆盖」；
  - 信息受限：两份变量 (z₁, x₁, z₂, x₂) 加分布相等约束。
- 真实数据：候选限制为至少出现在一个可行解中的路径；超出时间上限记为 UNRESOLVED，单独报告。

## 8. P0b 检验（全部要求 100%，事先写定）

| 编号 | 性质 | 对照 |
|---|---|---|
| B1 | 三态判定与穷举一致（δ = 0、1、2、不限） | 穷举所有支持集 |
| B2 | 每个反例的两个解都满足全部约束 | 独立复核器 |
| B3 | 宣称的充分观测集排除全部反例，且代价等于用穷举得到的全部反例直接解覆盖问题的最优代价 | 穷举反例 + 独立覆盖求解 |
| B4 | 宣称「信息受限」的两个解，τ 观测分布确实相同，且都可行 | 独立复核 |
| B5 | δ 增大时，NECESSARY 和 INCOMPATIBLE 只减不增；证书来源与定义一致（证据迫使的在任何 δ 下都必然） | 穷举 |
| B6 | 证据冲突 → INFEASIBLE_MODEL；超时 → UNRESOLVED；开放边界不强制使用；截短读段按子路径处理 | 构造案例 |

**必须包含的构造案例**：
1. 多个反例需要不同的区分观测；
2. 简约性制造假的必然（两起点、两终点，端点量 (2,1)、(2,1)）；
3. 读段对两端相容，中间有多条路径；
4. 两端连接已定，剪接链不定；
5. 某协议测多深都区分不了（例如只有端点证据时的配对，即 E1 型）；
6. 两个局部观测单独都不够，合起来才充分。
