## 0. 要回答的问题

在不知道新增分子的情况下，IDENT 能否提前选出更有价值的补测位置，使同等新增分子预算下，被独立重复验证的新增结构比简单规则更多？

**不是**要回答：「建议的观测出现后，模型内的歧义是否消除」。CEGIS 已经保证这一点，用它当主检验是自证循环。

## 2. 开工前的工程修复（ChatGPT 第 7 轮，第一步完成）

1. 正式求解接口（`Model.solve`、`info_limited`）返回前直接检查见证；检查失败记 UNRESOLVED。
2. 含 / 不含目标两次都不可行时判 UNRESOLVED，不判 NECESSARY。
3. presolve 复核计数拆成三项：误报、复核未解决、复核确认不可行。oracle 的 LP 区分 INFEASIBLE 和 UNRESOLVED。
4. 5 个 presolve 异常实例存为永久回归测试，记录 SciPy、HiGHS 版本。
5. 空候选的显式处理；路径枚举先剪掉到不了汇点的节点；位点级总时间预算（默认 10 分钟，开发集调定）。
6. 代价表和协议显式传入，不再用全局默认值。
7. **内含子链等价类判定**：类 C 为 NECESSARY，当且仅当不存在一个可行解使 C 的全部成员同时缺席。诊断时反例是「不含 C 任何成员」的可行解。
8. 开放端点的路径不能获得 full 证据。

这些修复都要在 P0b 的 617 个实例上重跑一次，确认 0 失败，才能进入第 3 步。

## 3. 分析单位与候选空间

**主分析单位：内含子链**（有序的剪接内含子序列）。理由：PacBio cDNA 读段的 5′、3′ 端不一定是真实端点，拿来当起点、终点会重犯 E1 的真值偏差。

- 次要分析：起点、终点有可信端点证据（WTC11 CAGE ctss，ont 上已有）的完整转录本。
- 开放端点的完整转录本不作精确判定；单外显子转录本不在 P0c 范围。

**图只用发现集 D 构建，之后固定**：
- 节点是 D 中质控后的内含子；内含子 i → j 的边要求有 D 读段把 i、j 作为相邻内含子同时包含（即中间的外显子被观察到）。
- 起点：至少 2 条 D 读段以该内含子为第一个内含子；终点同理。两者都是开放边界，不强制使用。
- 候选 = 起点到终点的全部路径，每个位点上限 5,000 条，超出记 UNRESOLVED。
- 观测：每条 D 读段的内含子序列是一个「子路径」硬观测。

**位点**：同链、内含子相互重叠或相邻的读段簇。

**合格的歧义位点**（在开发集定死规则）：
- D 中至少 20 条质控读段；
- 至少 2 条候选内含子链；
- 在主 δ 下至少有 1 条链为 POSSIBLE；
- 在时间预算内算完；超时的单独计数，不剔除，计入「计算可行性」分母。

**图外证据**：A 或 V 中有当前图表示不了的内含子链（新内含子、新相邻关系）时，记为 out-of-graph，单独报告比例，不丢弃，也不加入图（主分析固定图）。另做一次「允许图扩展」的安全性审计，单独报告。

## 4. 划分与预算

- **按分子随机划分 rep1**：
  - D = 20%；
  - A = 剩下的 80% 作增量池（ChatGPT 建议 40%；V 改用独立重复后，A 可以更大，模拟更多预算档）。

  随机种子固定，同一读段名只进一个集合。
- **V** = 独立重复 ENCFF388HXU（主）、ENCFF985LGZ（敏感性）。
- **预算**：新增分子总数 = D 中合格位点读段总数的 5%、10%、25%（主分析 10%）。
  - 每个策略把预算分配到位点；
  - 被分到 b 条的位点，从该位点的 A 读段中**随机**抽 b 条（不挑读段）。这模拟理想化的靶向采样：能决定在哪个位点加测，但不能决定测到哪条分子。
- 抽样重复 20 次（不同种子），报告均值和区间。

## 5. 各策略怎么分配预算

所有策略看到的都只有 D，并在读 A、V 之前冻结分配。

| 编号 | 策略 | 排除的解释 |
|---|---|---|
| R0 | 随机分配 | 基础收益 |
| R1 | 按位点 D 读段数（丰度）排序 | 纯表达量 |
| R2 | 按候选链数 / 分支数排序 | 纯复杂度 |
| R3 | 按「区分单个反例的最短观测」排序，并按其出现概率分配 | CEGIS 的全局覆盖是否必要 |
| R4 | 按歧义分支间最大距离（bp）排序 | 简单读长规则 |
| R5 | 按「最容易获得的区分观测」的出现概率排序 | 纯采样概率 |
| R6 | 按「缺全长读段支持的 POSSIBLE 链数」排序 | 是否只是在重新发现长读长 |
| **IDENT** | 每条 POSSIBLE 链的最低代价条件充分观测集 O_p，估计 b 条新分子得到 O_p 的概率，按每条分子的期望解决数贪心分配 | 完整方法 |
| 消融 a | IDENT 的全局 O_p，但不计出现概率（按代价排序） | 优势是否来自采样模型 |
| 消融 b | 计出现概率，但只用单反例区分观测 | 优势是否来自 CEGIS |

**出现概率 q_o**：只从 D 估计。
- 方法：在 D 中，该位点读段里能产生 o 的比例，加平滑。
- D 中没出现过的 o 不能设为 0，用开发集拟合的截短长度分布估计。
- 绝不用 A 或 V 估计。

**多观测集合**：O_p 中的观测是否要由同一分子产生，按观测类型处理：子路径观测互相独立，读段对、全长分子必须单分子。出现概率按 D 重抽样估计。

## 6. 主要指标与次要指标

**主要指标**：同等预算下，**新获得且被 V 独立支持的内含子链数** N。
- 「新获得」：加入 A 抽样读段后，在固定的 K 下从 POSSIBLE 变为 NECESSARY。K 固定为加入前的 k* + δ，不重新计算 k*。
- 「独立支持」：V 中至少 1 条质控读段的内含子链与之完全相同（敏感性：至少 2 条）。
- 增益 = (N_IDENT − N_最强基线) / N_最强基线，同时报告绝对差。

**按证书来源分开报告**：
- 不依赖简约（证据迫使）的新增结构；
- 依赖简约的新增结构。

**安全性指标**：
- 新获得的 NECESSARY 中，V 在该位点覆盖充足（≥ 20 条）却没有任何支持的比例（「未支持」）；
- 和 V 证据冲突的比例。

不能以更多未支持结构换取 N 的增加。

**机制性次要指标**（不作主要结论）：POSSIBLE 减少数、CEGIS 反例数、O_p 大小、模型内歧义消除率。

**全长需求的三类统计**（ChatGPT 第 7 轮）：
- 对每个 POSSIBLE 链求 C_all 与 C_nonfull（禁止 full 观测）；
- 分为全长非必要（C_nonfull = C_all）、全长有代价优势（C_nonfull 更大但有限）、全长逻辑必要（C_nonfull = ∞）；
- 另报 O_p 中最长观测在转录本坐标上的物理跨度（bp）及其占候选链剪接后长度的比例；
- 以及能用 ≤ 600 bp 片段实现的比例，作为对短读长可行性的上界估计，不当作真实短读长数据的结论。

## 7. δ 的选择（需要作者确认，见第 10 节）

**一个必须先说清的事实**：在「只用结构硬约束、不设简约上限（δ = ∞）」时，充分观测诊断会退化成简单规则。原因如下：
- 不含 p 的可行解可以包含任意多条其他链；
- 所以一组观测足以确定 p，当且仅当其中某一个观测只有 p（或 p 的等价类）能产生；
- 也就是「p 独有的最短子链」。

这时 CEGIS 的全局覆盖没有额外作用，IDENT 等于一个简单规则。

因此：
- **主分析 δ = 1**（ChatGPT 建议的「主要简约辅助」）。CEGIS 的全局覆盖只在有简约上限或定量约束时才起作用。
- **δ = ∞** 作最保守的对照：此时 IDENT 与「独有最短子链」规则相同，单列为基线 R7，用来说明「简约上限带来的收益是多少、代价是多少」。
- δ = 0、2 作敏感性。
- 门槛要求：优势不能只来自 δ = 0；δ = 1 下的新增结构中，依赖简约的那部分的「未支持」比例不能明显高于证据迫使的部分。

**定量约束**：主分析不用（只用结构硬约束）。同文库定量（D 内读段计数）作次要分析；跨协议定量留到 P1。这意味着 P0c 主要检验结构观测诊断，不检验「可定量区分」的预测价值，这一点在结论里写明。

## 8. 门槛（开发集先检查规模和功效，再冻结；不过就停，不降门槛）

**开发集**：chr16、chr22（已有 rep1 子集），用于定质控规则、合格位点规则、时间预算、q_o 平滑、预算换算。**测试集**：其余常染色体。开发结束时写 FROZEN（规则、代码哈希、随机种子），交作者确认后才读测试集结果。

| 指标 | 继续条件 |
|---|---|
| 规模 | 测试集 ≥ 100 个合格歧义位点（若开发集外推不到 100，先回作者） |
| 计算可行性 | ≥ 80% 的合格位点在时间预算内算完；报告图外、INFEASIBLE_MODEL、UNRESOLVED 比例 |
| 非平凡诊断 | ≥ 20% 的位点存在非全长充分方案，且其中每个观测的物理跨度 ≤ 该链剪接后长度的 80% |
| 主要效应 | 10% 预算下，IDENT 的 N 比最强基线（R0–R7 中最高者）多 ≥ 20%，且绝对差 ≥ 10 条；按位点做 1 Mb 区块配对 bootstrap（2,000 次），95% CI 下限 > 0 |
| CEGIS 必要性 | IDENT 显著优于消融 b 和 R3（配对 CI 下限 > 0） |
| 安全性 | IDENT 新增结构的「未支持」比例不高于最强基线 + 5 个百分点 |
| 简约依赖 | δ = 1 下的优势不完全来自依赖简约的结构；证据迫使部分单独报告 |

**停止条件**（任一出现就停，不扩大样本挽救）：
- 考虑真实长度后，非全长诊断几乎消失（< 20%）；
- CEGIS 与单反例规则（R3、消融 b）收益相当；
- 优势能被丰度或出现概率（R1、R5、消融 a）完全解释；
- 只增加模型内部的 NECESSARY，不增加 V 支持的结构；
- 只有事后挑选分子的 oracle 策略有效（另做 oracle 上界，单独报告，不参与判定）。

只是合格位点不够或计算超限时，判为「证据不足」，回作者决定，不说「没有科学信号」。

## 9. 能证明什么、不能证明什么

- 能：在现有 PacBio 分子的理想化靶向追加实验中，结构歧义诊断是否比简单规则选出更多被独立重复支持的结构。
- 不能：真实短读长、CAGE、TIF-seq 文库上的效果；实际测序成本或 capture 的收益；「可定量区分」的预测价值。这些留给 P1。
