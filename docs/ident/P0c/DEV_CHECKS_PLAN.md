# P0c 开发集三项检查：判定标准（运行前写定，2026-11-24）

> 作者 2026-11-24：「Yes, run dev checks」。依据：ChatGPT 第 8 轮（`10_AUTH/discussion_20261124/ROUND8_ChatGPT_P0c_plan.md`）。
> 范围：只用开发染色体 chr16、chr22；ont 已有数据；不下载（ENCODE 元数据查询除外）；nice 19。
> 用途：决定是否值得写 P0c 计划 v1 并冻结测试。任何一项明显不过，就在冻结前停下，回作者。这里的结果不是 P0c 的正式结果。

## 共同设置

- **数据划分**：rep1（ENCFF373TKM）按读段名哈希分成 D 20% / A 80%；V = ENCFF388HXU。
- **读段质控**：主比对；MAPQ ≥ 30；两端软剪切 ≤ 30 nt；内含子长度 ≥ 50 bp；按 hg38 序列判定剪接基序，必须是经典基序（GT-AG、GC-AG、AT-AC）。
- **内含子准入**：D 中至少 2 条质控读段支持。含有未准入内含子的 D 读段整条去掉，并记录比例。
- **位点**：同链、内含子区间相互重叠的读段做连通分量。
- **G-strict 图**：节点为准入内含子；i → j 要求某条 D 读段中两者相邻。
- **G-expanded 图**：另允许 i → j，条件是 i 的受体位点在 j 的供体位点之前，且有 D 读段的连续比对块完整覆盖两者之间的外显子区间。
- **边界**：开放边界。起点 = 至少 1 条 D 读段的第一个内含子；终点 = 至少 1 条 D 读段的最后一个内含子。都不强制使用。
- **观测**：每条 D 读段的内含子序列是一个子路径硬观测。
- **候选**：每个位点枚举起点到终点的全部路径，上限 5,000；位点总时间预算 300 秒，超出记 UNRESOLVED。
- **合格歧义位点**：D 质控读段 ≥ 20，候选 ≥ 2。定义在求解前，超时、超上限的位点也计入分母。

## 检查 2：剩余歧义还剩多少

报告（G-strict 和 G-expanded 分别报告）：
- 合格位点数、算完比例；
- 每个位点在 δ = ∞ 与 δ = 1 下的 POSSIBLE 数；
- 嵌套链比例（候选是另一候选的严格连续子链）；
- 非嵌套（最大）POSSIBLE 链所在位点数；
- G-strict 下 δ = 1 时为 NECESSARY、但在 G-expanded 下变成 POSSIBLE 的比例。

**通过**（两条都满足）：
- 两条染色体合计，在 G-strict、δ = 1 下至少有 1 条**非嵌套** POSSIBLE 链的合格位点 ≥ 30 个。按染色体数比例外推，全基因组可望 ≥ 100。
- 算完比例 ≥ 80%。

## 检查 1：出现概率 q_o 能否预测新观测

- **对象**：G-strict、δ = 1 下每条非嵌套 POSSIBLE 链 p，其最低代价充分观测集 O_p（只用长读段子路径观测）。
- **模型**：q_o = Σ_p π_p · P(o | p)。P(o | p) 用截短模型：读段覆盖 p 上连续的一段内含子，覆盖长度分布从 D 估计（按候选链内含子数分层），起点均匀。π_p 比较三种：
  - Q0：位点内候选均匀；
  - Q1：每条 D 读段平均分给与之相容的候选；
  - Q2：在截短模型下用 EM 估计混合比例（只用 D）。
- **结果变量**：每个位点从 A 随机抽 b 条读段（b = 该位点 D 读段数的 10%，至少 1；重复 5 次）；看每个 o ∈ O_p 是否至少出现一次，以及「O_p 全部出现」。
- **评价**：
  - 观测层面：预测概率 1 − (1 − q_o)^b 的 Brier score；以 Q0 为参照的 Brier 技巧分；AUC。
  - 链层面：用整条分子模拟得到的「O_p 全部出现」的概率，与实际是否全部出现比较。

**通过**（全部满足）：
- Q1 或 Q2 在观测层面的 Brier 技巧分 > 0（相对 Q0），且 bootstrap 95% CI 下限 > 0（按位点重抽样）。
- 同一模型的观测层面 AUC ≥ 0.70。
- 至少有 50 个 (p, o) 对可评价。

## 检查 3：同文库定量能否带来不靠简约的识别增益

- **定量证据**：每个准入内含子在 D 中的读段覆盖数 y_i。模型期望 = Σ_{p∋i} x_p。容差：相对 30%，绝对 2。这是粗略的流量模型，不含位置偏差。
- **比较**：δ = ∞（不靠简约）下，「只用结构」与「结构 + 定量」的 NECESSARY 链数。
  - 新增的 NECESSARY 记为「定量迫使」；
  - 定量下模型无解的位点（INFEASIBLE_MODEL）单独计数。
- **验证**：V 中有完全相同内含子链读段（≥ 1 条）的比例。比较对象：定量迫使的、证据迫使的（结构下已 NECESSARY）、δ = 1 简约迫使的（结构下 δ = 1 才 NECESSARY）。

**通过**（全部满足）：
- 定量迫使的新增 NECESSARY 链 ≥ 20 条（两条染色体合计）；
- 它们的 V 支持率不低于简约迫使链的 V 支持率；
- 定量导致的 INFEASIBLE_MODEL 位点 ≤ 20%。

## 结果的读法

| 结果 | 含义 |
|---|---|
| 三项都过 | 写 P0c 计划 v1 并冻结，进测试集 |
| 检查 2 不过 | 剩余歧义太少，IDENT 在真实数据上没有用武之地 → 回作者，建议停 |
| 检查 1 不过 | 无法预测新观测，P0c 的分配实验无法公平进行 → 回作者，建议停或改问题 |
| 检查 3 不过、1 和 2 过 | 只剩简约辅助一条路；按 ChatGPT 估计，一区概率约 25–30% → 回作者决定 |
