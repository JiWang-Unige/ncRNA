# IDENT 计划：lncRNA 转录结构在什么证据、什么预算下能被确定（草案，2026-11-24，待作者批准）

> 来源：11-23 三方讨论的方向「转录本可识别性」（Gemini 第 1、ChatGPT 第 3）与「注释发现累积曲线」（ChatGPT 第 2）合并，加上 AUTH / v1 / E1 的结果作为第一部分。作者 2026-11-24：目标 JCR 一区，「写合并计划」。
> 状态：草案。批准前不下载、不计算。
> 范围：ont CPU 为主；需要下载 LRGASP 公开数据（第 3 节，分批，先只下 WTC11）；不训练深度模型。

## 1. 要回答的问题

做 lncRNA 注释，真正的瓶颈不是「这里有没有转录」，而是「转录单位长什么样」：从哪开始、在哪结束、怎么剪接。AUTH 和 E1 已经说明，分开测的起点、终点证据能检出转录，但定不了配对。

本计划要系统回答：
1. **可识别性**：在每种证据组合下（端点证据、短读长、不同深度的长读长，以及它们的组合），有多少 lncRNA 转录结构能被**唯一确定**？和编码基因比差多少？差在哪里（起点、终点、剪接，还是配对）？
2. **累积与外推**：随测序深度和方案增加，可确定的结构怎样增长？能否从浅测序的数据可靠地预测深测序的收益？
3. **怎么用**：给定一个样本的现有数据，报告哪些结构已经确定、哪些还不能，以及还缺哪类证据；给定预算，该把钱花在哪种测序上。

## 2. 为什么这有一区的分量

- **问题完整**：「问题（定不了结构）→ 原因（哪类信息缺失）→ 解决方案（缺什么补什么、预算怎么花）→ 别人怎么用（工具和建议）」，不只是一个「做不到」的发现。
- **范围够广**：4 个 LRGASP 样本（人 WTC11、H1、H1 定形内胚层，加小鼠 ES），每个都有短读长和多种长读长平台（PacBio cDNA、ONT cDNA、ONT 直接 RNA、CapTrap 等），可以检验结论是否跨样本、跨物种、跨平台。
- **有可复用产出**：一个可识别性报告工具，加上一个预测测序收益的模型。
- **已有工作**（Phase 0 用文献检索逐一核实，再定新意的写法）：
  - 剪接图上的「安全路径」：Safe&Comp / SafeMFD 一类，回答的是给定剪接图哪些路径必然存在；
  - 文库复杂度外推：preseq，以及 Good–Toulmin 估计；
  - LRGASP（Nature Methods 2024）：比较了平台与工具，但没有按「结构是否可唯一确定」来分解；
  - GENCODE CLS 定向长读长测序：Kaur 等，PMC11565817；
  - TIF-seq / TIF-Seq2：同一分子的两端；Bookend：端点引导组装。
- **可能的新意**：把「可识别性」从剪接图理论变成跨证据类型、跨深度、可预测的经验量；专门量化 lncRNA 与编码基因的差距；给出预算建议。这些都要在 Phase 0 的文献核实后才能定。

## 4. 定义（Phase 1 开始前写定，之后不改）

- **参考结构集**：同一样本在全深度下，至少两种长读长平台都观察到的转录结构。结构 = 内含子链 + 起点簇 + 终点簇，端点按 ±50 bp 聚类。按 GENCODE 类别和 TALON 新颖性分 lncRNA / 编码 / 其他。若 LRGASP 文库含 SIRV 外加 RNA，另用 SIRV 作绝对真值（待核实）。
- **证据组合**：
  - R1 端点：CAGE + 3′ 端测序（WTC11、H1）；
  - R2 短读长：剪接位点和覆盖度；
  - R3 短读长 + 端点；
  - R4(d) 长读长：单一平台，深度为全量的 d（1%、2%、5%、10%、25%、50%、100%，每档下采样 3 次）；
  - R5(d) 短读长 + 深度 d 的长读长。
- **「确定」的判定**（每个参考结构、每种组合）：
  - 剪接：每个内含子都被观察到，且结构的内含子链在该证据下的剪接图里是唯一相容路径（安全路径），即没有另一条参考结构能产生同样的观察；
  - 起点和终点：被端点证据或长读长观察到，并且和这条内含子链的配对是唯一的。E1 证明，只有分开测的端点时，配对一般不唯一；
  - 长读长：至少 2 条全长读段与这条结构完全一致。
  - 只满足一部分的，记录缺的是哪一类（剪接、起点、终点、配对），这正是「还缺什么证据」的来源。

## 8. 风险

- **新意**：剪接图可识别性理论和长读长基准都已有人做过，新意要靠「跨证据、按深度、可预测、专门针对 lncRNA」这几点。P0 文献核实不过就停。
- **参考集偏差**：参考结构来自长读长本身，偏向高表达；可确定比例的绝对值依赖参考集定义。对策是多平台交叉支持、在 SIRV 上验证，按表达分层报告。
- **结果平凡**：如果 lncRNA 和编码基因差别不大，或者短读长几乎全定 / 全不定，故事撑不起来。P1 的门槛就是为此设的。
- **跨样本不一致**：只有 1–2 个样本支持的规律，只能写成个例。
- **工作量**：比 AUTH 大一个量级；每个阶段都可以停。
