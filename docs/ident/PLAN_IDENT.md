## 1. 要解决的问题

转录本组装器只输出一套结构，不告诉你哪些是数据**逼出来的**、哪些只是**猜的**。lncRNA 证据稀、表达低，这个问题最严重。E1 已经说明：只有分开测的两端时，模型选的配对不比「取最强终点」更好。

本研究要给出一个方法：对每个候选转录结构，在给定证据下回答三件事：
1. **状态**：
   - 必然存在：所有能解释数据的方案里都有它；
   - 可能存在：只在部分方案里有它；
   - 不相容：没有任何方案包含它。
   并给出丰度的上下界。
2. **证书或反例**：
   - 必然存在的，给出可核查的理由，即哪些观测迫使它存在；
   - 只是可能存在的，给出一个同样能解释全部数据、但不含它（或含另一结构）的替代方案。
3. **缺什么证据**：要消除这个歧义，需要哪一类新观测。例如：
   - 跨某两个分支的读段；
   - 同一分子的两端连接；
   - 跨多个剪接事件的长读段；
   - 只是更多分子。

应用（方向 B）：给定浅测序数据，预测哪类新增测序能消除最多歧义，用来指导测序设计。

|---|---|---|
| Bioinformatics 2009 / 2022 isoform 可识别性 | 给定候选转录本集合和短读长参数，判断能否唯一解；比较了编码与 lncRNA；建库片段长度建议 | 不依赖给定候选集；转录本级三态 + 反例 + 缺失证据诊断；纳入端点与长读长约束 |

| Scallop / Scallop2 | 用同一分子的多段读段（相位）消除组装歧义 | 显式报告剩余歧义和原因，而不是只输出一套最优解 |
| Bookend（Genome Biol 2022） | 端点引导的组装 | 同上 |
| IsoTools（2023）、preseq | 发现饱和与所需深度 | 预测的是「哪类证据能消除哪种歧义」，不是发现数 |
| SQANTI3、Bambu | 转录本质控与置信度过滤 | 结构性理由与反例，而不是打分 |

## 3. 模型（Phase 0a 写成严格定义）

- **图**：剪接图只用输入证据构建，包括起点集、终点集、外显子片段、剪接边。不使用任何评价用的目录或平台，以免循环。
- **观测约束**：
  - 每条观测到的剪接边、短读段对或长读段子路径，都必须被某条转录本覆盖；
  - 起点、终点证据限定路径的端点；
  - 可选的覆盖度约束：流守恒，允许误差 ε。
- **可行解**：满足全部约束的转录本集合，规模受简约性限制（转录本数 ≤ 最小值 + δ；δ = 0 为主，δ = 1、2 作敏感性）。没有简约性约束时几乎什么都「可能」，这一点要明确写出。
- **判定**：
  - 必然：在所有可行解中；
  - 可能：在部分可行解中；
  - 不相容：在任何可行解中都不出现。
  - 丰度上下界 L、U 由线性规划求出。
- **计算**：小图穷举；大图用整数线性规划（scipy 自带的 HiGHS 求解器，ont 上已有，不装新包）或流分解算法。指数爆炸的图记为「超出计算范围」，单独报告，不硬算。
- **结构粒度**分开报告：内含子链、带端点的完整结构、单外显子转录本。端点聚类：起点、终点分别定义，用最大簇直径避免链式合并；主分析事先固定一个窗口，另报告 10–200 bp 的敏感性。

**对照**：
- 至少 2 条全长读段的规则；
- IsoQuant / StringTie 组装；
- Bambu 的置信度；
- SQANTI3 分类；
- SafeMFD 安全路径（同一输入、同一粒度）。

**lncRNA 与编码基因的比较**逐层控制混杂：
1. 原始差异；
2. 控制表达量；
3. 再控制长度、外显子数；
4. 再控制剪接图复杂度和异构体数。

不预设方向。

## 8. 风险

- **新意**：安全路径一系文献离我们很近，P0a 必须找到清楚的差异，找不到就停。
- **算法**：可行解空间可能指数爆炸，需要好的约束和简约性设定；简约性本身是假设，结论都是「在该模型下」。
- **证据噪声**：截短读段、内部引物、模板转换会产生假约束；需要误差容忍，SIRV 和留一平台用来检验。
- **实用价值**：如果大多数 lncRNA 都只是「可能」，工具输出要能告诉用户补什么证据，否则审稿人会说「只是把不确定说出来」。P2 的证据增量就是为此设的。
