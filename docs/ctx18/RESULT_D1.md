## 读法
1. 「同一 lncRNA 在不同细胞类型里核富集不同」的信号确实存在且远超抽样噪声，但**蛋白编码对照同样很高**（交互占比 68.9% vs lncRNA 57.6%）。这说明交互的大部分不是 lncRNA 特有的生物学，很可能是两种测量各自的解离 / 制备批次按组织不同造成的（协议 §5 已预写）。
2. 能预测的那一点（r ≈ 0.15–0.16）主要来自「相似上下文的偏离也相似」（M1）或每个基因自己的反应（M4），序列特征没有带来增益（M2 / M3 r ≈ 0.07–0.08）；R² 为负说明幅度预测不稳。
3. 与 D0（ENCODE 13 个细胞系）结论一致：信号存在，不可由序列 + 细胞状态预测。两套独立数据给出同一答案，D 方向到此为止。
