# PROTOCOL_D1：Tabula Sapiens total-RNA 上的 lncRNA 核富集 基因 × 上下文 交互预研（2026-11-25）

作者 2026-11-25「按你建议推进」。本协议在读取任何定位统计量之前冻结。此前只看了元数据：obs / var 字段、各上下文的细胞数、生物类型计数。

## 1. 数据
- `TSP33_total_RNA.h5ad`：figshare 10.6084/m9.figshare.31827436，CC BY 4.0，md5 3710aa3f…，21.2 GB，存在 ont `~/ncrna-annot/data/ctx18/ts_total/`。
- 单一供体，Smart-seq-total 类 total-RNA；`method` 分为 Cells / Nuclei，使用 `raw_counts` 层和 `cell_type`。
- 上下文 c = (tissue, cell_type)，要求 Cells ≥ 50 且 Nuclei ≥ 50 个细胞：共 73 个上下文，11 个组织，36 个细胞类型（元数据已数过）。
- 外部对照：D0 的 ENCODE 核 / 质数据，13 个细胞系。

## 2. 标签
- 每个上下文、每种测量方式做伪 bulk（原始计数求和）→ CPM。
- y_{g,c} = log2((CPM_nuc + 1) / (CPM_cell + 1))，即核富集。
- 观测条件：(CPM_nuc + CPM_cell) / 2 ≥ 2。
- 基因纳入：var.biotype 为 lncRNA（主分析）或 protein_coding（对照），且在 ≥ 15 个上下文中观测到。
- 抽样噪声：在每个上下文里对细胞和细胞核分别有放回重抽 50 次 → 得到每个 (g, c) 的 y 方差；噪声方差取其平均。
  - 这只覆盖抽样噪声，不覆盖批次和解离效应；单一供体也无法估计供体噪声。

## 3. 门槛
- **G0 标签有效性**：lncRNA 的基因主效应 μ_g（TS）与 ENCODE 基因均值 log2(nuc / cyto)（13 个细胞系平均，两者共同基因）的 Spearman ≥ 0.30。不过 → 标签不可信，停。
- **G1 交互存在**：做与 D0 相同的两向分解（μ_g + α_c + δ）。
  - 真实交互方差 = var(δ̂) − 平均抽样噪声方差；
  - 基因块 bootstrap（2000 次）95% CI 下限 > 0，且占「去掉 μ_g 后方差」的比例 ≥ 20%。不过 → 停 D。
- **G2 交互可预测（主门槛）**：留一组织外（11 折），预测 δ。
  - 各折中，μ_g 只用训练上下文估计；测试上下文的 α_c 用测试标签的中位数，与 D0 相同（只吸收主效应）。
  - 模型：
    - M0：零。
    - M1：最近 3 个训练上下文（按上下文 PC 距离反加权），取其 δ 的平均。
    - M2：双线性 ridge，基因特征 ⊗ 上下文 PC，α 用内层留组织交叉验证选。
    - M3：两塔 MLP，基因塔与上下文塔各输出 32 维，点积加偏置；固定 300 个 epoch，Adam 1e-3，weight decay 1e-4。
    - M4：基因特异的反应规范，每个基因对上下文 PC 做 ridge（α = 10），不用序列。
  - 上下文特征：只用 Cells 伪 bulk 的蛋白编码基因 log CPM（不含任何 lncRNA，防止目标泄漏）→ 在训练上下文上拟合 PCA，取 10 个 PC。
  - 基因特征：`e1_features` 的 b_ / s_ 列（与 D0 相同），PCA 20 维，再加训练集 μ_g 和平均表达。
  - **通过**：M2 / M3 / M4 中最佳者满足
    - 各留出组织 Pearson 的中位数 ≥ 0.20；
    - 合并交互 R² 比 max(0, M1) 至少高 0.05；
    - 该增益的基因块 bootstrap CI 下限 > 0。
  - 判停：最佳中位 r < 0.10 → 停 D，不再加复杂度。0.10–0.20 为灰区，只报告，不申请扩大。
  - 诊断（不进门槛）：最佳模型改用打乱后的上下文特征（在训练上下文间置换），R² 应 ≤ 0.01。
- **G3 对新基因可迁移（决定是不是「方法」）**：留组织外 × 留基因外（基因按 5 折分组），只评 M2 / M3（M4 无法用于新基因）。
  - 合并交互 R² > 0，且基因块 CI 下限 > 0。

## 4. 决策
- G0 或 G1 不过：停 D。
- G2 不过：停 D。
- G2 过、G3 不过：交互可由细胞状态预测，但只对已见过的基因成立，属描述或资源层面，不是序列方法；交作者决定。
- G2 + G3 都过：D 立项，写 D-full 计划（加 lncATLAS / APEX / Halo 外部验证，以及测量方式感知的观测层）。

## 5. 已知偏差（写在前面）
- 全细胞和细胞核来自不同的解离 / 制备批次。批次造成的「基因 × 组织」偏差会抬高 G1；但它在留组织外时不可预测，只会压低 G2，不会造成假阳性。
- 单一供体：79 个细胞类型不是独立的生物学重复。
- 细胞核里内含子读段比例更高。若 count 方式对两种测量不同，会产生基因特异的偏差；这部分大多被 μ_g 吸收。
- 结果只读一次；代码在运行前冻结（sha256 记在本文件末尾的 `.sha256`）。
