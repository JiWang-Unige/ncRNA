## 我的判断
1. **Q1（序列 + 上下文）**：同意 ChatGPT。「序列 + 细胞状态 → 表达」已被 AG2 / Decima 做掉；我们再做就是跟跑。
   - 唯一与我们已有工作直接相连的是「条件化先验 + 廉价证据」：WTC11 有 ssCAGE + QuantSeq + PacBio 真值，M1 的打分框架现成，用 AG2 以 WTC11 单细胞谱作条件，看能否多定位真值 lncRNA。
   - 成本 1–2 天，但需要作者注册 AG2 API（创建账号需作者本人做）。
   - 我对它的预期偏低：上次无条件先验是 0 增益，而 AG2 的强项是覆盖，不是端点配对。
   - 「从头生成转录本对象」碰到的正是 IDENT 里已经证明的端点配对不可辨识问题，不建议再碰。
2. **D（上下文定位）**：同意它排第一，但有两个 ChatGPT 低估的风险。
   - TS total-RNA 是单一供体，「留组织外」时组织和供体无法分开；不过供体只有一个，反而没有供体混杂。
   - 「单细胞 vs 单核」的比例混有核分离和捕获偏差。D0 的同类风险是批次和细胞系混杂，这次是测量方式混杂；所以必须对 ENCODE 分级分离或 MERFISH 做外部方向一致性检验。
   - 新意边界：BiGM-lncLoc 已做「细胞系特异定位分类」。我们的区别必须是「预测交互项、留上下文外、排除目标泄漏、多种测量联合建模」，D0 已经证明这个交互项真实存在。
   - 预研成本：下载 21 GB 处理后数据，单机 1–2 天。
3. **B（结构变化）**：作者「应该有别的公开数据」的直觉部分成立。
   - GSE236224 有真正的生物学重复和发育对比，原始数据只有 12.5 GB，比 Sun 2019 的 94 GB 便宜得多；
   - 但它是 DMS（只探测 A/C），lncRNA 覆盖未知，处理后文件很小，覆盖可能很窄。
   - 先下 5 MB 处理后文件，数一数有多少 lncRNA 有反应性；不到 100 个就停 B。
   - 巨噬细胞数据 267 GB 且无对照，暂不考虑。
