Context: this is a continuation of our ncRNA methods project (repository JiWang-Unige/ncRNA, folders 08_M1, 16_new_methods_20261124, 17_context_pilot). Please do a deep research pass and then give your own critical judgement on three linked questions. The goal of the author is NOT a particular annotation pipeline; it is a genuinely new model/method that helps the field study lncRNAs and other ncRNAs, and that can carry a JCR Q1 paper. Be blunt where an idea is already done or not worth doing.

What we already found (short):
- DNA-only lncRNA annotation: a sequence model's prior added nothing over cheap experimental evidence (WTC11 ssCAGE + QuantSeq endpoint rule reached S50 recall 0.436 alone; adding our DNA-only posterior gained zero loci). We stopped DNA-only.
- Pilot D0 (ENCODE nuclear/cytosolic polyA+ RNA-seq, 13 cell lines, 1,243 lncRNAs): gene x cell-line interaction in localisation (log2 cyto/nuc) is real (noise-corrected interaction variance 0.60, 44% of variance beyond the gene mean; protein-coding genes show the same), but NOT predictable from cell-line RBP expression + gene features (leave-one-cell-line-out median r 0.03-0.16, interaction R^2 negative).
- Pilot B0-lite (icSHAPE, Sun et al. NSMB 2019, GSE117840, HEK293 and mES; chromatin/nucleoplasm/cytoplasm, in vitro/in vivo): predicting compartment change in reactivity, delta r = r_target - r_ref, from local sequence + reference reactivity: gradient boosting Pearson 0.537 vs reference-only 0.426 (+0.11, gene-block bootstrap CI 0.104-0.117), consistent in mouse (+0.10). BUT (i) only 16-39 lncRNA genes are covered in both compartments, and (ii) post-hoc ablation shows the gain comes from the +-12 nt sequence window, which may be reference-noise shrinkage or NAI/RT chemistry bias, not biology. Processed files merge replicates, so we cannot test this without ~94 GB of raw reads from a single study.

The author's new ideas (please evaluate each):

Q1. Context-conditioned ncRNA modelling instead of DNA-only. Input = DNA sequence PLUS a description of the cellular context (cell type / state / environment, e.g. a single-cell expression profile or chromatin state), output = which lncRNA/ncRNA transcripts exist and how they behave in that context. lncRNAs are highly context-specific, so a context-free DNA prior may be the wrong question.
  - AlphaGenome 2 (Gayoso, ..., Avsec; bioRxiv 10.64898/2026.11.11.765857, Nov 2026) now does "1 Mb DNA + condition embedding (ontology dictionary or a scVI-like encoder of a few dozen cells) -> stranded CAGE/RNA-seq coverage, splicing, gene-level TPM (GENCODE v46 incl. lncRNA genes), chromatin, methylation", with few-shot adaptation to new cell states. Please read it.
  - Given AG2 (and Borzoi, Enformer-Celltyping, scooby, Decima, Flashzoi, any single-cell conditioned sequence models), what is still open for ncRNA specifically? Candidate gaps to check: (a) how well AG2-class models predict lncRNA (low-expression, cell-type-restricted, antisense, unannotated) vs mRNA — has anyone benchmarked this?; (b) context-conditioned prediction of transcript STRUCTURE (TSS-TES pairing, isoforms, novel unannotated lncRNAs) rather than coverage; (c) using such models as priors combined with cheap context-specific evidence (our earlier finding was that a context-free prior added nothing — would a context-conditioned prior change that?); (d) mouse/other species; (e) small ncRNAs.
  - Which one, if any, is a defensible new method rather than a benchmark of AG2? What is the minimal decisive pilot (data, metric, gate) that we can run on one RTX 4090 + 32 cores, using AG2 via its API (non-commercial) where useful?

Q2. Direction D (context-specific lncRNA localisation). AG2 addresses transcription per cell type, not post-transcriptional fate. Should D be reframed as "AG2-style condition-conditioned model for RNA localisation / nuclear retention / stability"? Specifically:
  - Which public data give localisation (nuclear vs cytoplasmic or finer) across MANY cell types/states, enough to learn a condition embedding: e.g. ENCODE fractionation (all phases), lncATLAS, paired snRNA-seq vs scRNA-seq, spliced/unspliced ratios, APEX-seq, CeFra-seq, Halo-seq, imaging-based (MERFISH/seqFISH/Xenium nuclear fraction per cell type), subcellular spatial transcriptomics, metabolic labelling (SLAM-seq) for stability? Give accession numbers, number of cell types, replicates, lncRNA coverage.
  - Our D0 failure might be due to only 13 cell lines and RBP mRNA as context. Is there a design with tens-hundreds of contexts where the condition-transfer question becomes learnable? Is anyone already doing it (e.g. RNA-fate foundation models 2025-2026)?

Q3. Direction B (compartment- or context-specific RNA structure). The author believes more public data must exist beyond Sun et al. 2019. Please systematically list in vivo / in-cell RNA structure-probing datasets (icSHAPE, SHAPE-MaP, DMS-MaPseq, smartSHAPE, PARIS/SPLASH/COMRADES duplex maps, nanopore-based probing such as nanoSHAPE/SMS, RIC-seq) that have: (i) more than one cellular context (compartment, cell type, stress, differentiation, drug), (ii) biological replicates available at raw-read level, (iii) meaningful lncRNA coverage (state how many lncRNA genes or which lncRNAs). Include databases (RASP, RMDB, RNA Atlas of Structure Probing, etc.). For each: accession, contexts, probe, replicates, lncRNA coverage, raw data size if known.
  - Then judge: with the best available data, is "predict context-induced structure change of lncRNAs" a viable new method, or does chemistry/RT bias and low lncRNA coverage make it a dead end? What replicate-based gate would separate real change from artefact?

Finally: rank the options (Q1 sub-options, reframed D, B, or something better you find), with for each: novelty vs closest 2025-2026 work (with PMIDs/DOIs), feasibility on our compute, decisive pilot, and probability it supports a Q1-journal ncRNA methods paper. Please cite every dataset and paper with an accession/DOI/PMID so we can verify; mark anything you are unsure about.
