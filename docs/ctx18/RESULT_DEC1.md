# RESULT_DEC1：Decima 自身数据上的 lncRNA 盲区诊断（2026-11-25，只读一次）

- 协议 `PROTOCOL_DEC1.md`（含偏离 1、2，最终 sha256 c3e6d859…），脚本 `scripts/dec1.py`（e3317cb6…），冻结提交 a7dc60b。输出 `DEC1.json`。
- 指标是作者给出的每基因 Pearson（Decima 预测 vs 实测，跨 8,856 个伪 bulk）。实测矩阵不公开，变异度只能用轨道数间接控制（偏离 2）。

## 结果（test 基因：lncRNA 203，蛋白编码 1,607）
| 项 | test | val（复核） |
|---|---|---|
| 中位 r：lncRNA / 蛋白编码 | 0.420 / 0.615 | 0.488 / 0.637 |
| H1 原始差距（pc − lnc） | 0.194（CI 0.130–0.232） | 0.150 |
| 中位表达 mean_counts：lnc / pc | 0.38 / 2.26 | 0.48 / 2.22 |
| **H2 校正后 is_lnc 系数** | **+0.070（CI +0.039 至 +0.100）** | +0.062 |
| 敏感性（加预测 SD） | +0.085 | +0.077 |

- 表达十分位内配对：lncRNA 与蛋白编码基本持平，中等表达段 lncRNA 反而更高（如第 3–4 十分位 0.75–0.81 vs 0.65–0.66）。
- **H2 判定：不过**。系数为正，方向与「盲区」相反。
- H3 覆盖：Decima 只纳入 GENCODE lncRNA 的 **11.6%**（2,084 / ~18,039），蛋白编码 81.7%。
- 探索：基因间 lncRNA 的中位 r 最低（test 0.374），反义重叠的最高（0.493），但基因间的表达也最低（0.24），未校正。

## 读法
- 在 Decima 自己的（主要是 poly(A)）数据上，lncRNA 预测差 **完全由表达低解释**；同等表达下 Decima 对 lncRNA 不差，甚至略好。
- 「Decima 对 lncRNA 有特有盲区」在这个层面不成立。
- 仍然开放的两点交给 DEC2：
  1. 表外 89% 的 lncRNA（Decima 根本没训练、没评估）；
  2. total-RNA 测量下（非 poly(A)、核内 RNA）的表现。
