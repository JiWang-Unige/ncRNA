## 总判断（意译）
不要做「lncRNA 版 AlphaGenome」，这件事已经来了；也不要做通用的「上下文条件化 isoform 或 lncRNA 定位分类器」。最强的剩余机会是：**测量方式感知（assay-aware）的、上下文依赖的 ncRNA 命运交互模型**，尤其是核滞留 / 定位；目标明确设为 基因 × 上下文 偏离，而不是基因的静态定位倾向。B 不宜作主线，除非先过严格的重复 / 噪声门槛。

## Q1：序列 + 上下文
- AG2、Borzoi（10.1038/s41588-024-02053-6）、Enformer Celltyping（PMID 39550354）、scooby（PMID 39345504）、Decima（10.1038/s41592-026-03102-0，2,200 万细胞）已占据「序列 + 细胞状态 → 表达 / 覆盖」。
- AG2 API 条款：直接输出不得用于训练机器学习模型；每次条件化最多 256 个细胞；适合几千次而不是几百万次预测。
- 未找到按 lncRNA / 低表达 / 细胞特异 / 反义 / 未注释 分层的 AG2 评估 → 可做诊断，但单独的基准不是方法论文。必须做「目标基因屏蔽」的条件化，否则条件谱里含目标 lncRNA 本身，会泄漏。
- 上下文 isoform 已拥挤：HELIX（10.1038/s43588-026-00988-w）、Otari（10.1016/j.xgen.2025.101126，含 lncRNA）、IsoPrism（PMID 42969855）、Mach-1（10.1101/2024.08.26.609813）。剩下的窄口子：DNA + 上下文 → 从头生成未注释转录本对象（TSS + 剪接链 + TES），高风险。
- 条件化先验 + 廉价证据融合：值得一次小的证伪实验（AG2 只作冻结先验，不作教师标签）。门槛：固定召回下精度相对提升 ≥10%，或固定 FDR 下召回 +0.05，且在弱证据位点上有增益；否则立即停。
- 小鼠单独不是新意；小 ncRNA 更开放，但等于新课题。

## Q2：方向 D
- 直接定位数据都是少数背景：lncATLAS（15 个细胞系，PMID 28386015）、CeFra-seq（K562，GSE88622）、APEX-seq（HEK293T，GSE116008）、Halo-seq（GSE172281，PMID 34875090）、MERFISH（PMID 31501331）、scRLP（PMID 42051298，预印本）。
- 关键新资源：Tabula Sapiens total-RNA（PMID 41929159），22 个组织，27 个全细胞 + 21 个细胞核样本，11 个组织两种都测，79 个细胞类型；计数在 figshare 10.6084/m9.figshare.31827436。它是弱标签（sc 对 sn 比例，不是分级分离），且基本是单一供体。
- 新意警告：BiGM-lncLoc（PMID 39724386）已做「细胞系特异的 lncRNA 定位」分类（用细胞系表达），所以朴素版本不新。
- 建议的方法：潜变量 L_{g,c}，每种测量（分级分离 / 邻近标记 / 成像 / sc-sn 比）各有观测层；只预测 L_{g,c} − 基因均值；上下文嵌入只用蛋白编码基因，排除目标 RNA。
- 预研门槛：留组织外，交互 r ≥ 0.20–0.25、交互 R² > 0.05（CI > 0）；条件模型优于只有基因 / 序列的模型；打乱上下文 ≈ 0；与 ENCODE / APEX / Halo / MERFISH 方向一致。r < 0.10 就停 D，不再加复杂度。

## Q3：方向 B
- 目录：RASP v2.0（PMID 39546630，438 个数据集；59 个低覆盖数据集是模型插补的，不能当真值）、RMDB（PMID 22976082）。
- 候选数据：
  - Sun 2019：GSE117840；
  - smartSHAPE：GSE155961，PMID 38933905，小鼠肠巨噬细胞炎症，重复结构需要按 run 审计；
  - 人神经发生 icSHAPE：GSE236224，PMID 34655516，GEO 只有 9 个样本，hESC / NPC 有重复；
  - PrismNet：GSE145805，6 个细胞系，但每系只有 1 个 NAI 样本，不满足重复条件；
  - PARIS：GSE74353；SPLASH：PMID 27184079。这两个是双链 / 互作图，不是反应性。
  - 纳米孔探测：未找到合格数据。
- ±12 nt 的增益是红旗，可能是异方差去噪。决定性实验：交叉拟合重复（用 A1 作输入，标签用 B2 − A2），再加同条件伪变化 A2 − A1 作阴性对照。
- 门槛：
  - 重复变化可靠度 ≥ 0.5；
  - 伪变化上的序列增益 ≤ 0.01；
  - 真实对比增益 ≥ 0.05，且 ≥ 3 倍伪增益；
  - ≥ 100 个 lncRNA 基因，每个条件 ≥ 2 个生物学重复。
- 先按 run 审计 GSE155961、GSE236224；若都凑不到约 100 个有重复的 lncRNA，就停掉 B 作为 lncRNA 方法。

## 排序（条件概率是它的主观估计）
| 名次 | 方向 | 过门槛后发 Q1 的概率 |
|---|---|---|
| 1 | 测量方式感知的上下文 ncRNA 定位 / 核滞留交互模型 | 45–65%（预研前 25–40%） |
| 2 | 从头生成上下文转录本对象 | 35–55% |
| 3 | 条件化先验 + 廉价证据 | 25–45% |
| 4 | AG2 的 lncRNA 失败基准 + 校正 | 20–40%；只做基准 10–20% |
| 5 | 上下文小 ncRNA | 30–50%，但等于新课题 |
| 6 | lncRNA 化学结构变化（B） | 15–30%；过门槛前 < 15–20% |
| 7 | 只做小鼠 | < 15% |

建议顺序：
1. 用 TS total-RNA 重做 D 预研；
2. 并行做小规模 AG2 审计（20–50 个上下文，几百个 lncRNA，比较屏蔽与不屏蔽目标基因）；
3. 做条件化先验融合测试；
4. 按 run 审计 B 的两个候选数据集；
5. 只有 D 失败、且结构预研信号很强时，才投入从头转录本对象。
