# P1.5 第 1 批读取：chr20 与 T2T chr20（2026-11-01）

**结论**：
- **Go 通过。** v1.9 主模型（G1B，三个 seed）在 chr20 上：
  - lnc L1 Sn 平均 0.306，严格 Pr 0.422，与 GENATATOR 的 Pr（0.422）持平。
  - Sn 比 GENATATOR（0.028）高 0.278，配对 bootstrap 95% CI [0.256, 0.300]。
- **护栏通过。**
- **Strong 未通过。** lnc 的内含子链（L2）一条也没有完全对上，三个 seed 都是 0；T2T chr20 官方 metric 的 lnc_RNA segmentation recall / precision 也都是 0。四项中只有"非同源子集 Sn ≥ 0.15"通过（0.292）。
- **含义**：模型能找到 lnc 基因在哪里，比 GENATATOR 多找到约 11 倍，精确度相同；但没有学到 lnc 的外显子–内含子结构。

- 分两批读取：用户 2026-11-01 在看板卡 `p15-read-order` 上的决定，见协议偏离记录。

**lnc**：
- 模型报出的 lnc 剪接点只有 0.4–1.5% 落在真值剪接点上。
- GENATATOR 报得少，但它报出的剪接点有 16% 是对的。
- 这一点在 chr18 开发时已经看得到：三个主模型 chr18 的 lnc L2 Sn 为 0.001 / 0 / 0。
- 不是评分代码的问题：同一套 ruler 给 GENATATOR 的 lnc 剪接点 16%、给本模型 seed 42 的 mRNA 剪接点 73%（S1 解码时 90%），坐标约定一致。

**mRNA**：
- 结构随 seed 变化很大：L2 从 0.108 到 0.004，seed 456 的剪接点精确度只有 0.144。
- 位点层面（L1 0.84–0.90）仍过护栏。

**MEAX 的代价**：
- 同一后验用 S1（逐碱基 argmax）时，mRNA L2 为 0.264 / 0.189 / 0.030，剪接点精确度 0.896 / 0.869 / 0.527，都高于 MEAX。
- 所以 MEAX 在提高 lnc 检出的同时，降低了 mRNA 剪接点的精确性。
- 对 lnc，两种解码的 L2 都约为 0。

## 8. 对论文主张的含义

**可以主张**（Go）：
- 在冻结的协议、未调参的测试染色体上，冻结 DNA 语言模型特征 + HMM-CRF 语法在同等精确度下找到的 lnc 基因是 GENATATOR 的约 11 倍（hg38 chr20），T2T chr20 上约 10 倍。
- 对 v50 新增基因和非同源基因同样有效。
- mRNA 位点检出保持在 0.84–0.90。

**不能主张**（Strong 未过）：
- 本模型给出 lnc 的转录本结构。它的 lnc 预测只在位点层面有用：剪接点、外显子边界和内含子链基本不对。
- 在 GENATATOR leaderboard 的 segmentation metric 上胜过 GENATATOR。

**另须如实报告**：
- seed 间差异大（Sn 0.21–0.40）。
- 置信度明显偏高。
- MEAX 降低了 mRNA 的剪接精度。

按协议，chr20 与 T2T chr20 已读，不能在它们上面再调参。若要改进结构，只能在 chr18 上开发，并在另一份未读数据上评估，需要新版协议和用户批准。下一步是 P1.6（零样本面板，描述性）和第 2 批消融，由用户决定。
