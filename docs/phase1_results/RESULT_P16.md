## 结论

- **lnc 位点在三个脊椎动物 / 昆虫上能零样本找到一部分**。3 seed 平均 lnc L1 Sn：鸡 0.318、斑马鱼 0.348、果蝇 0.214、线虫 0.073。同一染色体上 GENATATOR（Phase 0 0.1a）几乎为 0：鸡 1 个 lnc 预测、斑马鱼 Sn 0.022、果蝇和线虫没有 lnc 预测。
- **lnc 精度低，一部分是真值稀疏造成的**。
  - 严格 Pr：鸡 0.246、斑马鱼 0.065、果蝇 0.089、线虫 0.008。
  - 斑马鱼 22 只注释了 135 个 lnc 基因，线虫 I 只有 150 个，预测里大量「新位点」无从判对错。
  - 宽松 Pr（只看与已注释基因重叠的预测）：鸡 0.40–0.47、斑马鱼 0.19–0.21、果蝇 0.16–0.25。
- **线虫 I 基本失败**。lnc 预测中约一半到八成落在编码基因上（seed 42：2,167 个里有 1,197 个）。线虫基因组紧凑、基因密，人类训练的模型把编码基因当成了 lnc。
- **mRNA 能零样本迁移，且明显好于 GENATATOR**。mRNA L1 Sn：鸡 0.862、斑马鱼 0.842、果蝇 0.640、线虫 0.683；GENATATOR 依次为 0.837 / 0.489 / 0.214 / 0.006。mRNA 严格 Pr 为 0.74–0.93。
- **结构层面与人类一样没学到**。lnc L2 内含子链 Sn 在四个物种上都是 0，lnc L3 剪接点 Sn 0–0.03。mRNA L2 只有 0.016–0.050，而 GENATATOR 在鸡上是 0.243。这与 chr18 剪接诊断的结论一致：结构瓶颈在剪接信号。
- **置信度明显偏高**，ECE 0.49–0.75（人类 chr20 为 0.34）。
- seed 间差异大，与人类一致，例如线虫 seed 42 报了 2,167 个 lnc，seed 123 只有 763 个。

## 4. 统一 GFF3

每个物种、每个 run 都写了 `unified.gff3`：lnc / mRNA 预测，加上 Phase 0 0.6 的 Rfam / tRNAscan 小 RNA 命中，按 0.6 的整合规则合并。
- 去掉 clan 竞争的落选命中，以及 Rfam 的 lncRNA / Cis-reg / Intron 家族。
- Metazoa_SRP 和 U6 只保留全长命中。
- 与预测 lnc 外显子同链重叠的小 RNA，两者都保留，并以 `Note=overlaps_lnc` 标注。

小 RNA 条数：鸡 53、斑马鱼 842（主要是 tRNA 和 5S 簇）、果蝇 133、线虫 194。

面板没有 RepeatMasker 过滤，也没有 miRNA 专用组件，这两项留作软件设计的后续工作。

## 5. 完整性

- **chr18 复现**：用 P1.6 配置重读三个主模型，后验与基因和 P1.5 第 2 批的 chr18 读取逐位相同（sha256），之后才读面板。
- **代码**：读取代码（src + p15_read.py + p16_read.py）的哈希与配置一致，打分脚本单独记录哈希。
- **输入**：面板序列的 md5 与 Phase 0 下载时记录的一致（prep_panel.py），特征提取 0 失败。
- **算力**：ont，chr18 复现约 12 分钟，四个物种读取约 31 分钟，打分约 1 分钟；GPU 与 coding-rna 的 M34 共用，CPU nice 19。

## 6. 局限

- 零样本、描述性，不设判据。
- 面板物种的 lnc 注释稀疏，严格 Pr 会低估真实精度，宽松 Pr 又会高估。
- 只有一条染色体，样本小，斑马鱼 22 只有 135 个 lnc。
- 线虫的失败也可能部分来自注释口径：WormBase 的非编码类别多归为 small / other。
