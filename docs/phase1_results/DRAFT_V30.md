## 1. 要回答的问题

只用人类训练时，lnc 位点的零样本检出随进化距离下降。3 seed 平均 lnc L1 Sn：

| 物种 | Sn |
|---|---|
| 小鼠 chr19 | 0.280 |
| 鸡 5 | 0.32 |
| 斑马鱼 22 | 0.35 |
| 果蝇 2L | 0.21 |
| 线虫 I | 0.07 |

问题：在训练中加入一个注释完整的近缘物种（小鼠），对**训练里没有的物种**是否也有提升？

- 小鼠自己（chr19 留出）的提升是预期内的，不算「泛化」。
- 审稿人一定会问：提升是来自「多一个物种」，还是只是「多一倍数据」。所以设一个**同样数据量的纯人类对照**（§3 的 H6）。

## 2. 三个臂（都是 G1B，seed 42 / 123 / 456，配方同 v2.0）

| 臂 | 训练窗口 | 说明 |
|---|---|---|
| H | v2.0 的 3,000 个人类窗口 | 即已训好的 v20-g1b-*-ke，不重训 |
| H6 | H 的 3,000 个 + 新抽 3,000 个人类窗口 | 数据量对照 |
| HM | H 的 3,000 个 + 3,000 个小鼠窗口 | 多物种 |

- 配方与 v2.0 相同：
  - GENERanno 第 17 + 23 层特征，ont 缓存；
  - 2 × 4 累积，12 epoch，取第 10–12 epoch 权重平均；
  - v1.2 标签（canonical + 可行性修复）加 U-ev。
- H6 与 HM 的优化步数相同，都是 H 的两倍。
- 解码、编码潜能特征、校准模型的形式都与 v2.0 相同。每个臂各自在**人类 chr18** 上：
  - 拟合校准；
  - 按 §17.1 规则选 τ：先按 §16 细网格定 τ_base，再取 Sn 不低于 τ_base 的 Sn − 0.02 的 τ 中严格 Pr 最高者。
- 六聚体表沿用 v2.0 的人类表，三个臂相同。

## 3. 数据

### 3.1 新抽的人类窗口（H6）

- 抽样规则同 `prep_p1.py`：40% lnc 中心、30% 编码中心、30% 随机，N > 10% 的丢弃。
- 从 v2.0 的训练染色体中抽（不含 chr9 / chr18 / chr20），`numpy.random.default_rng(3)`。
- 与已有 3,000 个窗口重叠超过 50% 的重抽。

### 3.2 小鼠窗口（HM）

- **基因组与注释**：
  - mm39 全基因组：UCSC `mm39.fa.gz`，约 870 MB。chr19 的序列须与 S5 用过的 `data/mouse/chr19.fa` 的 md5 一致。
  - GENCODE vM39：与 S5 的真值同一文件。
- **染色体**：
  - 训练：chr1–17 与 chrX；
  - 留出：**chr19（测试）**；
  - 开发：**chr18**，只做标签与读取的健全性检查，不参与任何选择；
  - 不用：chrY、chrM、未定位片段。
- **抽样**：3,000 个 24,576 bp 窗口，比例与人类相同，`default_rng(2)`。
- **标签**：
  - vM39，按 v1.2 标签规则（Ensembl_canonical 加可行性修复），与人类相同的代码路径。
  - 修复前不可行的窗口比例要报告。人类为 311 / 3,000。
- **U-ev**：与人类的定义逐字相同，换成小鼠数据：
  - Snaptron **srav1m**（recount3 小鼠，约 41.7 万个样本）；
  - 过滤：samples_count ≥ 100、coverage_sum ≥ 500、规范 motif、长度 ≤ 500 kb，且不与任何注释基因跨度重叠；
  - 区间：两端各扩 500 bp 后合并，再减去注释基因跨度。
  - srav1m 的坐标是 **mm10**，要映射到 mm39：用 UCSC 的 `mm10ToMm39.over.chain.gz`，复用 S4 自写的 chain 读取代码。两端都映射到同一染色体与同一链、且映射后长度变化 ≤ 10% 的连接才保留。
  - 报告保留比例与 U-ev 覆盖的碱基比例。人类训练染色体上的覆盖比例已知，可对照。
- **提特征**：3,000 个小鼠窗口与 3,000 个人类新窗口各约 1 GPU 小时、各约 100 GB。ont 现剩约 550 GB。

## 4. 测试集（冻结并在人类 chr18 上复现后，每个模型每个测试集只读一次）

| 组 | 测试集 | 真值 | 对 HM 而言 |
|---|---|---|---|
| A 同物种留出 | 小鼠 chr19 | GENCODE vM39（875 个 lnc 基因） | 同物种 |
| B 已有面板 | 鸡 5、斑马鱼 22、果蝇 2L、线虫 I | Ensembl 116 / 63（P1.6 同一文件） | 零样本 |
| C **新增零样本物种** | 大鼠、牛、热带爪蟾，各一条染色体 | Ensembl 116 | 零样本 |

- **C 组物种的理由**：
  - 大鼠：与小鼠最近，检验「加小鼠」是否首先帮到它的近亲。
  - 牛：哺乳动物的外群，与人和小鼠等距。
  - 热带爪蟾：两栖类，进化距离介于鸡和斑马鱼之间。
  - 三者在 Ensembl 都有 lncRNA 注释，都不是 TE 的封存物种。
- **C 组染色体的选法**（下载后、读任何模型输出之前按规则定，写进配置）：在 40–80 Mb 的常染色体中，取注释 lnc 基因最多的一条。若 lnc 基因 < 200 个，该物种只作描述，不进判定。
- **已读过与没读过的**：A、B 两组曾用 v1.9 模型读过，但从未用来做任何选择。v2.0 模型（H）还没读过它们。C 组从未读过。
- **人类**：没有剩余的留出染色体（chr20、chr9 都已读）。人类只在 chr18（开发）上看有没有退步，作为护栏。

## 5. 判定（冻结时写死）

**统计方法**：

- 对每个测试集做两组比较：HM 对 H6（主比较），HM 对 H（次要）。
- 统计量是 3 seed 平均。
- 用分层 bootstrap 2,000 次，`default_rng(0)`：先按真值 lnc 基因重抽，再在每个臂内有放回地重抽 3 个 seed。seed 间差别很大（小鼠 Sn 0.20–0.38），这样置信区间里包含 seed 的波动。

**判据**：

| 项 | 判据 |
|---|---|
| 主判定：「多物种训练提升零样本泛化」 | 零样本测试集（B + C 组中进判定的）上，HM − H6 的 lnc L1 Sn 平均差 ≥ +0.03，且至少一半测试集的 Δ Sn 95% CI 下界 > 0；同时这些测试集上 HM 报出的 lnc 数不超过 H6 的 1.3 倍（防止靠多报换 Sn） |
| 同物种（小鼠 chr19） | HM − H6 的 Δ Sn 与 Δ 严格 Pr 的 CI。只报告，预期为正 |
| 近缘梯度 | Δ Sn 是否随与小鼠的距离递减（大鼠 > 牛 > 鸡 / 爪蟾 > 斑马鱼 > 果蝇 / 线虫）。只描述 |
| 人类护栏（chr18） | HM 相对 H6：lnc Sn 不低于 0.02 以上，严格 Pr 不低于 0.02 以上 |
| 校准 | 每个测试集报 ECE（τ 之前）。只报告 |

- 严格 Pr 只在注释完整的人和小鼠上作判据。其他物种的 lnc 注释稀疏，严格 Pr 只报告（P1.6 的教训）。
- 不论结果正负，都写进论文：
  - 主判定为负，论文写「只加一个近缘物种不提升远缘零样本检出」；
  - 若只有大鼠等近缘物种提升，就如实写成「提升局限于近缘物种」。
