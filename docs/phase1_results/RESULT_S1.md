## 结论

- **坐标核对通过**：gtexv2 的 188,752 个规范连接（共 199,311 个连接）全部落在规范二核苷酸上（100%）。
- **主判定（写定规则，判读模型为自训 S10k）：「差距主要由使用量解释」。**
  - 位点用 GTEx 剪接读段定义，与 GENCODE 无关。负例是同类基因体内、没有出现在任何 ≥ 5 个样本的 gtexv2 连接里的规范二核苷酸位置。在这个口径下，lnc 和 mRNA 的剪接位点一样好预测：
    - 自训模型 AUROC 0.925 对 0.925；不匹配时差距 0.000 [−0.012, 0.014]，按使用量匹配后 −0.003 [−0.015, 0.010]。
    - SpliceAI 为 0.911 对 0.913，差距同样为 0。
  - 可预测性随使用量陡升，lnc 和 mRNA 在每一层几乎重合。自训模型：1–9 条读段时 AUROC 0.87 / 0.86，≥ 1,000 条时 0.99 / 0.99。
  - 已注释的位点几乎都能和未见剪接的位置分开：v41 已有的 lnc 位点 AUROC 0.997，mRNA 0.999；v42–v50 新增的 0.995 / 0.993。
- **lnc 与 mRNA 真正的差别在于注释的内含子用得少得多（R4，与模型无关）**：
  - v50 注释的 lnc 内含子，GTEx 读段中位数为 **352 条**，mRNA 为 **9,194 条**，约低 26 倍。
  - 读段 ≥ 1,000 条的比例：lnc 33%，mRNA 73%。
  - v41 已有的 lnc 内含子中位数 840 条，长读长时代（v42–v50）新增的只有 222 条。
- **这把 S1b 和旧的 AP 读数连了起来**：
  - 旧口径（chr20 上重算）：候选为全染色体的基序位置，正例为注释位点。自训模型的 lnc AP 为 0.177，mRNA 为 0.663。lnc 的数与 chr18 上的 0.161 一致。
  - 新旧口径的差别来自三处：lnc 注释位点的使用量低、全染色体的负例极多（患病率极低）、真实但未注释的剪接位点被当成负例。
  - 所以「lnc 剪接位点难预测」不是 lnc 剪接信号本身的问题：同样低使用量的 mRNA 位点一样难。
  - S1b 表明，给出真位点后解码器就能出结构。合起来：**lnc 结构从序列定不下来，是因为 lnc 的剪接大多是低使用量事件，而不是因为 lnc 的剪接信号与 mRNA 不同。**
- **文献口径（R3，转录本内 top-k）**：
  - SpliceAI 在 mRNA 上为 0.738，v41 已有 lnc 0.541，新增 lnc 0.521。
  - 按写定规则判为「文献高分不能只用注释年代解释」：老 lnc 与新 lnc 几乎一样，都远低于文献报的 lncRNA 高分（据查新报告，NAR 2026 复评 SpliceAI 自带的 lncRNA 测试集，auPRC 0.963，待核实原文）。
  - 我们的口径用全部 v50 转录本、跨度内全部位置。mRNA 的 0.74 也低于 SpliceAI 论文的约 0.95，说明这个口径整体更严。可比的是 lnc 与 mRNA 的相对差距，而不是绝对值。
- **事后检查（读过主结果之后加的，不改判定）**：转录本层面的差距用使用量解释不完。
  - 按每个转录本最弱内含子的使用量分三档（< 100、100–999、≥ 1,000 条）后，文献口径下 lnc 仍明显更难。SpliceAI 的 top-k：lnc 0.50 / 0.56 / 0.62，mRNA 0.80 / 0.81 / 0.83。
  - 再把「GTEx 里出现过但未注释」的位点从负例中去掉：lnc 升到 0.60 / 0.67 / 0.75，mRNA 升到 0.84 / 0.88 / 0.91。差距缩小约三分之一，但仍有 0.16–0.24。
  - 剩下的差距可能来自分档不够细：同一档里 mRNA 其余内含子的使用量仍远高于 lnc。也可能有别的原因。本次没有拆开。
  - 所以论文里的准确说法是：**在位点层面、使用量匹配后，lnc 和 mRNA 的剪接位点没有差别**；在转录本层面，lnc 仍更难。差距约三分之一来自未注释的真实位点，其余未拆开。
- **Vipsania（对照）**：
  - 整体弱得多（AUROC 0.76）。
  - 在已注释位点上，lnc 明显差于 mRNA：v41 时代 0.903 对 0.972，匹配后差距 0.053 [0.040, 0.067]。
  - 符合它只建模编码基因的设计（位点态受读框约束），不算失败。

## 6. 局限

- gtexv2 只有 GTEx 成人组织。「未见剪接」只相对这约 1.9 万个样本、且只计 ≥ 5 个样本中出现过的连接，负例里可能有低频的真位点。
- 位点按所在基因体归类；同时落在 lnc 与 mRNA 基因体内的位点（1,196 个）不进主读数。
- SpliceAI 在 chr20 上是样本内的，判读只用了自训模型，两者结论相同。
- 只有 chr20 一条染色体；按计划，SpliceAI 测试染色体上的干净数字和 chr18 的补充查询在第 2 批（要下载，走卡）。
