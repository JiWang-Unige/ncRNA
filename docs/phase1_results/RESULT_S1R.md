## 结论

- **按写定的复现规则，S1 的判定没有复现。**
  - 规则是：chr18（自训判读）与 chr7（SpliceAI 判读）都判为「差距主要由使用量解释」。
  - 实际结果：chr18 为「部分由使用量解释」，chr7 为「lnc 固有差距」，再加上 chr20 的「主要由使用量解释」，三条染色体三种判定，没有多数。
  - 按规则如实报告：S1 的定性判定（差距是否「主要由使用量解释」）**不稳定**。
- **稳定、可写进论文的是以下三点**（三条染色体、四个模型一致）：
  1. **使用量匹配后，lnc 与 mRNA 剪接位点的可预测性差别很小，符号随染色体而变。**
     - 判读模型下的匹配差距：chr20 −0.003，chr18 −0.015（lnc 更好预测），chr7 +0.015（lnc 稍难）。
     - 在同一条染色体上，四个模型的方向一致。在 chr18 上四个模型都是 −0.015 到 −0.027，在 chr7 上三个模型都是 +0.008 到 +0.015。所以差别来自各染色体的位点构成，不是模型特性。
  2. **使用量的效应大得多**：最低层（1–9 条读段）到最高层（≥ 1,000 条），AUROC 升高 0.07–0.21，两类都是。lnc 与 mRNA 之间 ±0.02 的差距只有它的十分之一左右。
  3. **注释的 lnc 内含子使用量远低于 mRNA，三条染色体都成立（R4）**：GTEx 读段中位数 lnc 为 352 / 234 / 430 条，mRNA 为 9,194 / 6,662 / 6,851 条，低 16–28 倍。长读长时代新增的 lnc 内含子更低：222 / 149 / 213 条。
- **文献口径（R3）在三条染色体上都是 lnc 更难**：
  - SpliceAI 的 top-k：mRNA 为 0.74 / 0.75 / 0.71，v41 已有 lnc 为 0.54 / 0.54 / 0.59，新增 lnc 为 0.52 / 0.52 / 0.53。
  - 按写定规则，三条都判为「不能只用注释年代解释」。
- **R4 后半（chr18，真值剪接位点下的结构恢复）**：
  - 恢复率随基因使用量升高：0 条读段的基因 6%，1–9 条 14%，10–99 条 16%，100–999 条 16%，≥ 1,000 条 21%（3 seed 平均）。
  - 恢复了的基因，最弱内含子使用量中位数为 1,333 / 774 / 446 条，未恢复的为 356 / 350 / 375 条。
  - 即使使用量很高，真值剪接位点下也只有约五分之一的结构能恢复。低使用量是一个因素，但解码器在真位点之间的组合选择也是瓶颈。
- **Pangolin**：
  - 位点层面 AUROC 与其他模型相近：chr20 0.90 / 0.89，chr18 0.93 / 0.91，chr7 0.87 / 0.89（lnc / mRNA）。偏移在 chr20 上选定为 0，峰值清楚。
  - 它不区分供体和受体，同一条链的两列用同一个分数，所以文献口径（R3）明显偏低（mRNA 约 0.49）。这是口径限制，不是性能差。
- **对主线措辞的修正**：
  - 原来写的「lnc 剪接信号不特殊、差距主要由使用量解释」**说得过强**，要改成：「使用量匹配后，lnc 与 mRNA 剪接位点的可预测性差别很小（|Δ AUROC| ≤ 0.02），方向随染色体而变；而可预测性随使用量的变化大一个数量级，注释的 lnc 内含子使用量低 16–28 倍」。
  - 结构定不下来的主因仍然是 lnc 剪接多为低使用量事件。但「lnc 剪接信号与 mRNA 完全相同」不能写。
- **对 v2.0 chr9 复核的影响**：DRAFT_V20 §4.2 的 R-S1 复现判据原来沿用 PLAN_S1 §5 的置信区间规则。位点数以万计时，0.01 量级的差距也会排除 0，这条规则对很小的差距过于敏感。在 chr9 冻结之前改成按量级的判据，见 DRAFT_V20。

## 5. 局限

- 判定规则用的是置信区间是否含 0。位点数以万计时，0.01 量级的差距也会被判为「显著」，规则对很小的差距过于敏感。这一点在 S1 冻结时没有预见到，只能如实报告。
- 只用了 GTEx（gtexv2），且只计 ≥ 5 个样本中出现过的连接。
- 每条染色体上只有一个模型是严格样本外的判读模型。SpliceAI 在 chr18 / chr20 上、自训在 chr7 上都是样本内的。
