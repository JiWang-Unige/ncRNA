## 2. 逐条取舍

**采纳，投稿前做：**

1. **B1 严格位点评价（0 GPU）**。在已有预测上重算，不重读模型、不调参：
   - 主口径：同链同类别，按基因跨度算双向覆盖 R_g ≥ 0.5 且 R_p ≥ 0.5，一对一（二分图最大匹配）；副口径 0.25 / 0.25。
   - 同时报：跨度比、TSS/TES 偏差、一个预测吞并多个真值的比例；GENATATOR、SegmentNT、AlphaGenome 分段用同一口径重算。
   - 事前措辞规则（ChatGPT 建议，可采用）：严格 Sn ≥ 0.15、Pr ≥ 0.35 且对 GENATATOR ≥ 5 倍 → 「locus discovery」；严格 0.08–0.15 且宽松 ≥ 0.20 → 「candidate locus discovery」；更低 → 「transcription-associated regions」。
   - 我加一项对照：只用 CpG / GC / 基序等简单序列特征的位点检测器（chr18 开发），回答「1.2B 骨干 + 语法比简单启发式强多少」。S3 已说明检出靠 CpG 与跨度，审稿人必问。
2. **全基因组人类推理 + 新转录单位的独立验证（约 17 GPU 小时，主要算力投入）**。这是最可能提升档次的一项。
   - 先冻结预测与判据，再下载验证数据。
   - 独立于 GENCODE CLS 的证据：LRGASP（WTC11 / H1 长读长、QuantSeq、ssCAGE）、ENCODE 非靶向长读长 / EN-TEx、ENCODE RAMPAGE；ChatGPT 还推荐 Tabula Sapiens 全长异构体图谱（2026）——**这一项我未能独立核实，下载前先确认**。FANTOM CAGE、PolyASite、CHESS 只作辅助（与 GENCODE 来源有重叠）。
   - 证据分三级：L1 同链 junction 或长读长；L2 长读长转录本 + TSS 或 TES；L3 长读长 + TSS + TES 且排除已知基因延伸 / 假基因 / 编码。
   - 对照改为每个候选 ≥10 个匹配的未注释基因间区间（染色体、链、跨度、GC、启动子 CpG、重复类型与比例、到最近基因 / TSS 的距离、基因密度、可比对性），另加链翻转与位置平移；统计单位是去重后的位点，不按 seed 重复计数。
   - 更强的写法需要这些候选有共同的生物学特征（细胞类型限制、启动子类型等），解释它们为何长期被漏掉。
3. **S11 两阶段结构：先过「边界抖动门」（约 2–6 GPU 小时，失败即停）**。
   - chr18 上用 GENATATOR 区间分割（已安装）：真值转录本区间 / 真值基因跨度 / 两端各 ±1、5、10、20 kb（外扩与内裁分开）。
   - 停止规则：真值区间下 L2 就没有意义 → 停；±10 kb 已掉 80% 以上 → 停；±10–20 kb 仍保留一半以上 → 才把我们预测的位点送进去读端到端 L2（分母是全部多外显子 lnc）。
   - 注意：GENATATOR 自己端到端 lnc L2 约 0.012，所以不能说「首次 > 0」，只能说可比条件下的实质改善；chr20 对 GENATATOR 是验证集而非完全独立。
   - 我的看法：ChatGPT 把它排第 4，我建议与 B1 并行先跑抖动门——它便宜，且是唯一可能把「结构为 0」变成正结果的路。
4. **B3 改写为「可观测性」分析（CPU）**。用共享 donor / acceptor 的竞争 junction 算相对使用率；表达量代理用不含目标位点的其他 junction（避免数学耦合）；样本数单列为可观测广度。结论只写关联：「lnc 剪接连接的可预测性与相对使用率和观测广度相关」，撤掉「低剪接效率导致」的因果说法。核 / 胞质分馏数据（ENCODE K562）只在需要坚持「效率」一词时再补，倾向不做。
5. **选择性统一 GFF3 + 编码护栏（染色体级 1–3 GPU 小时）**。编码结构取 Tiberius，lnc 只输出位点级候选 + 校准置信度，结构未解析的不伪造多外显子转录本；chr18 上比较强制完整结构与选择性输出的错误成本。同时解决自评第 2、4 条（联合注释说法、可用软件）。

**采纳，但只改写不加实验：**
- 「严格 Pr 下界」、v41→v50（CLS 一次性扩张）、GENATATORs 任务差异的措辞。
- AB3 消融（去掉编码通路 lnc AUPRC −0.061）可写成「显式学习编码基因有助于界定非编码基因」，用现有数据按错误类型拆开即可。
- 把 SpliceAI2、SPLAIRE 写进相关工作；SpliceAI2 至多作为跨模型剪接表里的一行对照（许可限制，不能进软件）。

**可选（便宜，有余力再做）：** 启动子 CpG 的计算机内扰动（1–4 GPU 小时），把「相关」升级为「模型依赖」。

**不采纳 / 留到返修：** 更多 seed 与置信区间；核 / 胞质剪接动力学；Compara 同线性（S4 已显示功效不足）；单外显子、反义、TE 家族的进一步分层；更多零样本物种。

**停止（双方一致）：** 再训剪接网络；G2 / G2-PH；加人类窗口；人 + 鼠联合训练；编码证据特征重训；用 MEAX 救 L2；v41→v47 时间穿越；调 AlphaGenome 分段阈值。

## 3. 主线如何改

- 原主线「序列能定位 lnc 基因但定不了结构，因为 lnc 内含子低使用量」同时压了三个强度不同的命题；因果那一条证据不足，且已有 SPLAIRE、Mele 等在先。
- 新主线的候选（取决于第 1、2 项的结果）：
  - 最好：**只用 DNA 的预测揭示一批参考注释遗漏的转录单位，并解释现有注释体系为何漏掉它们**（严格位点评价成立 + 独立长读长验证 + 候选有共同特征）。目标 Genome Research / Nat Commun。
  - 中等：**从序列发现候选 lncRNA 位点，并分层给出位点、连接、转录本三个层次的可预测性与不确定性**。
  - 最差：全基因组的转录相关候选区域图谱 + 基准（资源类）。
- S11 若成功，是加分的独立结果（「位点发现使已有分割模型能恢复此前拿不到的 lnc 结构」），不重写主线。
