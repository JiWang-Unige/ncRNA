## 1. 为什么要 v2.0

主线已经定下来（`SCREEN_SUBJOURNAL.md`）：

- **位点能从序列找到**：
  - chr20 lnc L1 Sn 0.306、严格 Pr 0.422，约为 GENATATOR 的 11 倍；
  - 小鼠 chr19 零样本 0.280 / 0.372，判为「迁移」（`RESULT_S5.md`）；
  - 检出靠启动子 CpG 和长转录单元，不靠外显子序列（`RESULT_S3.md`）。
- **结构定不下来，瓶颈是剪接位点，不是边界**：
  - chr18 上只给真值边界时 L2 为 0.003，只给真值剪接位点时 0.168，两者都给时 0.341（`RESULT_S1B.md`）。
  - 使用量匹配后，lnc 与 mRNA 剪接位点的可预测性差别很小（三条染色体上 |Δ AUROC| ≤ 0.02，方向不定），而可预测性随使用量变化大一个数量级。注释的 lnc 内含子使用量低 16–28 倍（`RESULT_S1.md`、`RESULT_S1R.md`）。
  - 从序列改进结构已经试过四次，都未达有效：SpliceAI、自训剪接网络、外部编码证据，以及两阶段解码（S1b 已排除）。

v2.0 因此不再追求结构，有两个目的：

1. **精度与校准**：严格 Pr 0.42，置信度偏高（chr20 ECE 0.34，小鼠 0.385，面板物种 0.49–0.75）。主体改动是编码潜能特征加基因层面的置信度校准（§3.3–3.4），与第 1 版相同。
2. **第二条完全留出的人类染色体**：在 chr9 上一次性读取。
   - 复现 Go，检验精度和校准的改进；
   - **同时预注册地复核主线的三条结论**（§4.2）。审稿人最可能问「只在 chr20 / chr18 上成立吗」，chr9 对三个剪接模型都是样本外的，正好回答这个问题。

## 3. 改动

### 3.1 主模型：去掉 chr9 后重训（与第 1 版相同）

- G1B，3 个 seed（42 / 123 / 456），配方与 v1.8 §15、v1.9 §16 完全相同：GENERanno 第 17 + 23 层特征，ont 缓存，2 × 4 累积，12 epoch，取第 10–12 epoch 权重平均。
- 补抽的 154 个窗口要提特征，约 0.2 GPU 小时；重训共约 12 GPU 小时。

### 3.2 剪接势能：不进 v2.0，也不作消融

- 依据：
  - S1b 表明，即使给出真值剪接位点，L2 也只有 0.168；
  - S1 表明，lnc 剪接位点的困难来自低使用量，现有序列模型都没有这方面的优势；
  - 两次 chr18 剪接诊断都未达有效。
- 第 1 版里「只作消融」的选项删除。

### 3.3 编码潜能特征（基因层面，与第 1 版相同）

对每个预测 lnc 转录本（按链拼接外显子序列）计算：
- 最长 ORF 长度（ATG 起始到终止密码子）及其占转录本长度的比例；
- 六聚体编码分：最长 ORF 上按读框计的六聚体对数似然比，仿 CPAT。频率表只用训练染色体上 v50 的 mRNA CDS 与 lnc 外显子序列统计，不用 chr9 / chr18 / chr20；
- Fickett TESTCODE 分；
- 模型内部量：转录本外显子上 mRNA 态后验质量的平均值，以及 lnc 态后验均值（即 v1.9 的置信度）。

这些特征只进入 §3.4 的校准模型，不改解码出的结构，也不把 lnc 改判成 mRNA。外部编码证据（Vipsania / Tiberius）在 chr18 诊断中未达有效（`RESULT_VIPSANIA.md`），不加。

### 3.4 置信度校准（与第 1 版相同）

- 模型：logistic 回归（L2 正则，C = 1，特征标准化）。输入为 §3.3 的特征，加 log 成熟长度和外显子数。目标为该预测是否命中 v50 lnc（L1 严格口径，同链外显子重叠）。
- 拟合：chr18 上三个重训主模型的全部 MEAX lnc 预测合并（τ 过滤之前）。另做 chr18 前后两半交叉拟合，报告折外 ECE 与 AUPRC_lnc，判断是否过拟合。最终用全部 chr18 拟合一次，系数写进配置。
- 校准后的概率即新的基因置信度。τ 按 v1.9 §16 的规则在 chr18 上重选：三 seed 平均严格 Pr ≥ 0.43 的 τ 中，取三 seed 平均 lnc L1 Sn 最大者，网格 0.2–0.9。
- 保留规则：只有 chr18 折外 AUPRC_lnc 不下降、且折外 ECE 下降时才保留；否则 v2.0 只用原始后验均值，τ 照 §16 重选。
- 可选（要你定）：把 S3 发现的「反义重叠」（与反向 mRNA 基因体重叠）作为一个校准特征。它影响的是漏检，对精度的作用不确定，默认不加。

## 4. chr9 判定（冻结时写死，读取前不改）

### 4.1 主判定（与第 1 版相同）

**基线**：同一批重训模型，用 v1.9 的解码（MEAX γ = 3，无校准，τ 按 §16 规则在 chr18 上重选）。所有比较都是同一模型上的配对比较，按 chr9 真值 lnc 基因重抽 2,000 次（seed 0）。

| 项 | 判据（3 seed 平均） |
|---|---|
| Go 复现 | v2.0 的 lnc L1 Sn ≥ 0.20，且严格 Pr ≥ 0.40 |
| 结构（Strong 的 L2 线） | v2.0 的 lnc L2 Sn ≥ 0.05，且相对基线的 Δ 95% CI 下界 > 0（预计不过，如实报告） |
| 精度 | v2.0 的 lnc 严格 Pr 相对基线的 Δ 95% CI 下界 > 0，且 lnc L1 Sn 降幅 ≤ 0.03 |
| 校准 | v2.0 的 lnc 基因 ECE ≤ 0.15（10 个等宽箱，τ 过滤之前） |
| 护栏 | mRNA L1 Sn ≥ 0.80，且不低于基线 0.02 以上；被报成 mRNA 的 lnc 基因数不多于基线 |

### 4.2 主线结论的预注册复核（新增；判据沿用已冻结的计划，只换染色体与模型）

| 复核 | 做法 | 复现判据（写定） |
|---|---|---|
| R-S1 剪接可预测性 | `s1_analyze.py` 原样运行于 chr9，模型为 SpliceAI、自训 S10k、Pangolin（偏移沿用 chr20 选定值），判读模型为自训 S10k | 按量级判定（11-04 晚改，见下）：判读模型的匹配差距 \|Δ AUROC\| ≤ 0.03，且两类的 AUROC 从最低使用量层到最高层都至少升高 0.05；R4 中 lnc 内含子使用量中位数低于 mRNA 的 1/5 |
