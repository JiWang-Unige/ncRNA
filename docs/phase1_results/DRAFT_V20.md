## 1. 为什么要 v2.0

v1.9 在 chr20 上过了 Go，没过 Strong，主要缺口有三个：
- **结构**：lnc L2 内含子链 Sn 为 0。chr18 诊断显示瓶颈在剪接信号：剪接信息完美时 L2 可到 0.071。
- **精度**：严格 Pr 0.42。P1.6 中线虫的 lnc 预测有一半到八成落在编码基因上；生物学验证显示约一半「新位点」有转录证据，但结构不对。
- **校准**：置信度偏高，chr20 ECE 0.34，面板物种 0.49–0.75。

按用户定的顺序，先解决剪接信号，再加编码潜能特征和置信度校准。
- 剪接信号已在 chr18 上试了两次：SpliceAI，以及用 mRNA + lnc 位点自训的网络。两次都未达有效。原因是 lnc 位点的区分能力不够：基序位置上的 lnc 剪接点 AP 只有 0.14 和 0.16。
- 所以 v2.0 主要针对精度和校准。结构线照样写进判据，但不含剪接项时预计过不了，结果如实报告。

## 3. 改动

### 3.1 主模型：去掉 chr9 后重训

- G1B，3 个 seed（42 / 123 / 456），配方与 v1.8 §15、v1.9 §16 完全相同：特征为 GENERanno 第 17 + 23 层，ont 缓存特征，2 × 4 累积，12 epoch，取第 10–12 epoch 权重平均。
- 补抽的 154 个窗口要提特征，约 0.2 GPU 小时。
- 重训每个 seed 约 4 GPU 小时，共约 12 GPU 小时。

### 3.2 剪接势能：不进 v2.0 主体（情况 B）

- 自训剪接网络在 chr18 上判为「未达有效」（`RESULT_SPLICE_OWN.md`）：
  - w = 1 过了结构线（lnc L3 Sn 0.102），但严格 Pr 0.337，没过护栏；
  - w = 0.5 守住护栏（严格 Pr 0.418），但 L3 Sn 只有 0.053。
- v2.0 默认不含剪接项。两次 chr18 诊断与真值上限如实写进论文。
- 是否把剪接项作为预注册消融放进 chr9 读取（只报告，不参与判定），由用户在冻结卡上决定。若放：
  - 剪接分数用选中的自训 S10k 网络（`SPLICE_OWN/SELECT.json`，sha256 7a57b8c8），在 chr9 两条链上打分；
  - w 固定为 0.5，不在重训后的模型上重选。chr18 上两套剪接分数都只有 w = 0.5 守住护栏；
  - 公式与 `splice_diag.py` 相同，加在三个重训主模型上，τ 与 v2.0 主体相同。

### 3.3 编码潜能特征（基因层面，推荐）

对每个预测 lnc 转录本（按链拼接外显子序列）计算：
- 最长 ORF 长度（ATG 起始到终止密码子）及其占转录本长度的比例；
- 六聚体编码分：最长 ORF 上按读框计的六聚体对数似然比，仿 CPAT。频率表只用训练染色体上 v50 的 mRNA CDS 与 lnc 外显子序列统计，不用 chr9 / chr18 / chr20。
- Fickett TESTCODE 分；
- 模型内部量：转录本外显子上 mRNA 态后验质量的平均值，以及 lnc 态后验均值（即 v1.9 的置信度）。

这些特征只进入 §3.4 的校准模型，不改解码出的结构，也不把 lnc 改判成 mRNA。

备选（不推荐，要你选）：把逐碱基的读框 / 密码子特征作为头部的额外输入通道重训。代价是要改模型、重训，而骨干 GENERanno-cds 本身已有编码信息，收益不确定。

### 3.4 置信度校准

- 模型：logistic 回归（L2 正则，C = 1，特征标准化）。输入为 §3.3 的特征，加 log 成熟长度和外显子数。目标为该预测是否命中 v50 lnc（L1 严格口径，同链外显子重叠）。
- 拟合：chr18 上三个重训主模型的全部 MEAX lnc 预测合并（τ 过滤之前）。另做 chr18 前后两半交叉拟合，报告折外 ECE 与 AUPRC_lnc，判断是否过拟合。最终用全部 chr18 拟合一次，系数写进配置。
- 校准后的概率即新的基因置信度。τ 按 v1.9 §16 的规则在 chr18 上重选：三 seed 平均严格 Pr ≥ 0.43 的 τ 中，取三 seed 平均 lnc L1 Sn 最大者，网格 0.2–0.9。
- 保留规则：只有 chr18 折外 AUPRC_lnc 不下降、且折外 ECE 下降时才保留；否则 v2.0 只用原始后验均值，τ 照 §16 重选。

## 4. chr9 判定（冻结时写死，读取前不改）

**基线**：同一批重训模型，用 v1.9 的解码（MEAX γ = 3，无剪接势能、无校准，τ 按 §16 规则在 chr18 上重选）。所有比较都是同一模型上的配对比较，按 chr9 真值 lnc 基因重抽 2,000 次（seed 0）。

| 项 | 判据（3 seed 平均） |
|---|---|
| Go 复现 | v2.0 的 lnc L1 Sn ≥ 0.20，且严格 Pr ≥ 0.40 |
| 结构（Strong 的 L2 线） | v2.0 的 lnc L2 Sn ≥ 0.05，且相对基线的 Δ 95% CI 下界 > 0 |
| 精度 | v2.0 的 lnc 严格 Pr 相对基线的 Δ 95% CI 下界 > 0，且 lnc L1 Sn 降幅 ≤ 0.03 |
| 校准 | v2.0 的 lnc 基因 ECE ≤ 0.15（10 个等宽箱，τ 过滤之前） |
| 护栏 | mRNA L1 Sn ≥ 0.80，且不低于基线 0.02 以上；被报成 mRNA 的 lnc 基因数不多于基线 |

- 次要终点：L3–L6、分层、非同源子集（chr9 对训练染色体做 §1 的 BLASTn 隔离）、生物学验证式的新位点证据（复用 `PREREG_BIOVAL.md` 的判据与已下载数据中 chr9 的部分，另需 Snaptron 的 chr9 查询，走决定卡）。
- 消融（同一次读取，只报告）：基线、+ 校准（含编码潜能，即 v2.0 主体）；用户选「只作消融」时，再加 + 剪接（w = 0.5）和 + 剪接 + 校准。
- 对照（描述性）：GENATATOR 在 hg38 chr9 上的预测（ont 已有其环境）。它的训练集可能含 chr9，标注偏乐观。
