## 结论

**按冻结规则：灰区，补跑 seed 123 后仍是灰区。A（标签是瓶颈）、B（结构是瓶颈）、C（序列定位不了）都不成立。** 计划没有规定第二次灰区之后怎么办，我没有再加 seed。

|---|---|---|---|---|

- A 不成立：只用有证据的端点没有更好，平均反而低 0.10，两个 seed 方向相反。
- B 不成立：分通道后 lnc 从 0.15 升到 0.31（约 2 倍），但离 0.50 很远。
- C 不成立：lnc 两臂都 < 0.30 的条件不满足（P-ann 0.31），mRNA 在 P-ann 下也只有 0.60。
- **计划里的一条预期是错的**：我原以为不带 CRF 的探针 seed 方差会远小于整模型，实际很大。同一个 P-ann，mRNA 起点在两个 seed 上是 0.785 和 0.414。

## 稳定的发现（7 个模型方向一致，判读规则之外，描述性）

### 1. 只有 CpG 岛型的 lnc 启动子能从序列定位

全部 929 个 lnc 起点按启动子 CpG o/e 四分位，1 kb 内比例（随机期望 0.05）：

| 来源 | Q1（最低） | Q2 | Q3 | Q4（最高） |
|---|---|---|---|---|
| 阶段 0 seed 42 / 123 / 456 | 0.064 / 0.086 / 0.064 | 0.082 / 0.073 / 0.060 | 0.126 / 0.100 / 0.126 | 0.250 / 0.172 / 0.224 |
| P-ann seed 42 / 123 | 0.073 / 0.047 | 0.146 / 0.064 | 0.221 / 0.113 | **0.608 / 0.392** |
| P-ev seed 42 / 123 | 0.026 / 0.060 | 0.034 / 0.064 | 0.130 / 0.186 | 0.267 / 0.440 |

- 7 个模型都是 Q1、Q2 ≈ 随机（0.03–0.15），Q4 明显高于随机（0.17–0.61）；每个模型都是 Q4 > Q3 > Q1、Q2。Q1 与 Q2 之间在两个模型上有小幅倒挂（阶段 0 的 seed 123、456），所以不是严格单调。
- 这与 S3（检出靠启动子 CpG）、S3-TE（TSS 在 TE 内的 lnc 更难，主要因为缺 CpG 岛）相互印证：**在这套特征下，低 CpG 的 lnc 起点不可定位；高 CpG 的部分可定位**。
- 这是分层描述，不是事前判据。Q4 的绝对水平随 seed 变化很大（0.39–0.61）。

### 2. 终点（TES）对两类都定位不了

有 polyA 证据的终点，1 kb 内比例：lnc 0.045–0.087，mRNA 0.022–0.126，全部在随机水平附近（0.05）。现有边界头、两种探针都一样。之前后验里 mRNA 终点三四成在 1 kb 内（BND），说明那部分来自解码语法（外显子结构、终止密码子之后的长度），而不是终点信号本身。

### 3. 现有边界头本身很弱，连 mRNA 也一样

阶段 0 中 mRNA 起点只有 0.27–0.43（BND 中后验是 0.70）。现有模型的 mRNA 起点定位主要由语法给出，边界头贡献不大。分类别的探针在 mRNA 起点上能到 0.41–0.79。

### 4. 有证据的 lnc 起点比无证据的更容易定位

所有来源里，有 CAGE 的 lnc 起点都 ≥ 无 CAGE 的（例如 P-ann seed 42：0.405 对 0.229）。但这和 CpG 混在一起：有 CAGE 的 lnc 启动子 CpG 更高，没有拆开。

## 含义

1. 「lnc 端点是限速步骤」这条结论仍然成立（B1、S11、BND），这次进一步细化为：**起点只有在 CpG 岛型启动子上能从序列定位；终点在这套特征下对 lnc 和 mRNA 都定位不了**。这是一条可以写进论文的生物学描述，而且与 S3、S3-TE 是同一条线索。
2. 通过换标签（P-ev）改进端点没有证据；通过分通道（P-ann）大约翻倍，但不稳定，也达不到规则要求的水平。按计划，阶段 2（整模型重训）不启动。
3. seed 方差大到能翻转两个臂的排序。若要把「分通道翻倍」当作方法结论，需要更多 seed；按投稿前「创新优先、不在稳健性上循环」的原则，我没有自行加跑。
