## 结论

- **A 剪接位点：最强的序列模型也复现了主线的三条剪接结论。**
  1. AlphaGenome 是四条染色体上最强的剪接位点模型（GTEx 定义位点），这在样本内训练下是预期的：lnc AUROC 0.949–0.972，其他模型最高 0.956。
  2. 使用量匹配后，lnc 与 mRNA 的差距仍然很小：
     - chr20 −0.007，chr18 −0.011，chr9 −0.004，chr7 +0.000；
     - |Δ| ≤ 0.011，在主线 |Δ| ≤ 0.02 的范围内，方向是 lnc 略易或持平。
  3. 可预测性仍随使用量大幅变化：lnc AUROC 从 1–9 条读段层的 0.90–0.94，升到 ≥ 1,000 条读段层的 0.995–0.997。
  4. 在注释位点层面，差距对 AlphaGenome 依旧很大：
     - v50 位点 AP：lnc 0.13–0.24，mRNA 0.82–0.84；
     - 文献口径的 top-k：lnc 转录本 0.46–0.53，mRNA 0.75–0.77。lnc 这一项并不比 SpliceAI 或自训模型高。
  - **含义**：lnc 剪接位点的困难来自低使用量和注释层面，不是模型容量的问题。用 RNA-seq 训练、而且样本内的最强模型，表现出同样的模式。这加强了主线的结论（结构瓶颈在剪接位点，而 lnc 剪接位点难在低使用量）。
- **B lnc 位点：AlphaGenome 预测的 RNA-seq 用简单分段定不出 lnc 位点，严格精度只有我们模型的约 1/4–1/5。**
  - 阈值规则：chr18 上没有一个候选阈值的严格 Pr 达到 0.43，最高只有 0.090。按规则取严格 Pr 最高的阈值（chr18 信号 80% 分位数，t = 0.030）。
  - 读数：
    - chr20：Sn **0.521** [0.491, 0.554]，严格 Pr **0.097** [0.092, 0.103]，10,003 个预测。v1.9 同一把尺子为 0.306 / 0.422，平均 631 个预测。
    - chr9：Sn **0.514** [0.488, 0.540]，严格 Pr **0.095** [0.091, 0.099]，18,295 个预测。v2.0 为 0.304 / 0.498。
  - Sn 高是因为报出的片段多 16–20 倍。在相近的 Sn 下精度差得多：
    - chr18 上 AlphaGenome Sn 0.32 时，严格 Pr 0.064；
    - 我们的 v2.0 在 chr18 上 Sn 0.253 时，严格 Pr 0.471。
  - chr20 的片段中：
    - 72%（7,251）不与任何注释基因重叠；
    - 1,696 个只落在 mRNA 上（AlphaGenome 预测的是转录，不区分编码与非编码）；
    - 宽松 Pr 0.35。
  - **含义**：最强的「序列 → 表达」模型并不能直接当 lnc 注释器用；在同一把尺子下，我们方法的精度优势成立。
  - 限定：这是预注册的朴素用法（阈值分段，不区分编码与非编码），不是 AlphaGenome 的设计用途，而且是样本内的。未注释的转录有一部分可能真实存在，严格 Pr 会低估。条款也不允许把它的输出当特征接进我们的方法。

## 3. 局限

- **样本内**：all_folds 训练用了全部人类染色体，包括 chr9 / chr20，以及 GTEx / ENCODE 的 RNA-seq。所以 A 中 AlphaGenome 的高 AUROC 和 B 中的高 Sn 都偏乐观。按保守方向，这不削弱「差距随使用量、而非模型」的结论，也不削弱我们在 B 上的精度优势。
- **B 是朴素用法**，不是 AlphaGenome 的设计用途：
  - 用所有组织的最大值，会把任何组织中的低水平转录都算进来；
  - 不区分编码与非编码。
- 更细的用法（组织特异的阈值、与编码预测结合）不在预注册范围内。而且条款不允许用它的输出改进我们的方法。
- 只用了 hg38 人类；AlphaGenome 的小鼠头没有用。

## 4. 对论文的含义

- **图 5 / 剪接部分**：加 AlphaGenome 一行，并注明「样本内」。它是目前最强的序列模型，显示出与其他模型相同的模式：使用量匹配后差距约为 0，可预测性随使用量单调上升，注释位点层面的 lnc AP 仍远低于 mRNA。审稿人「换更强的模型会不会解决」的问题因此有了直接回答。
- **主表 / 对照部分**：加「AlphaGenome RNA-seq 分段」一行。Sn 更高，但严格 Pr 只有 0.10，我们为 0.42–0.50。同时说明它不是为此设计的，而且是样本内。
