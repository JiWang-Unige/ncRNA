# RESULT P1-S2：重新设计的代理路线筛选（协议 v1.4 §11；2026-10-21）

## 设定（全部按 v1.4 预注册执行）

- **特征**：代理特征（GENERanno-1.2b-cds 第 23 层，PCA 降到 512 维）。
  - 整条 chr18 的特征在 Kaggle T4 上提取。与训练特征（A10G bf16）的一致性：逐 token 余弦相似度中位数 **0.99999**，可以视为同一套特征。
- **训练**：2,000 个窗口，12 个 epoch，余弦学习率，seed 取 42 / 123 / 456。用 300 个验证窗口上的 NLL 选 checkpoint，最佳 epoch 落在 9–12，选择过程稳定。
- **评估**：每次运行在整条 chr18 上评估一次：v50 真值，**929 个 lncRNA 基因**；S3 解码；基因置信度取后验平均；主指标是基因级 PR / AUPRC，precision 按位点合并计算。
- **算力**：Kaggle castwj，共 9 次运行，外加 chr18 特征提取，约 17 个 T4 小时。期间有 2 次 Kaggle 端的空日志错误，按"基础设施错误可重试一次"的规则各重试了一次。没有使用 ont 的 GPU。

## 解读

1. **unknown 处理是这一轮唯一稳健的差异**。
   - AUPRC 上 U-ev 比 F 高约 65%（0.056 对 0.034），位点 F1 高 0.042，Sn 高 0.027，3 个 seed 方向一致。
   - 在 Phase 0 的逐碱基、无结构设定下，同样的处理只带来很小的增益（0.5：+1.7 个百分点）。这里的效应更大，支持"unknown 边缘化需要结构化解码才能充分体现"的推测（与 coding 项目 M30 的结论一致）。
   - 这为方法主张提供了第一份可复核的支撑。它仍是代理结论，需要在正式特征上复核（P1.4 的 AB2）。
2. **语法解码与无约束解码在 AUPRC 上打平**，但工作点不同：S3 的 Pr 是 0.53，S1 是 0.38；S3 输出合法的基因结构，S1 输出碎片。结构化解码没有损失召回，还换来了更高的 precision 和合法结构，因此保留。
3. **只有 lnc 通路（S2）的方差很大**：seed 42 几乎失败（0.016），另外两个 seed 明显高于 R（0.087–0.105）。这说明没有编码通路竞争时训练更不稳定，但有时 lnc 的表现更好。这是 P1.4 消融 AB3 需要重点复核的问题，也许要配合更稳定的训练。
4. **绝对水平仍然低**：lnc 位点 Sn 约 0.1，Pr 约 0.5，内含子链几乎为 0；而 mRNA 位点 Sn 达 0.97、Pr 0.7。在代理特征（512 维 PCA、单层）和 2,000 个窗口下，lnc 是瓶颈。下一步提升主要应来自：
   - 正式特征（第 17 + 23 层，4,096 维，不做 PCA）和更多训练窗口（P1.1 / P1.3，需要 GPU 和 credits）；
   - 改进 TSS / TES 与长度建模（L2 几乎为 0，说明转录本两端和内部结构都还没有学好；若在正式特征上仍然如此，就进入 G2 的评估）。

## 对后续计划的含义

- Phase 1 设计保持不变：**G1 + S3 解码，并集语法，U-ev**。P1-S2 没有推翻任何 v1 的设计决定，并且给出了 U-ev 的正向证据。
- 等 credits 刷新后进入正式流程：P1.1 特征缓存 → P1.3 pilot → P1.4 消融（重点：AB2 U-ev、AB3 只有 lnc 的稳定性）→ P1.5 冻结后读取 chr20 / T2T。
