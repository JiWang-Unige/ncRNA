# S4 结果：鸡 / 斑马鱼零样本 lnc 预测的同线性（2026-11-04）

> 计划：`PLAN_BATCH2.md` C，判据与实现在读数前冻结（4fdfcb5、02c8630）。决定卡 `batch2-downloads`。
> 运行：ont CPU，11-04 下午。脚本 `scripts/phase1/s4/s4_synteny.py`，单元测试 `tests/test_s4_synteny.py`。
> 链文件：UCSC GRCg7b→hg38、danRer11→hg38，sha256 见 `data/batch2/MANIFEST.json`。预测来自 P1.6（τ* = 0.6），只读，不重新解码。

## 结论

- **判定（写定规则）：鸡和斑马鱼的新位点预测都没有得到同线性支持。**
  - 鸡：3 seed 平均富集 1.20 倍，没有一个 seed 的经验 p < 0.01。
  - 斑马鱼：0.45 倍，同样没有一个 seed 达到。
- **但这个检验的功效太低，不能当作「精度低」的证据**：
  - 链文件只覆盖鸡 chr5 的 **11.1%**（659 万 bp），斑马鱼 chr22 的 **2.8%**。
  - **lnc 外显子在序列层面几乎对不齐**：命中本物种 lnc 真值的预测，只有 2–5%（鸡）/ 0–2%（斑马鱼）能被映射。新位点预测的映射率为 0.5–14%。每个 seed 能映射的新位点预测只有 2–54 个。
  - **阳性对照成立，说明映射流程是对的**：落在本物种已注释基因（主要是 mRNA）上的预测，映射率为 31–48%（鸡）/ 5–10%（斑马鱼），映射后有 86–95% 落在人类同链 mRNA 基因体上。
- **含义**：
  - 按碱基对齐的 UCSC 链在鸟类 / 鱼类与人之间只保留了保守的（大多是编码的）区段，而 lnc 外显子序列保守性很低。这本身与文献一致（Necsulea 2014、Hezroni 2015），也与 S1 / S3 的「lnc 靠启动子和转录单元、不靠外显子序列」相合。
  - 用 lnc 的同线性做精度估计，需要**按基因顺序的位置同线性**：用两侧直系同源的编码基因定位，如 Hezroni 2015、slncky，而不是碱基层面的链。这需要 Ensembl Compara 的直系同源表（要下载）。是否做由用户另定。
- **一个附带观察（描述性，未在计划内）**：能映射过去的新位点预测，相当一部分落在人类的 mRNA 基因体上（鸡 13–71%，斑马鱼 44–100%，样本很小）。也就是说，零样本 lnc 预测落在保守区段时，常常是对应人类编码基因的区段：可能是本物种未注释的编码基因，也可能是 lnc / mRNA 混淆。这与 P1.6 里线虫的 lnc 预测大多落在编码基因上方向一致。

## 2. 局限

- 本检验的分母（能映射的预测）太小。对照命中率本身约 0.16–0.19：随机区段映射后常落在人类长基因体内。富集 2 倍的门槛在这种样本量下几乎不可能有统计功效。这是设计层面的问题，**在读数前没有预见到**，如实记录。
- 只用了两条面板染色体。小鼠（S5）与人的碱基对齐覆盖高得多，如需同线性证据，小鼠是更合适的物种。
