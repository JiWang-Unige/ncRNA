# 生物学验证：chr20 上 GENCODE v50 之外的候选 lnc 的转录证据（描述性，2026-11-03）

> 预注册：`PREREG_BIOVAL.md`，冻结于 GitHub 7c7bc88（决定卡 `bioval-data`，用户 11-03 下午批准）。
> 顺序：冻结 → 下载 → 只记 sha256 的清单 `BIOVAL/MANIFEST.json` 提交（8583915）→ 打开文件看格式 → 分析代码提交（a5cb8e8）→ 运行一次。
> 代码 `scripts/phase1/bioval.py`；原始输出 ont `outputs/PHASE1/BIOVAL/`，汇总 `docs/phase1_results/BIOVAL/RESULT.json`。
> 只用 P1.5 已读出的 chr20 预测，结果不回流到任何模型选择，也不用于 v2.0 开发。

## 结论

- **主终点**：「有转录证据」的定义是有剪接读段，或有非 v50 的长读长 / 组装转录本，或 CAGE 起点与 polyA 终点同时成立。
  - 候选里有转录证据的比例，三个 seed 依次为 0.689、0.549、0.545，平均 0.594。
  - 位置匹配的随机对照为 0.403、0.286、0.193，平均 0.294。
  - 三个 seed 的经验 p 都 < 0.01：100 次对照没有一次达到观察值。
- **最干净的是基因间区候选（S_inter）**，即 ±5 kb 内两条链都没有任何 v50 基因的候选，共 13、71、65 个。
  - 支持率 0.615、0.366、0.462，平均 0.481；对照只有约 0.04（0.046、0.033、0.031），约 13 倍。
  - 链翻转后降到 0.327，即信号大体有链特异性。seed 42 例外：只有 13 个候选，翻转前后相同。
- **v50 基因内或其侧翼的候选（S_other）要打折看**。支持率 0.631，对照 0.362，但链翻转后仍有 0.574。也就是说，这些位置大多有转录，却未必在模型报的那条链上：其中一部分可能是链判错，或借用了反义已注释基因的转录。
- **证据几乎都来自「区间内有剪接」，不是「结构对」**。
  - 主终点几乎全部由 S2 撑起：S2 为 0.581，对照 0.291。
  - 预测内含子与 junction 坐标完全一致（S2-exact）的只有 0.011，整条内含子链与长读长转录本一致（S4-chain）的为 0。这与结构线（L2 为 0）的结论一致：模型找到了转录区，外显子结构仍不对。
- **两端证据弱**。
  - 预测 TSS ±500 bp 内有 CAGE 的为 0.047（对照 0.008）。
  - 预测 TES ±500 bp 内有 polyA 位点的为 0.076（对照 0.040）。
  - 非 v50 的 CHESS / GTEx 长读长转录本有外显子重叠的为 0.083（对照 0.006，约 14 倍），全部来自 CHESS。GTEx FLAIR 为 0，它经过 TransDecoder 过滤，偏向编码转录本。
- **约一半已被其他目录收录（只作标签）**：与 LncBook 2.1 重叠 0.43–0.49，与 RNAcentral（Release 28）重叠 0.54–0.61。
- **一致候选**：至少 2 个 seed 在同链报出、外显子重叠的候选，合并为 111 个位点。主终点 0.829，对照 0.545，p < 0.01。
- **阳性参照**：
  - chr20 上 955 个 v50 lnc 基因（同一判据，去掉「不属于 v50」的两个排除条件）的支持率为 0.870，其中 CAGE 0.269、polyA 0.444、长读长 / 组装 0.443。
  - τ* 之后命中 v50 lnc 的预测（三个 seed 共 800 个）为 0.949。
  - 候选低于阳性参照是预期的选择效应：GENCODE 本身就用这些证据收录基因。
- **对精度的含义（描述，不改任何判据）**：严格 Pr 把这些「新位点」全部当成错。实际上约一半的新位点在区间内有剪接读段，基因间区候选的富集约 13 倍，所以严格 Pr 低估了真实精度。但证据多为「这里有转录」，候选的外显子结构和起止点大多不对，S_other 的链也不可靠，不能据此把它们算作正确的基因模型。

- Snaptron 坐标核对（只用 v50 内含子）：偏移 0 时 v50 内含子的 96.1% 能找到完全一致的 junction，偏移 ±1 时为 0，约定一致。

## 3. 数据

- 文件、大小和 sha256 见 `BIOVAL/MANIFEST.json`，共 190.9 MB。
  - 固定文件：FANTOM5 CAGE 5.5 MB、PolyASite 2.0 50.6 MB、GTEx v9 FLAIR 14.0 MB、CHESS 3.1.3 20.0 MB、LncBook 2.1 29.0 MB、RNAcentral Release 28 59.2 MB。
  - Snaptron gtexv2：chr20 共 65 个 1 Mb 查询、12.6 MB，去重后 198,600 条 junction。
- chr20 上 GTEx FLAIR 2,419 个转录本，其中 1,324 个不属于 v50；CHESS 4,024 个，其中 1,216 个不属于 v50。

## 4. 局限

- 证据都是「这里有转录」，不检验预测的外显子结构；S2-exact 和 S4-chain 几乎为 0。
- S_other 的链翻转对照几乎与原链一样高，链特异性只在 S_inter 上成立。
- seed 42 的 S_inter 只有 13 个候选。
- GTEx 读段多来自成人组织，组织特异或低表达的 lnc 可能查不到；FLAIR 有编码偏向。
- 「别处已知」的目录（LncBook、RNAcentral）彼此引用，也收录 GENCODE，只作标签，不算独立证实。
