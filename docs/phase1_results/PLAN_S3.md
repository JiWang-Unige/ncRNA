## 1. 问题

- Q1：被 v1.9 找到和没找到的 v50 lnc 基因，在启动子、U1 位点–polyA 信号轴（Almada 2013）、重复序列、转录起止证据上有什么差别？
- Q2：这些差别在老注释（v41 已有）和长读长新增（v42–v50）的基因之间是否不同？

## 2. 单位与结果变量

- 单位：chr18 上的 v50 lnc 基因（929 个）。chr20 重复用 955 个。
- 结果：是否被检出，即被某个主模型的最终预测（τ* 过滤后）按严格 L1 命中：同链外显子重叠。
  - 每个 seed 分别建模，再取 3 个 seed 的平均。
  - 检出预测来自 P1.5（chr18 为复现读取；chr20 为 11-01 的一次性读取）。只读文件，不重新解码。

## 3. 特征（只来自序列与公开注释，不来自模型）

| 特征 | 定义 |
|---|---|
| 启动子 CpG | 最外侧 TSS ± 500 bp 的 CpG 观测 / 期望比 |
| CAGE | 任一注释 TSS ± 200 bp 内有 FANTOM5 CAGE 峰（0 / 1） |
| U1 位点 | TSS 下游 1 kb（转录方向）内 GT[AG]AGT 的个数 / kb |
| PAS | TSS 下游 1 kb 内 AATAAA / ATTAAA 的个数 / kb |
| U1 − PAS | 上两项之差（Almada 的轴） |
| polyA 证据 | 任一注释 TES ± 100 bp 内有 PolyASite 2.0 位点（0 / 1） |
| 重复序列 | 合并外显子中软屏蔽碱基的比例（hg38 小写） |
| 对照项 | log 基因跨度、log 成熟长度、外显子数、单 / 多外显子 |
| 年代 | 基因 ID（去掉版本号）是否出现在 v41 |

## 4. 分析与读数（草案）

- **R1**：多变量 logistic，特征标准化，L2 很弱（C = 100），只为数值稳定。
  - 每个 seed 一个模型，报系数，以及按基因自助法 2,000 次的 95% CI（seed 0）。
  - 「相关」的定义：3 个 seed 平均系数的 CI 不含 0，且 3 个 seed 系数同号。
- **R2**：各特征按四分位分组的检出率（不建模，直接看）。
- **R3**：R1 加上与年代的交互项，回答 Q2。
- **R4**：chr20 上照做一遍，只描述，与 chr18 比较方向是否一致。

## 6. 冻结时补的实现细节（读数之前）

- 代码：`scripts/phase1/s3/s3_features.py`。
- 预测文件：
  - chr18 用 P15b 的复现读取（`outputs/PHASE1/P15b/chr18/<run>/genes.json`）；
  - chr20 用 P15 第 1 批读取（`outputs/PHASE1/P15/chr20/<run>/genes.json`）；
  - τ* = 0.6（`configs/p15_v19b.json`）。
- 真值：chr18 用 `DIAG_L2/chr18_v50.gtf`，chr20 用 GENCODE v50（与 P1.5 相同）。
- 「最外侧 TSS」：+ 链取所有转录本最小的起点，− 链取最大的终点。U1 / PAS 计数窗口是从这个 TSS 起、沿转录方向 1 kb 的正义链序列。U1 基序取 GTAAGT 和 GTGAGT（即 GT[AG]AGT）。
- CAGE：FANTOM5 峰的 thickStart / thickEnd 中点，同链。PolyASite：簇的起止中点，同链（该文件的染色体名不带 chr）。
- 外显子数和成熟长度取最长转录本；重复序列比例在合并外显子上计算。
- 逻辑回归：L-BFGS，截距不罚，C = 100。R3 的交互项为标准化特征 × 中心化后的年代。
- 只用 CPU（ont，nice 19，核 2–31）。
