# PLAN BND：lnc 端点定位失败的诊断（读数前冻结，2026-11-12）

> 起因：`RESULT_B1.md`（lnc 端点偏差中位 8–22 kb，严格位点 Sn 0.064）与 `RESULT_S11.md`（区间分割模型需要 < 1 kb 的端点精度）。问题：端点信号是模型没学到，还是学到了但在后验拼接 / 解码时丢了，还是真值端点本身不可靠？
> 性质：chr18（开发染色体）上的 CPU 诊断，只读 v1.9 三个主模型已有的后验（`outputs/PHASE1/P15/chr18/<run>/post.npy`）和预测。不重训、不重读模型、不碰 chr20 / chr9。探索性，结论用于决定下一步做什么，不作为论文的检验。
> 脚本：`scripts/phase1/bnd/bnd_diag.py`（本提交之后写），输出 `outputs/PHASE1/BND/BND.json`。

背景事实（来自代码）：后验由 `chromosome_marginals` 在互相独立的 24,576 bp 小块上做前向–后向得到（步长 20,472，只留中段），所以相邻小块之间每 20,472 bp 有一条接缝；整条染色体的解码在拼好的后验上进行。lnc 基因跨度常超过一个小块。

## 读数

- **D0 接缝**：最终预测（lnc 置信度 ≥ τ 0.6；全部 mRNA）的基因起点、终点落在接缝 ±100 bp 内的比例；均匀分布下的期望是 201 / 20,472 ≈ 1.0%。真值基因端点作对照。
- **D1 错误类型**：对每个按 L1 被命中的真值 lnc 基因，取与它跨度重叠最大的 lnc 预测，按 R_g（覆盖真值的比例）和 R_p（落在真值内的比例）分成：两者 ≥ 0.5（定位合格）、预测过长（R_g ≥ 0.5 > R_p）、预测过短（R_p ≥ 0.5 > R_g）、两者都 < 0.5（错位）。另报无跨度重叠的。
- **D2 解码器**：同一份后验改用逐碱基取大（S1，`p15_score.s1_genes`）解码，τ 同为 0.6，按 B1 的 S50 / S25 口径打分，与 MEAX（B1 的 chr18 数字）比较。
- **D3 后验里的端点信号**：记 M(x) 为基因所在链上该类别 4 个基因状态的后验之和。
  - 「后验检出」的基因：基因跨度内 M 的均值 ≥ 0.5。
  - 台阶：TSS 内侧 1 kb 的 M 均值 − 外侧 1 kb 的 M 均值；TES 同理。
  - 起止距离：在真值 TSS（TES）±50 kb 内，M 由 < 0.5 升到 ≥ 0.5（按转录方向；TES 为由 ≥ 0.5 降到 < 0.5）的最近位置到真值端点的距离；报中位数、≤ 1 kb 的比例。只对后验检出的基因算。
  - lnc 与 mRNA 各算一遍，mRNA 作参照。
- **D4 真值端点的可靠性**：真值 lnc 基因最外侧 TSS ±200 bp 有 FANTOM5 CAGE 峰、TES ±100 bp 有 PolyASite 簇的比例；S50 Sn 按「两端都有 / 只有一端 / 都没有」分层。另报：L1 命中的 lnc 预测，其起点 ±200 bp 有同链 CAGE 峰的比例，对比其命中的真值基因 TSS 的比例和随机位置（预测起点平移 +50 kb）的比例。

## 判读（可同时成立）

| 判断 | 条件（三个模型平均） |
|---|---|
| 接缝是端点误差的主要来源 | lnc 预测端点在接缝 ±100 bp 内的比例 ≥ 20% |
| 解码器丢了端点信息 | S1 的 lnc S50 Sn ≥ MEAX 的 2 倍，且 ≥ 0.10 |
| 后验里就没有 lnc 端点信号 | 后验检出的 lnc 基因中 TSS 起止距离 ≤ 1 kb 的比例 < 30%，而 mRNA ≥ 60% |
| 真值端点不可靠占了相当一部分 | 两端都有证据的 lnc 基因 S50 Sn ≥ 都没有的 2 倍 |

- 都不满足时如实写「未定位到单一原因」。
- 下一步的方向由判断决定：接缝 → 改后验的计算方式（更长上下文 / 跨块前向–后向），不必重训；解码器 → 换解码；后验无信号 → 需要训练侧的端点监督（CAGE / polyA 作标签或输入），是新的方法工作；真值 → 评价与训练标签改用有端点证据的子集。
