## 结论

- **§4.1 主判定：Go 复现、精度、校准、护栏通过；结构未过（预期内）。**

  | 判定（3 seed 平均） | 基线 | v2.0 | 判据 | 结果 |

  | 精度：Δ 严格 Pr [95% CI] | — | **+0.041 [0.028, 0.055]** | CI 下界 > 0 | 过 |

  | 校准：lnc 基因 ECE（τ 之前） | 0.295 | **0.041** | ≤ 0.15 | 过 |
  | 护栏：mRNA L1 Sn | 0.883 | 0.883 | ≥ 0.80，不低于基线 0.02 以上 | 过 |
  | 护栏：被报成 mRNA 的 lnc 基因 | 47.3 | 47.3 | 不多于基线 | 过 |

  - chr9 上的增益与 chr18 开发时的预期几乎完全相同：ΔPr 都是 +0.041，ΔSn 都是 −0.014。校准和 τ 在 chr18 上没有过拟合。
  - 宽松 Pr（不计新位点）：v2.0 为 0.73，基线为 0.66。
  - 与人类 chr20（v1.9，同一把尺子）相比，chr9 的 v2.0 Sn 相近，严格 Pr 更高：0.304 / 0.498 对 0.306 / 0.422。

- **§4.2 主线复核：三条全部复现。**

  | 复核 | chr9 读数 | 判据（§17.1，读 chr9 前写定） | 结果 |
  |---|---|---|---|
  | R-S1 剪接可预测性（判读：自训 S10k） | 匹配差距 **+0.008** [−0.008, 0.024]；AUROC 从最低到最高使用量层升高 lnc **0.135**、mRNA **0.114**；lnc 内含子 GTEx 读段中位数为 mRNA 的 **3.8%**（383 对 10,032） | \|Δ\| ≤ 0.03；两类都升 ≥ 0.05；比值 < 1/5 | 复现 |

  | R-S3 位点特征（v2.0 预测） | 启动子 CpG **+0.32** [0.22, 0.44]，log 基因跨度 **+0.58** [0.43, 0.73]，都满足「相关」 | 两项都「相关」 | 复现 |

  - chr9 是 SpliceAI 的测试染色体，自训 S10k 也没在它上面训练过，所以 R-S1 在这里**所有剪接模型都是样本外**，这是对 S1R 那条「差距很小、使用量是主因」最干净的一次检验。
  - 三个模型的匹配差距都在 0 附近：SpliceAI +0.001 [−0.010, 0.012]，自训 +0.008，Pangolin −0.007。
- **对论文的含义**：在一条全新的、所有剪接模型都样本外的人类染色体上，主线的三条结论都复现了：
  1. lnc 位点能从序列找到，且靠的是启动子 CpG 与长转录单元；
  2. 结构定不下来，瓶颈是剪接位点而不是边界；
  3. 使用量匹配后，lnc 与 mRNA 剪接位点可预测性的差距很小，可预测性主要随剪接使用量变化，而注释的 lnc 内含子使用量低约 26 倍。

  v2.0 同时给出了一个已校准、精度更高的工具版本。
