# PLAN END：lncRNA 端点监督实验（草案，2026-11-13，未冻结）

> 起因：`RESULT_BND.md`。lnc 端点定不准，唯一成立的原因是后验里没有 lnc 端点信号（起点定位到 1 kb 内：lnc 23%，mRNA 70%）；接缝、解码器、真值端点不可靠都已排除。端点问题在训练侧。
> 要回答的问题：**lncRNA 的转录起点能不能从序列定位？** 三种可能：(a) 能，只是现有标签太脏、模型学不到；(b) 能，现有标签也够，只是边界头的结构把 lnc 和 mRNA 混在一起；(c) 在我们的特征下就定位不了。三种结果都能写进论文。
> 性质：开发染色体 chr18 上的探索性实验，不碰 chr20 / chr9 / T2T。不下载新数据（FANTOM5 CAGE、PolyASite 2.0 已在 ont `data/bioval/raw/`）。阶段 2 另需冻结。

## 0. 设计依据（新统计，2026-11-13，ont CPU）

**现有边界头的结构**（`heads/c0.py` `C0BHead`，`grammar/g1.boundary_edges`）：
- 只有 4 个通道：正负链各一个起点、一个终点，**不分 lnc / mRNA**。
- lnc 和 mRNA 进出基因的加分用同一条 logit，只乘一个按类别学的系数。训练后 mRNA 的系数升到 1.13–1.25，lnc 的系数几乎没离开初始值 1.0（0.999–1.03）。也就是说，模型几乎没有用边界头去决定 lnc 从哪里开始。

**现有端点标签**（`prep_events.py`）：
- 正例：GENCODE v50 Ensembl_canonical 转录本端点 ±10 bp。
- 忽略：非规范转录本端点 ±50 bp，以及 U-ev 未知区。
- 其余都是负例，正负比约 1 : 2,500，不加权 BCE。

**标签质量**（v2.0 的 3,000 个训练窗口，`data/p1v20`）：

| | lnc | mRNA |
|---|---|---|
| 窗口内的规范起点标签 | 1,614 | 1,614 |
| 其中 ±200 bp 有同链 FANTOM5 CAGE 峰 | **494（31%）** | 1,495（93%） |
| 窗口内的规范终点标签 | 1,494 | 1,799 |
| 其中 ±100 bp 有同链 PolyASite 簇 | 565（38%） | 1,601（89%） |
| 有端点在窗口内的基因中，两端落在同一窗口 | 911 / 2,168 | 667 / 2,693 |

全基因组（去掉 chr18 / chr20 / chr9）的规范转录本：lnc 起点有 CAGE 25%（7,891 / 31,368），终点有 polyA 35%，两端都有 10.5%；mRNA 分别为 92%、87%、82%。

所以 lnc 的起点标签里约七成没有任何起始证据；而这些标签与 mRNA 的高质量标签共用一个通道。

## 1. 阶段 0：现有边界头的原始输出（基线，约 0.5 GPU 小时）

- v2.0 三个主模型（`v20-g1b-{42,123,456}-ke`，avg10-12）在 chr18 上前向一次，保存边界 logit（[L, 4]，float16），不解码。
- 按第 3 节的指标打分。这一步回答「边界头本身有没有 lnc 起点信号」，补上 BND 的局限（BND 看的是并入后的后验）。
- 代码改动：`train_formal_ont.py` 的 eval-only 路径加 `--dump-bnd`（`evaluate_chromosome` 里已经算出 `bnd`，只需保存）。

## 2. 阶段 1：端点探针（2 个臂，约 2 GPU 小时）

只训练端点，不带 CRF，用来隔离「标签」和「结构」两个因素。

- **架构**：与 C0 相同的隐层（投影 + 双向 GRU + DNA 卷积 + 融合），输出 8 个通道：{lnc, mRNA} × {起点, 终点} × {+, −}。冻结的 GENERanno 特征照旧（`data/p1_feat/train.npy` + v2.0 的替换窗口）。
- **训练**：v2.0 的 3,000 个训练窗口；不加权 BCE（与现有边界头一致）；AdamW lr 1e-3，batch 8，余弦退火；固定 4 个 epoch，**取最后一个 epoch，不做验证集选择**（现有验证窗口都在 chr18 上，用它选模型就和评估重叠了）；seed 42。
- **两个臂只差标签策略**：

| 臂 | 正例 | 忽略 | 负例 |
|---|---|---|---|
| P-ann | 规范转录本端点 ±10 bp（与现有标签相同，只是按类别分通道） | 非规范端点 ±50 bp；U-ev 未知区 | 其余 |
| P-ev | 有证据的规范端点：起点 ±200 bp 内有同链 CAGE 峰、终点 ±100 bp 内有同链 polyA 簇；正例放在**证据位置**（峰中点）±10 bp | 没有证据的规范端点 ±1 kb；非规范端点 ±50 bp；U-ev 未知区 | 其余 |

- P-ev 对 lnc 和 mRNA 用同一规则，保证两个臂只差「是否要求端点证据」。
- 一个 seed 的理由：探针不带 CRF，方差应远小于整模型；判读规则要求的效应量（0.15–0.20）远大于预期的 seed 噪声。只有结果落在灰区时才补第二个 seed。

## 3. 评估（chr18，CPU）

主读数 **Loc1k**：对每个真值基因的规范起点，在同链对应通道的得分上取 [起点 − 20 kb, 起点 + 20 kb] 内的最大值位置，到真值起点 ≤ 1 kb 的比例。

- 随机期望约 5%（2 kb / 40 kb）。±20 kb 的范围对应 B1 里 lnc 端点偏差的量级，正好是解码器需要修正的范围。
- 阶段 0 用现有的不分类别起点通道；阶段 1 用 lnc 起点通道评 lnc、mRNA 起点通道评 mRNA。

**分层**（主判读用第一层）：
1. lnc，起点 ±200 bp 有 CAGE（chr18 约 150 个；真值可信）；
2. lnc，无 CAGE；
3. mRNA，有 CAGE（参照）；
4. lnc 按启动子 CpG 四分位（与 S3 对照）。

**次要读数**：Loc200（≤ 200 bp）；终点的同样指标（证据用 polyA）；全染色体的峰级 AUPRC（得分局部极大、500 bp 内非极大抑制，500 bp 内命中真值起点算对）。

## 4. 判读规则（冻结前可改，冻结后不改）

以 lnc 有 CAGE 的子集为准：

| 结果 | 条件 | 结论 | 下一步 |
|---|---|---|---|
| A 标签是瓶颈 | P-ev Loc1k ≥ 0.50，且 ≥ P-ann + 0.15 | lnc 起点能从序列定位，现有标签太脏学不到 | 阶段 2，用 P-ev 标签 |
| B 结构是瓶颈 | P-ann Loc1k ≥ 0.50，且阶段 0 ≤ P-ann − 0.15 | 分通道就够，现有边界头把 lnc 和 mRNA 混在了一起 | 阶段 2，只改分通道 |
| C 序列定位不了 | P-ann 和 P-ev 都 < 0.30，而 mRNA（有 CAGE）≥ 0.60 | 在这套特征下 lnc 起点不可定位，这是一条负的生物学结论 | 停止端点方法工作；论文按「端点是限速步骤且序列不可解」写 |
| 灰区 | 其余 | 不下结论 | 补 seed 123 再判 |

- A 和 B 可以同时成立（都 ≥ 0.50），此时按 A 走，阶段 2 同时改通道和标签。
- 无 CAGE 的 lnc 子集只描述：它的真值起点本身可能不准，Loc1k 低不能归因于模型。
- 若 C 成立，再看 CpG 分层：如果高 CpG 的 lnc 起点可定位、低 CpG 的不可，结论细化为「只有 CpG 岛型 lnc 启动子能从序列定位」，与 S3、S3-TE 的结果相互印证。

## 5. 阶段 2（只在 A 或 B 成立时做；需另写协议节并冻结）

- 模型：G1B 的边界头改为 8 通道分类别（lnc 进出用 lnc 通道，mRNA 用 mRNA 通道），标签按阶段 1 胜出的策略；其余与 v2.0 相同（训练窗口、12 个 epoch、avg10-12、MEAX、校准、τ 规则）。
- 开发：chr18 上按 B1 的 S50 / S25 口径和原 L1 一起报；同时报 lnc 起点 Loc1k，确认信号进到了后验。
- 测试：冻结后 chr20 与 chr9 各读一次，与 v1.9（chr20）、v2.0（chr9）在同一口径下比较。主终点：lnc S50 Sn；护栏：mRNA L1 与 lnc L1 不降超过 0.02。
- seed：整模型的 seed 方差在本项目里很大（B1 中 chr20 的 S50 Sn 三个 seed 为 0.041 / 0.102 / 0.050），这是一条核心 claim，所以建议 3 个 seed。由用户决定。
- 算力：约 3 GPU 小时 × 3 seed + 读取约 2 小时，ont 4090，共享 GPU 时约 2 天。

## 7. 风险

- CAGE 偏向高表达、广泛表达的转录本，有 CAGE 的 lnc 子集更容易（S3：高 CpG 更易检出）。所以 A / B 的结论只对「有起始证据的 lnc」成立，论文里要这样限定。
- P-ev 的正例比 P-ann 少约七成（lnc），如果 P-ev 更差，可能只是正例太少；这时看 mRNA 是否也变差来区分。
- 探针成功不保证阶段 2 成功：起点信号进入 CRF 后还要和外显子、内含子状态竞争。阶段 2 的 chr18 开发结果会先看 Loc1k 是否传到了后验。
