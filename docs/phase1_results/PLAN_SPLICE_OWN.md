# 自训剪接位点网络 + chr18 再诊断：设计与判据（看结果前写定，2026-11-03）

> 来源：用户 2026-11-03 下午在对话中回复「按照推荐推进」，即决定卡 `splice-next` 第一项。
> 性质：探索性诊断，只用 chr18 判读，不属于任何冻结判定。达标才把剪接项写进 v2.0（v2.0 的测试数据 chr9 已锁定，见 `configs/v20_testdata.json`）。
> 代码：`scripts/phase1/splice_diag/own_splice.py`、`own_queue.sh`；诊断沿用上午的 `splice_diag.py` 与 `summarize.py`，不改。
> 本文件与代码提交后才开始训练；chr18 打分在选定网络之后进行。

## 1. 为什么

上午的 SpliceAI 诊断（`RESULT_SPLICE_DIAG.md`）未达有效，但真值剪接点上限（seed 42）的 lnc L2 Sn 为 0.071，超过 Strong 线。SpliceAI 对 lnc 真剪接点打分低（中位 0.12），压不住模型在 lnc 里切出的假内含子。这一轮检验：用 mRNA 和 lnc 剪接点一起训练的剪接网络，能否把结构推过判据。

## 2. 数据

- 剪接点：GENCODE v50（与训练标签同一文件，sha256 83fba3e9）中 ruler 类别为 mrna 或 lnc 的基因，所有转录本的所有内含子两端。位点约定与 `sai_score.py` 相同：acceptor 记在外显子第一个碱基，donor 记在外显子最后一个碱基，以转录方向为准。
- 染色体：
  - 训练：chr1–8、10–17、19、21、X；
  - 剪接网络自己的验证（选 epoch 和变体）：chr22；
  - 不碰：chr9（v2.0 测试）、chr18（开发，只在第 5 节打分）、chr20（已读）。
- 标签：每个位置三类（无 / acceptor / donor），N 位置不计损失。− 链的位点在反向互补序列上学，与 SpliceAI 相同。
- 其他类别基因（小 RNA、假基因等）的剪接点不作正例，记为「无」。

## 3. 模型与训练

- SpliceAI 式残差空洞卷积，32 通道，每 4 个残差块接一条 1×1 跳连，输出三类 softmax。两个变体：
  - S2k：RB(11,1)×4、RB(11,4)×4、RB(21,10)×4，上下文 ±1,000 nt，约为卡上写的规模；
  - S10k：S2k 再加 RB(41,25)×4，上下文 ±5,000 nt。
- 每 epoch 64,000 个 5,000 nt 的块：40% 以随机 lnc 剪接点为中心（偏移均匀），40% 以随机 mRNA 剪接点为中心，块方向取该位点的转录方向；20% 在染色体上均匀随机，方向随机。每个 epoch 的块由固定种子（seed 0 与 epoch 号）决定。
- 交叉熵；AdamW，学习率 1e-3 余弦降到 1e-5，weight decay 1e-4；batch 16；10 epoch；bf16 autocast。
- 算力：ont 4090，经 `gpu_gate.sh`，本进程显存上限 30%。闸门关闭时存档退出，重开后从同一步、同一批数据继续。

## 4. 选择（只用 chr22，不看 chr18）

- 指标：chr22 上的 lnc 剪接点 average precision。acceptor / donor × 两条链共 4 列取平均；候选位置为满足语法剪接基序的位置，去掉只属于 mRNA 的剪接点（它们是真位点，不作正例也不作负例）。
- 每个变体取该指标最高的 epoch，再在两个变体中取较高者。只有选中的这一个网络给 chr18 打分。
- 同时记录 mRNA 剪接点 AP，仅作描述。

## 5. chr18 诊断（与上午相同的流程）

- 选中的网络给 chr18 两条链打分，输出格式与 `sai_score.py` 相同；另报它在 chr18 真值剪接点上的分数分布和 AP，与 SpliceAI 对照（SpliceAI 训练过 chr18，对照偏向 SpliceAI）。
- 势能、解码、读数与上午完全相同：边界态加 w ×［log max(p, 1e-6) − log π］，π 为满足基序位置上的平均分数；三个主模型 g1b-42 / 123 / 456-ke（configs/p15_v19b.json），v1.9 MEAX（γ = 3、τ = 0.6）；w ∈ {0.5, 1, 2}，共 9 次。基线（w = 0）沿用 P1.5 第 2 批的 chr18 读取，真值上限沿用上午的结果。

## 6. 判据（沿用上午写定的，`own_splice.py verdict` 自动判）

某个 w 同时满足：
- **结构线**：3 seed 平均 lnc L3 剪接点 Sn ≥ 0.10，且三个 seed 的 lnc L3 Sn 都高于各自基线；或 3 seed 平均 lnc L2 内含子链 Sn ≥ 0.05，且三个 seed 的 lnc L2 Sn 都高于各自基线；
- **精度护栏**：3 seed 平均 lnc L1 Sn 比基线降幅 ≤ 0.03，且 3 seed 平均严格 Pr ≥ 0.40。

满足则判「诊断有效」，剪接项写进 v2.0 草案；不满足则如实报告，v2.0 只含编码潜能特征与置信度校准（决定卡 `precision-order`），剪接项是否保留由用户在 v2.0 草案上决定。w 是在 chr18 上挑的，只代表可达上限；正式结论只看 chr9 的一次性读取。

## 7. 事先说明的局限

- 选择与判读都在 chr18 以外或 chr18 上进行，没有触碰 chr9 / chr20。
- 训练标签只有 v50，未注释的真剪接点会被当成负例。
- 两个变体只按 chr22 二选一，不在 chr18 上比较。
