# PLAN S11：两阶段结构的「边界抖动门」（读数前冻结，2026-11-12）

> 起因：`CONVERGENCE_20261112.md` 第 3 条。S1b 说明我们自己的解码器在真值边界下 lnc L2 只有 0.003，但 GENATATORs 在给定转录本区间内报告 25.6%。问题：专用的区间分割模型对**边界误差**有多敏感？只有它能容忍我们量级的边界误差（B1：TSS / TES 偏差中位 8–22 kb / 9–31 kb，跨度比 0.3–3），两阶段（我们找位点 → 它分割）才值得做。
> 性质：探索性的停止门，开发染色体 chr18，不碰 chr20 / chr9 / T2T。
> 模型：`models/genatator-caduceus-ps-multispecies-segmentation`（rev 2716f2b2，已在 ont），按管线默认方式调用：`infer_segmentation_tracks_with_rc`（区间正链序列，反向互补平均，context 250 kb，sigmoid）→ `build_segmentation_result`（外显子对内含子逐碱基取大，splice_filter 开）→ 首尾为内含子则拒绝（intronic_filtering 开）。不用它的区间发现和类型分类。
> 注意：GENATATOR 的训练染色体包含 chr18，所以本门在 chr18 上对它是**样本内**的，结果是乐观上限。门不过即可停；门过了也只说明值得在 chr20（它的验证集）上再看。

## 1. 基因与条件

- 基因：chr18 GENCODE v50 的 lnc 基因中有多外显子转录本、且基因跨度 ≤ 60 kb 的；按基因 ID 排序后用 numpy rng(0) 抽 200 个（不足则全用）。
- 每个基因的条件（区间均在正链坐标上，链取真值）：

| 条件 | 区间 |
|---|---|
| A | 该基因跨度最长的多外显子转录本的精确区间 |
| B | 真值基因跨度 |
| O1 / O5 / O10 / O20 | A 的两端各向外扩 1 / 5 / 10 / 20 kb |
| I1 / I5 | A 的两端各向内裁 1 / 5 kb（剩余 < 200 bp 的基因在该条件记为失败） |

## 2. 读数

- **链正确率**（主读数）：预测外显子链的内含子集合与该基因任一真值转录本的内含子链完全相同。分母是全部入选基因（被拒绝、无外显子、单外显子都算错）。
- 连接精度 / 召回：预测内含子对该基因全部真值内含子。
- 被拒绝比例（首尾为内含子 / 无外显子）、单外显子比例。

## 3. 判读规则

设 ref = max(A, B) 的链正确率。

1. ref < 0.10 → 停（该模型在我们的真值与口径下本身就恢复不了结构）。
2. O10 的链正确率 < 0.2 × ref → 停，不把两阶段当作端到端的升级方向。
3. O10 与 O20 都 ≥ 0.5 × ref，且 I1 ≥ 0.5 × ref → 过门，下一步把 v1.9 的 chr18 预测位点（原始区间与加 padding）送入同一模型读端到端 L2，分母为全部多外显子 lnc 基因（另写计划）。
4. 其余情况 → 记为「对边界敏感」，不进入下一步；结果写进论文的局限与讨论。

- 向内裁剪单列出来，是因为它会直接切掉外显子；我们的预测两种误差都有（B1 的跨度比 0.3–3）。
- 不调模型的任何参数；不换基因集；只跑一次。
