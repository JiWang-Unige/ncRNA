## 结论

- **复现核对通过**：3 个主模型在 chr18 上的后验与基因预测，与 P1.5 第 2 批读取逐字节一致（REPRO_OK）。
- **判定（写定规则）：「零样本位点检出迁移到小鼠」**。
  - 3 seed 平均 lnc L1 Sn **0.280**，严格 Pr **0.372**。判据为 ≥ 0.20 且 ≥ 0.30。
  - 作为参照，人类 chr20（留出染色体）为 0.306 / 0.422。小鼠的 Sn 低 0.03，严格 Pr 低 0.05。
  - 宽松 Pr（不计新位点）为 0.58 / 0.60 / 0.52。
- **其余读数与人类一致**：
  - mRNA L1 Sn 0.852、严格 Pr 0.967（人类 chr20 为 0.861 / 0.948）。
  - lnc 内含子链 L2 为 0（人类同样为 0）。
  - 护栏 8.0 / 8.7，低于人类 chr20 的 10.0 / 12.3。
  - 置信度仍未校准：ECE 0.385（人类 0.337）。
- **seed 间的高低顺序与人类相同**：123 > 42 > 456。说明 seed 间差别来自模型本身，不是物种的问题。
- **对论文的含义**：P1.6 面板物种的 lnc 注释稀疏，精度读数不可靠。小鼠注释完整，在它上面，只用人类训练的模型得到的位点检出与人类留出染色体相差不到 0.05。「位点能从序列找到」这条在近缘物种上成立。结构（L2）同样为 0，与主线一致。

## 2. 局限

- 只有一条小鼠染色体。chr19 是小鼠最短的常染色体之一，基因密度中等。
- 没有在小鼠上跑任何基线：GENATATORs 的多物种版本训练含小鼠，是样本内的，计划里没有放它。
- GENERanno 骨干的预训练语料可能含小鼠序列（不含注释）。
- GENCODE vM39 小鼠的 lnc 注释也在扩张，严格 Pr 同样会低估真实精度，与人类相同。
