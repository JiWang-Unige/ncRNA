# P1-G 判读：G1B（G1 + 边界头）与 G2-PH（逐碱基相位型语法），对照 R（G1 + S3）

日期：2026-10-26。协议：v1.6 §13（规则 1）与 v1.7 §14（规则 2–7），两者都在看到任何结果之前冻结。
共同设定：代理特征（GENERanno-1.2b-cds 第 23 层，PCA-512），2,000 个训练窗口，v50 + U-ev 标签，12 epoch，seed {42, 123, 456}；
在整条 chr18（929 个 v50 lnc 基因）上评估一次。R 复用 P1-S2 的三个 seed，不重跑。未读 chr20。
运行：Kaggle castwj，2026-10-24 由 ont 调度器完成（G1B 456 训练 + 三个 G1B 评估 + G2-PH smoke + 三个 seed 训练与评估）。
聚合脚本：`scripts/phase1/aggregate_p1g.py`；数字：`docs/phase1_results/P1G/p1g_summary.json`。

## 主指标与次要指标（3 个 seed 均值）

| 臂 | AUPRC_lnc | 位点 F1 | lnc L1 Sn | lnc L1 Pr | lnc L2 Sn | mRNA L1 F1 | 预测 lnc 数 |
|---|---|---|---|---|---|---|---|
| R（G1 + S3） | 0.0560 | 0.175 | 0.105 | 0.529 | 0.0004 | 0.818 | 169 |
| G1B | **0.0796** | **0.294** | **0.275** | 0.316 | 0.0028 | 0.804 | 937 |
| G2-PH | 0.0393 | 0.189 | 0.137 | 0.304 | 0.0016 | 0.818 | 433 |

逐 seed 的 AUPRC_lnc：R 0.0521 / 0.0609 / 0.0549；G1B 0.0828 / 0.0711 / 0.0849；G2-PH 0.0318 / 0.0450 / 0.0411（seed 42 / 123 / 456）。

## 判定（按冻结规则逐条）

1. **规则 1，G1B 对 R：通过。** Δ = +0.031 / +0.010 / +0.030，均值 +0.024，三个 seed 同号。→ **G1B 作为改进的 G1 基线。**
2. **规则 2，G2-PH 对 G1 基线（G1B）：不通过。** Δ = −0.051 / −0.026 / −0.044，均值 −0.040，三个 seed 同号为负；
   lnc L2 Sn 均值 0.0016 < 0.01。→ G2-PH 不替换 G1。
3. 规则 3（mRNA 保护）：G2-PH 的 mRNA L1 F1 与 R 持平（0.818 对 0.818），未触发；G1B 比 R 低 0.014，在 0.05 以内。
4. 规则 4（简约）：不适用（G2-PH 对 R 本身就更差：Δ 均值 −0.017，三个 seed 同号为负）。
5. 规则 5：不适用（G1B 优于 R）。
6. 规则 6（G2-PH-1 消融）：只在 G2-PH 替换后运行，**不触发**。
7. 规则 7：没有不同号的比较；没有基础设施重试。

**结论**：代理特征下的语法选择为 **G1B**。G2-PH 在代理特征下不如 G1B，也不如 R；G2-PH 与候选格 G2 的代码保留，正式特征阶段是否把它们作为消融臂复核，需要在下一版协议里写明（§14 只在规则 5 的情形下规定了复核）。

## 解读（次要，不改变判定）

- G1B 的收益主要来自召回：lnc 位点 Sn 从 0.105 升到 0.275（2.6 倍），预测数从 169 升到 937，Pr 从 0.53 降到 0.32；位点 F1 从 0.175 升到 0.294。
- 绝对水平仍低于正式 Go 判据的召回门槛（位点 Sn ≥ 0.20、Pr ≥ 0.40）：G1B 的 Sn 过线、Pr 不过线。这只是代理特征上的参考，Go 判据针对正式特征和 chr20。
- **内含子链仍然失败**：三臂的 lnc L2 Sn 都 ≤ 0.004。这是方法线现在最大的缺口。

## 机制核对（v1.5 诊断，每臂取 AUPRC 中位 seed；只报告不判定）

| 指标（lnc，L1 命中的预测） | R（seed 123，v1.5） | G1B（seed 42） | G2-PH（seed 456） |
|---|---|---|---|
| 预测跨度 / 真值跨度，中位 | 2.77 | **1.04** | 1.85 |
| 一个预测跨 ≥ 2 个真值基因的比例 | 0.56 | **0.25** | 0.36 |
| 落在真值跨度外的预测内含子比例 | 0.72 | **0.56** | 0.71 |
| TSS / TES 偏差中位（bp） | 9,834 / 16,985 | 8,830 / 9,305 | **2,982** / 8,301 |
| 预测内含子中位长度（真值约 4.1–4.6 kb） | 18.4 kb | **8.9 kb** | 30.1 kb |
| 精确接头比例（预测内含子） | 0.043 | **0.085** | 0.035 |
| 真值内含子精确找回比例（均值） | 0.034 | **0.081** | 0.013 |
| mRNA 精确接头比例 | 0.715 | 0.779 | 0.767 |
| mRNA 碎片化（真值基因被 ≥ 2 个预测命中的比例） | 0.55 | 0.37 | **0.27** |

注：R 的诊断沿用 v1.5（seed 123）。按本表的 AUPRC，R 的中位 seed 其实是 456（0.0549），v1.5 写的 seed 123 是三者最高；此处如实注明，未重跑。

- G1B 的边界头基本解决了“停不下来”：跨度比从 2.77 降到 1.04，合并相邻基因的比例减半。
- G2-PH 的 TSS 定位最好，但内含子被拉得过长（中位 30 kb），跨度外内含子比例与 R 相当；长度阶段链在代理特征下没有学到合适的内含子长度。
- 三臂共同的问题是剪接点：lnc 预测内含子中只有 4–9% 的接头精确，> 85% 偏差超过 100 bp。代理特征（PCA-512）对 lnc 剪接位点的信号太弱，这与 Phase 0 0.4 探针的结论一致（lnc 外显子 AUPRC 只有先验的 2.4 倍）。
