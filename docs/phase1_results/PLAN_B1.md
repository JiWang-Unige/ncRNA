# PLAN B1：严格的一对一位点评价（读数前冻结，2026-11-12）

> 起因：`CONVERGENCE_20261112.md` 第 1 条。现有 L1 = 同链、同类别外显子重叠 ≥1 bp 即命中，一个预测可命中多个真值；预测跨度约为真值的 2.8 倍，L1 可能高估「发现独立基因位点」的能力。
> 性质：对**已有预测**重新打分。不重读模型、不重新解码、不改阈值（τ 用各配置冻结的值）。chr20 / chr9 上的数字是描述性重评，不回流到任何模型选择。
> 脚本：`scripts/phase1/b1/b1_strict.py`（本提交之后写，输出 `outputs/PHASE1/B1/B1.json`，汇总进 `docs/phase1_results/B1/`）。

## 1. 定义

- 真值基因跨度 g：该基因全部转录本外显子的最小起点到最大终点。预测跨度 p：预测基因最左到最右外显子边界。
- 候选配对：同类别（lnc 对 lnc，mRNA 对 mRNA）、同链（预测无链时两条链都可配），且
  R_g = |p∩g| / |g| ≥ θ，R_p = |p∩g| / |p| ≥ θ。
- **主口径 S50**：θ = 0.5。**副口径 S25**：θ = 0.25。
- 一对一：在候选配对图上求最大基数二分匹配。Sn = 匹配数 / 真值基因数；Pr = 匹配数 / 预测数（即「严格 Pr」，未注释的真 lnc 算错）。
- 原 L1 照旧并列报告。
- 同时报告（描述）：
  - 每个 L1 命中的预测命中的同类真值基因数；命中 ≥2 个的预测比例；
  - 预测跨度 / 其重叠最大的同类真值跨度（中位数）；TSS、TES 偏差中位数；
  - S50 匹配对的跨度 IoU 中位数。

## 2. 评什么

| 集 | 预测 | 阈值 |
|---|---|---|
| chr18（开发）、chr20 | v1.9 三个主模型（P15 读取） | τ = 0.6 |
| chr9 | v2.0 三个模型（V20 读取）：基线 τ 0.62 与校准后 τ 0.36 | 冻结值 |
| chr20 | GENATATOR（Phase 0 预测）、SegmentNT（t0.5 both，预注册主设定）、Tiberius（只有 mRNA） | 原样 |
| chr20 标尺 | GENCODE v41 当作对 v50 的「预测」 | — |

- v41→v50 这一行是标尺：同一批基因在两版注释之间按 S50 能对上多少，给出该口径在「完美定位」下的上限量级。
- mRNA 类一并报告（我们的模型与 Tiberius、GENATATOR），用来判断 S50 对一个定位准确的类别有多苛刻。

## 3. 判读规则（措辞，事前定）

以 chr20 三 seed 平均的 lnc 为准，chr9 作重复：

| 结果 | 论文允许的说法 |
|---|---|
| S50 Sn ≥ 0.15 且 Pr ≥ 0.35，且 Sn 为 GENATATOR 的 ≥5 倍、绝对差 ≥0.10 | 「lncRNA 位点发现」（locus discovery） |
| S50 Sn 在 0.08–0.15，且 S25 Sn ≥ 0.20 | 「候选 lncRNA 位点发现」（candidate locus discovery） |
| 更低 | 只说「转录相关区域的检出」，位点发现的说法收回 |

- 无论哪一档，原 L1 数字保留并注明口径。
- 阈值来自外部审阅的建议，不是文献公认标准；结果落在两档边界附近（±0.02）时按较低一档写。

## 4. 不做的事

- 不因结果改解码或 τ；不加 seed；不在 chr20 / chr9 上挑口径（θ 只有 0.5 和 0.25 两个，都报）。
- 「只用简单序列特征（CpG 等）的位点检测器」对照另写计划，不在本文件范围。
