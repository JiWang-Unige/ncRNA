## 4. 解读

1. **加小鼠没有比原来的纯人类模型更好。** HM 与 H 在 6 个零样本集上平均差 −0.016，没有一个集的 CI 排除 0；报出数也相近（4,615 vs 4,396）。
2. **HM 对 H6 的 +0.040 主要来自 H6 变保守。** H6（多加 3,000 个人类窗口）在 6 个集上都比 H 低（−0.011 至 −0.127），报出数少 29%（3,104 vs 4,396）。HM 报得更多，Sn 随之更高，所以 1.3 倍报出数这一条正是为排除这种情况而设，它不满足。
3. **seed 方差主导。** H6 三个 seed 在同一集上的 Sn 相差可达 0.26（鸡 0.13–0.39），报出数相差 4–10 倍（线虫 100–999）。CI 宽约 ±0.13，现有 2–3 个 seed 无法分辨 0.03 量级的效应。
4. **训练窗口加倍后不稳定。** 6 个新 run 有 3 个按事先规则失败或替换后再失败（两个 seed 123、hm-789），H 臂（3,000 窗口）的 3 个 run 都正常。
5. **两 seed 预览与正式结果一致：** 预览平均 Δ +0.003、0 / 6 集；正式 +0.040、1 / 6 集，都不成立。HM 的数字未变（同两个 run），变化全部来自 h6-789（该 run 报出数偏多，chr18 上 Sn 0.254）。

## 5. 论文中的写法（§18 要点 5：正负结果都写）

- 主文：在预注册的配对检验中，加入 3,000 个小鼠训练窗口没有带来可检测的跨物种零样本提升（平均 Δ Sn +0.04，1 / 6 集 CI 下界 > 0，报出数 1.49 倍，人类护栏严格 Pr 降 0.04）；与只用人类窗口的原模型相比也无差异（−0.016）。
