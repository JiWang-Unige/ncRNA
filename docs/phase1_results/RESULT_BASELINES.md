## 结论

- **lnc 位点：v1.9 在所有预注册的 SegmentNT 解码下都领先**。
  - SegmentNT 是唯一带 lncRNA 类、chr20 又不在其训练集里的深度学习注释器。
  - 主读数（阈值 0.5，不能定链的基因两条链各报一份）：lnc L1 Sn 0.108 [0.089, 0.129]，严格 Pr 0.113 [0.096, 0.131]，报出 1,235 个。
  - v1.9 三个 seed 平均为 Sn 0.306、严格 Pr 0.422，即 Sn 约为 SegmentNT 的 3 倍，严格 Pr 约 4 倍。
  - SegmentNT 的 lnc 预测 97% 不能定链。即使链全部判对，严格 Pr 最多翻倍到约 0.23，仍明显低于 v1.9。
  - 只保留能定链的基因时，只剩 21 个 lnc，Sn 0.010。
  - 阈值 0.3 时 Sn 0.174，但严格 Pr 降到 0.089。
  - 所有方法的 lnc L2 内含子链 Sn 都是 0，只有 GENATATOR 为 0.012。
- **mRNA 结构：专门的编码基因工具远好于 v1.9**。
  - Tiberius（人类在其训练中完整留出）：mRNA L1 Sn 0.964、严格 Pr 0.917，L2 内含子链 Sn 0.557 [0.513, 0.600]，剪接点精确度 0.934。
  - v1.9 的 mRNA L1 为 0.861 / 0.948，但 L2 只有 0.054。
  - 论文不能说本方法在编码基因结构上有竞争力，只能说位点层面过了护栏（L1 Sn ≥ 0.80）。
- **护栏：v1.9 把 lnc 报成编码的次数低于所有编码工具**。
  - 「被预测 mRNA 覆盖的 lnc 基因」：v1.9 10.0，Tiberius 15，Helixer 14，GENATATOR 34。
  - 「真值命中只有 lnc 的 mRNA 预测」：v1.9 12.3，Tiberius 18，Helixer 18，GENATATOR 46。
- **SegmentNT 主读数的 mRNA 部分不可用，这是预注册解码规则的直接后果**，不是模型通道接错。
  - 主读数报出 109,984 个 mRNA，严格 Pr 0.025。原因是 `protein_coding_gene` 概率在 0.5 附近抖动：55,225 个超过阈值的区间里有 28,449 个只有 1 bp，这些位置的概率与 0.5 平均只差 0.006。
  - 但 97.5% 的碱基落在 1,009 个 ≥ 1 kb 的区间里。
  - 预注册写明不平滑、不合并、mRNA 不设长度过滤。这些短区间都是单外显子、不能定链，所以两条链各报一份。
  - 只保留能定链的基因时：mRNA L1 Sn 0.807、严格 Pr 0.938，L2 0.113。
- **SegmentNT 逐碱基信号本身（事后核查，描述性）**：对 v50 的逐碱基 AUROC，`protein_coding_gene` 对编码基因体为 0.927，`exon` 对外显子为 0.812，`lncRNA` 对 lnc 基因体只有 0.649。它的 lnc 通道在 chr20 上本来就弱，与调研的判断一致。

- lnc 区间已按成熟长度 ≥ 200 nt 过滤。lnc 区间短（中位约 500 bp），大多是单外显子，因此不能定链。
- 逐碱基 AUROC（每 37 个碱基取 1 个，去掉 N，共 172.8 万个位置）：
  - `protein_coding_gene` 对 v50 编码基因体：0.927；
  - `exon` 对任意 v50 外显子：0.812；
  - `lncRNA` 对 v50 lnc 基因体：0.649。
  - 编码通道与外显子通道的 AUROC 说明，通道顺序和「是」的方向都没有接反。

- SegmentNT 作者的评价是逐碱基的分割（MCC），不是基因模型；这里的阈值解码是我们按「作者式」写定的。更好的解码器也许能改善它，但那要在 chr18 上调参，而 chr18 在 SegmentNT 的训练集里，所以不做（预注册第 2 节）。

## 4. 对论文的含义

- **图 5g**：同一把尺子下，chr20 上 lnc 位点的 Sn / 严格 Pr：
  - v1.9 0.306 / 0.422；
  - SegmentNT 最高 0.174 / 0.089（阈值 0.3，两链），主读数 0.108 / 0.113；
  - GENATATOR 0.028 / 0.422。
  - 「在同等精确度下找到更多 lnc 位点」的结论不仅相对 GENATATOR 成立，相对唯一另一个带 lnc 类、不泄漏的深度学习注释器也成立。
- **编码基因**：Tiberius 和 GENATATOR 的 mRNA 结构（L2 0.56 / 0.71）远高于 v1.9（0.05）。论文的编码基因部分只能作护栏来写：位点层面达标，且把 lnc 误报成编码的次数比所有编码工具都少。
- **结构**：所有方法的 lnc L2 都接近 0（GENATATOR 0.012）。lnc 外显子结构在只看序列的条件下普遍没有解决，与两次剪接诊断的结论一致。

## 5. 局限

- 每个对照只用一种配置；SegmentNT 的阈值解码是我们写定的，不代表它的最佳用法。
- Tiberius 只输出 CDS，UTR 缺失会降低 L4 外显子召回，但不影响 L1 和 L2。
- Helixer 偏乐观（人类在训练集里）。
- SegmentNT 的训练标签版本（v44）与真值（v50）不同。
- 第 3 节是看结果后加的描述，不属于预注册读数。
