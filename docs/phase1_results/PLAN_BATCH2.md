## A. S1 复核与扩展（S1R）

**目的**：S1 在 chr20 上的判定（「lnc 与 mRNA 剪接位点的差距主要由使用量解释」）换染色体、换模型后是否仍成立。

**设定**：完全沿用 `s1_analyze.py`（3082b7c 冻结，含 §8 细节），只换输入。

| 染色体 | Snaptron | 模型与样本内 / 外 |
|---|---|---|
| chr18（开发染色体） | 新下载，gtexv2，samples_count ≥ 5 | 自训 S10k：外（已有 `own_chr18.npy`）。SpliceAI：内（已有 `sai_chr18.npy`）。Pangolin：见下 |
| chr7（SpliceAI 的测试染色体） | 新下载，同上 | SpliceAI：外。自训 S10k：内（训练用过 chr7）。Pangolin：见下 |
| chr20（S1 原染色体） | 已有 | 只加 Pangolin |

- **Pangolin**（tkzeng/Pangolin，commit 5cf94b8，`final.*.v2` 权重）：
  - 每个位置的分数取 4 个组织模型「剪接概率」输出的最大值，两条链分别打分。
  - 它的训练 / 测试染色体划分沿用 SpliceAI 的测试染色体（1、3、5、7、9）。这一点在运行前从其仓库核实，写进结果文档。
- **判读**：每条染色体按 PLAN_S1 §5 的规则，用该染色体上「样本外」的模型判读。chr18 用自训 S10k，chr7 用 SpliceAI。Pangolin 在两条染色体上都只作参考。
- **复核判据（写定）**：chr18 与 chr7 的判定都是「差距主要由使用量解释」，就写「S1 的结论在另两条染色体上复现」。任一不同，就如实报告，并以多数为准写论文。
- **R4 后半**（S1 推迟的部分）：chr18 上 S1b A2（真值剪接）每个 seed 没恢复的多外显子 lnc 基因，统计其最弱内含子（与 Snaptron 精确匹配）落在哪个使用量层，与恢复了的基因比较。只描述。

**A 的实现补充（运行前写定，11-04 下午）**：
- Pangolin 的输出不分供体 / 受体，每条链只有一个「剪接概率」，我们把它填进该链的两列。打分器为 `scripts/phase1/s1/pangolin_score.py`。
- 坐标约定未写明，所以先在 chr20 上按 v50 mRNA 位点 AP 选每列的偏移（−2..+2），固定后用到 chr18 / chr7。
- R4 后半：
  - 「恢复」= 有一个最终 lnc 预测的内含子链与该基因某个转录本的内含子链完全相同；
  - 基因使用量 = 各多外显子转录本中最弱内含子读段数的最大值。
  - 脚本 `s1_r4b.py`；队列 `s1r_queue.sh`，等小鼠队列结束后再用 GPU。

## B. 小鼠零样本（S5）

**目的**：在注释完整的近缘物种上检验 v1.9 的零样本位点检出。P1.6 的面板物种 lnc 注释稀疏，精度读数不可靠。

**数据**：
- UCSC mm39 chr19（软屏蔽，61.4 Mb）；真值为 GENCODE vM39 的 chr19。
- 小鼠不在我们的训练里：只用人类训练。GENERanno 骨干的预训练可能含小鼠序列，但不含注释。

**流程**：与 P1.6 完全相同。
- `prep_panel.py` 生成 codes，`p1_feat_ont.sh` 提特征。
- `p16_config.py` 写新配置 `configs/p17_mouse.json`，输出到 `outputs/PHASE1/P17_MOUSE`。
- 先做 chr18 逐字节复现（3 个主模型），再用 `p16_read.py` 读 mouse_chr19，最后用 `p16_score.py` 打分。
- 代码只给 PANEL 加一个条目，加 `--only` / `--targets` / `--out-dir` 选项，不改读取和解码代码（p16_read.py 会核对 sha256）。

**读数**：lnc / mRNA 的 L1 Sn、严格 / 宽松 Pr、L2、L3，两种护栏，ECE；3 seed 平均与逐 seed。

**描述性判据（写定）**：3 seed 平均 lnc L1 Sn ≥ 0.20 且严格 Pr ≥ 0.30，写「零样本位点检出迁移到小鼠」。只满足其一写「部分迁移」，都不满足写「未迁移」。作为对照，人类 chr20 为 0.306 / 0.422。

**资源**：GPU 约 0.5 小时提特征，加 6 次读取（chr18 复现 3 次 + 小鼠 3 次）。临时磁盘约 80 GB，打分后删除特征缓存。

## C. 同线性：不依赖 RNA-seq 的精度估计（S4）

**目的**：鸡和斑马鱼的零样本 lnc 预测，有多少落在人类 lnc 基因的同线性位置上。拿这个作为与 RNA-seq 无关的精度证据，与位置匹配的随机对照比较。

**数据**：
- P1.6 已读出的预测：chicken_5、zebrafish_22，3 个主模型，最终预测 τ* = 0.6。
- 链文件：GRCg7b→hg38（加 chromAlias，把 Ensembl 的「5」对应到 RefSeq 名），danRer11→hg38（Ensembl「22」= UCSC「chr22」）。
- 人类 GENCODE v50。

**方法**：
- 用自写的 chain 映射（不另装 liftOver，单元测试对照手算），把每个预测的外显子碱基映射到 hg38。
- 能提升：≥ 50% 的外显子碱基映射到同一条 hg38 染色体，且映射后跨度 ≤ 2 Mb。
- 映射后的区间（按映射链方向换算链）与 hg38 v50 基因体比较。
- 「同线性 lnc 命中」：与同链 v50 lnc 基因体重叠。另报与 mRNA 基因体重叠的比例。

**对照**：每个预测在本物种同一条染色体上随机平移 100 次，保持长度和外显子结构，避开 N 区，seed 0，同样映射和计数。

**分层**：本物种真值命中的预测（严格 L1）与新位点预测（不与本物种任何注释基因同链重叠）分开报。

**读数**：提升率；提升后的 lnc 命中率；对照的均值与第 95 百分位；富集倍数；经验 p 值（100 次随机中 ≥ 观察值的比例）。

**描述性判据（写定）**：新位点预测提升后的 lnc 命中率是对照均值的 ≥ 2 倍，且经验 p < 0.01，写「新位点有同线性支持」。

**资源**：只用 CPU，约 1 天。

**C 的实现补充（运行前写定，11-04 下午）**：
- 脚本 `scripts/phase1/s4/s4_synteny.py`；单元测试 `tests/test_s4_synteny.py`（正链 / 反链映射与手算一致，ont 上 2 项通过）。
- 若同一目标区段被多条链覆盖，保留得分高的链，丢弃的块数写进输出。
- 汇总规则：3 seed 平均的新位点富集倍数 ≥ 2，且 3 个 seed 的经验 p 都 < 0.01（100 次随机时最小可达 1/101）。满足才写「新位点有同线性支持」。
