## 1. 要回答的问题

1.2B 骨干加 17 状态语法得到的 lncRNA 位点检出，是否明显强于只用 CpG / GC / 序列组成加长度先验的简单检测器？

- 如果简单检测器能达到我们的水平，「复杂模型带来检出增益」这一主张就要撤回，检出只能写成「主要由启动子类型决定」。
- 实验 1 的审计结果（骨干见过人类 CDS 标签）使这个对照更关键：它完全不依赖骨干。

## 2. 检测器（已固定）

1. **网格与特征**：染色体每 50 bp 一个格点，两条链各算一次。
   - 不分链：±500 bp 内的 CpG o/e、GC、CpG 密度、重复序列比例；±5 kb 的 GC；±2 kb 的 CpG o/e；前三项的平方。
   - 分链（按转录方向）：下游、上游各 1 kb 的 GC skew 和 AT skew，下游减上游的 CpG 密度，下游 1 kb 的 U1 位点（GTAAGT / GTGAGT）和 PAS（AATAAA / ATTAAA）密度，±500 bp 内 16 种二核苷酸频率。
2. **两种打分**：
   - `cgi`：CpG 岛规则（±500 bp 内 GC ≥ 0.5 且 o/e ≥ 0.6），得分为 CpG 个数，两条链都输出。没有可学参数。
   - `lr`：逻辑回归，只用 chr18 训练。正例为距任一 v50 lncRNA 转录本起点 100 bp 以内的同链格点（9,381 个），负例为距起点 1 kb 以外的随机 30 万个格点。
3. **起点**：每条链取局部最大，在半径 R 内做非极大值抑制。
4. **Tiberius 过滤**（可选，只依赖序列的从头编码预测）：丢掉落在同链 Tiberius 基因内的起点；跨度到下一个同链 Tiberius 基因为止。
5. **跨度**：从起点向下游延伸固定长度 L（长度先验），遇到下一个选中的同链起点即停止；短于 200 bp 的丢弃。
6. **输出数量**：取得分最高的 N 个预测，**N = 我们在该染色体上 lncRNA 预测数的 3 个模型均值**。N 由我们自己的预测决定，不用真值。

## 3. chr18 开发（已完成）

- **对照用的「我们」**：v1.9（τ 0.6）3 个模型的均值。chr18 上平均 571 个预测，S50 Sn 0.054，跨度 L1 Sn 0.342（外显子 L1 0.286）。v2.0（校准后 τ 0.36）的 S50 也是 0.054，跨度 L1 0.296。
- **两种读数**：
  - **S50**：预测跨度与真值基因跨度一对一匹配，双向覆盖都 ≥ 0.5。
  - **跨度 L1（L1s）**：预测跨度与任一真值 lncRNA 外显子同链重叠。为了公平，**我们的预测也换成跨度**再算，这样双方的表示方式相同。
- **选择方法**：
  - `lr` 用交叉拟合：以 40 Mb 为界分成两半，用一半训练、给另一半打分，避免样本内乐观。
  - 网格：变体 {cgi, lr} × R {1, 2, 5 kb} × L {2, 5, 10, 20, 40, 80 kb} × Tiberius {有, 无}，共 72 种。
  - 在 N = 571 下，**两个读数各选一套**：S50 最大者作为 S50 的对照，L1s 最大者作为 L1s 的对照。原因是 L1s 会随跨度变长而虚高（80 kb 的 CpG 规则 L1s 0.39，已超过我们），用同一套参数比两个读数会偏向其中一个。

**选中的配置与 chr18 结果**（N = 571）：

| 读数 | 选中配置 | 检测器 | 我们 v1.9 | 比值 |
|---|---|---|---|---|
| S50 Sn | cgi，R 5 kb，L 80 kb，有 Tiberius | 0.054 | 0.054 | 1.00 |
| L1s Sn | cgi，R 5 kb，L 80 kb，无 Tiberius | 0.394 | 0.342 | 1.15 |

- 在 chr18 上，**最简单的 CpG 岛规则（不训练）在 S50 上与我们持平，在跨度 L1 上超过我们**。学出来的 `lr` 没有更好（S50 最高同样是 0.054，配置为 R 2 kb、L 20 kb、有 Tiberius）。
- 不用 Tiberius 时，CpG 规则的 S50 最高 0.048（我们的 90%）。
- S50 对 L 不敏感：L ≥ 10 kb 时都在 0.04–0.054 之间，差异在抽样误差内（S50 的标准误约 0.007）。
- **CpG 分层**（全量拟合，样本内）：
  - 检测器的命中集中在 CpG 最高四分位（S50 0.146，我们 0.096）。
  - 我们在低 CpG 一侧更好：Q1 + Q2 的 S50 我们减检测器为 +0.024，95% CI [0.009, 0.040]；L1s 为 +0.050，CI [0.001, 0.096]。
- **重叠**：S50 命中的基因里，我们 3 个模型合计命中 123 个，检测器命中 50 个，两者共有的只有 14 个。两者找到的是不同的基因。

## 4. 测试读取与判据（冻结后不改）

**读取**：chr20 与 chr9 各一次。

| 染色体 | 对照的「我们」 | N |
|---|---|---|
| chr20 | v1.9（τ 0.6） | 631（502 / 891 / 500 的均值） |
| chr9 | v2.0（校准后 τ 0.36） | 905（1,000 / 968 / 748 的均值） |

**比值**：
- R_S50 = 检测器 S50 Sn ÷ 我们 3 个模型 S50 Sn 的均值（用 S50 选中的配置）。
- R_L1 = 检测器 L1s Sn ÷ 我们 L1s Sn 的均值（用 L1s 选中的配置）。
- 置信区间：对真值 lncRNA 基因做 2,000 次自助抽样（种子 0），给出比值和差值（我们减检测器）的 95% CI。

**主判据**：

| 结果 | 条件 |
|---|---|
| **撤回** | chr20 和 chr9 上都满足 R_S50 ≥ 0.8 且 R_L1 ≥ 0.8 → 撤回「复杂模型带来检出增益」的主张 |
| **保留** | chr20 和 chr9 上都满足 R_L1 < 0.5，且 S50 差值的 CI 下限 > 0 → 保留该主张 |
| 灰区 | 其余情况 |

**次要判据（事先写定，不影响主判据）**：在低 CpG 子集（每条染色体按 lncRNA 起点 ±500 bp 的 CpG o/e 分四分位，取 Q1 + Q2）上，我们减检测器的差值。如果 S50 或 L1s 在两条染色体上 CI 下限都 > 0，就可以写一个收窄的主张：「模型能检出 CpG 规则找不到的非 CpG 岛型 lncRNA」。

**只描述、不参与判据**：
- 用 chr18 上的得分阈值（不按 N 匹配）得到的结果；
- PR 曲线：检测器 N 从 100 到 3,000，我们的 τ 从 0.05 到 0.95；
- 检测器的 L1s 与我们原始外显子 L1 的比较；
- 命中基因的重叠；
- 四个 CpG 分层的读数。

## 5. 各结果对 M1 的含义

| 主判据 | 次要判据 | 含义 |
|---|---|---|
| 撤回 | 低 CpG 也不占优 | 检出部分的方法学贡献撤回；骨干审计的问题对 lnc 主张不再重要（不做自监督骨干对照）。M1 结束时这一项计入决策 D（「简单检测器接近我们」） |
| 撤回 | 低 CpG 占优 | 主张收窄为「CpG 规则之外的那部分」，并且需要实验 1 的方案 A（骨干没见过的组装）来排除泄漏 |
| 保留 / 灰区 | — | 按 DECISION 原计划，做实验 1 的对照（先方案 A） |

## 6. 局限

- L1s 会被长跨度刷高，所以 L1s 的结论只能是「简单检测器调到最有利时能达到多少」。
- 检测器用了 Tiberius（只依赖序列的从头编码预测器，统一 GFF3 的编码层也用它）。不用 Tiberius 的最好结果一并报告。
- chr20 / chr9 的真值我们以前读过多次；这里只是检测器第一次读，属于固定规则的回顾性比较。
- 我们的数字是 3 个模型的均值，检测器是确定性的，没有 seed 方差。
