# M1 审计方案 A 计划：在骨干没见过的组装上重复实验 2（2026-11-17，读取前写定）

> 依据：`RESULT_M1_AUDIT.md` 的方案 A；`RESULT_M1_SIMPLE.md` 的灰区按其计划第 5 节转入本方案。作者 2026-11-17 回复「批准方案 A」，批准下载与约 1 GPU 小时。
> 判据直接沿用实验 2 已冻结的规则，不新增阈值（第 4 节唯一新写的是「未复现」的界线）。本文件在任何长颈鹿读取之前提交。

## 1. 问题

实验 2 中，我们在 chr20 / chr9 的低 CpG lncRNA 上的 S50 比 CpG 岛规则高约 0.025。但骨干见过这两条染色体的 CDS 标签。
在一个骨干训练时完全不存在的组装上，这点优势还在吗？

## 2. 数据（已下载并核对）

- **组装**：长颈鹿 *Giraffa tippelskirchi* T2T-mGirTip1v1.2.pri（GCF_054371585.1，RefSeq 注释 GCF_054371585.1-RS_2026_02，2026-02-23 发布）。它在 Carbon-A 的 `eval/unseen` 里，即 2026 年才进入 RefSeq，不在骨干的训练快照中。近缘的牛科动物很可能见过（局限）。
- **染色体**：chr14（NC_137288.1，72,936,098 bp）。选择规则是「最小的常染色体」，在看任何注释之前按长度定下（其余常染色体 124–238 Mb）。
- **文件**：
  - `data/giraffe/NC_137288.1.fa`：NCBI efetch，长度与 NCBI 序列报告一致；
  - `data/giraffe/genomic.gff.gz`：NCBI FTP，md5 `88769639…` 与 FTP 校验表一致。
- **真值**：RefSeq GFF 中 `gene_biotype=lncRNA` 的基因（NCBI Gnomon，基于 RNA-seq 证据）为 lnc；`protein_coding` 为 mRNA。读法与 T2T chr20 相同（`ruler.read_gff3_truth`）。

## 3. 运行

- **分三段**：ont 磁盘只剩约 89 GB，整条染色体的特征缓存约 100 GB，放不下。所以按坐标三等分（a / b / c，各约 24.3 Mb），逐段提取特征、读取、删除缓存。
  - 跨越切点的真值基因不参与评估（对双方相同）。
  - 每段当作一条独立的染色体，双方都在段内预测。
- **我们的模型**：v2.0 的三个主模型（与 chr9 相同：同样的检查点、解码与校准，τ_v20 0.36），用 `p16_read.py` 读取。
  - 新配置 `configs/m1_unseen.json` 从 `configs/v20.json` 派生，代码与权重的 sha256 必须与之一致。
  - 读长颈鹿之前先在 chr18 上复现 v2.0 的读取：后验与基因的 sha256 必须相同，否则停止。
- **检测器**：实验 2 冻结的 RULES.json（sha256 `f43a4ce4…`），代码不改：
  - S50 用 cgi + Tiberius + 80 kb，L1 用 cgi + 80 kb。
  - Tiberius 用同样的设置（mammalia_nosofttmasking_v2）在整条 chr14 上跑一次，再按段切分。
- **N**：每段的 N = 我们三个模型在该段 lncRNA 预测数的均值（四舍五入），三段合计。
- **GPU**：特征提取约 10 分钟，读取约 15 分钟，Tiberius 约 10 分钟，全部经过 `gpu_gate.sh`，给 TE 让路。CPU 用 nice 19。

## 4. 判读（三段合并计算）

**主读数**：低 CpG（lnc 起点 ±500 bp 的 CpG o/e，在本染色体所有 lnc 基因中分四分位，取 Q1 + Q2）上，S50 的差值（我们减检测器）。按基因做 2,000 次自助抽样（种子 0），取 95% CI。

| 结果 | 条件 | 含义 |
|---|---|---|
| **复现** | CI 下限 > 0 | 在骨干没见过的组装上，低 CpG 一侧的优势依然存在，不是「骨干见过测试染色体」造成的 |
| **未复现** | 点估计 ≤ 0.0128（chr20 / chr9 平均差值 0.0255 的一半），且 CI 下限 ≤ 0 | 这点优势在新组装上消失，不能作为模型的贡献写进论文 |
| 灰区 | 其余 | 只描述 |

**只描述**：
- 实验 2 的主比值 R_S50、R_L1，以及按实验 2 主判据的条件逐条列出（单条染色体，不做判定）；
- 低 CpG 的跨度 L1 差值；
- 四个 CpG 分层；
- 我们的模型在长颈鹿上的绝对水平（L1、S50，与小鼠零样本 0.28 并列，后者见过骨干训练）；
- 三段各自的数字。

## 5. 局限

- 组装没见过，但近缘的牛科动物（牛、山羊、绵羊等的 RefSeq 组装）很可能在骨干训练集中，同源序列的影响排除不了。
- 真值是 NCBI Gnomon 基于证据的注释，与 GENCODE 的人工审核口径不同；低表达的 lncRNA 会更不完整。
- 我们的头在人类上训练，这里是跨物种读取，绝对水平会低于人类。检测器的规则也是在人类 chr18 上选的。两者条件相同。
