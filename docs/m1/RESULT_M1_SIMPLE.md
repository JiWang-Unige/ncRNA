## 结论（按冻结规则）

**主判据：灰区。**
- chr20 满足「撤回」的条件：S50 比值 0.82，跨度 L1 比值 1.11。
- chr9 的 S50 比值只有 0.70，未满足；而「保留」要求 L1 比值 < 0.5，两条染色体都远未达到。

**次要判据：成立（S50）。** 在低 CpG（Q1 + Q2）的 lncRNA 上，我们的 S50 在两条染色体上都高于检测器，置信区间都不含 0。

**一句话**：在 CpG 岛型 lncRNA 上，一个不训练的 CpG 岛规则与我们的模型一样好，在跨度 L1 上还更好。模型剩下的优势只在非 CpG 岛型 lncRNA 的界定（S50）上，绝对量很小：每条染色体约 10–20 个基因。

## 其他描述性读数

- **两边找到的基因不同**：
  - S50 命中中，我们 3 个模型合计命中 157 个（chr20）/ 209 个（chr9），检测器 50 / 69 个，共有的只有 22 / 18 个。
  - 跨度 L1 命中的重叠约 40%。
- **与已发表的外显子 L1 比较**：检测器的跨度 L1 是我们外显子 L1（0.306 / 0.304）的 1.31 倍（CI 1.19–1.45）和 1.20 倍（CI 1.10–1.31）。
  - 也就是说，稿件头条的「lncRNA 检出 30%，约为 GENATATOR 的 10 倍」，一个 CpG 岛规则加 80 kb 区块就能达到并超过。
- **用 chr18 阈值而不是匹配预测数**：检测器在 chr20 / chr9 上分别给出 859 / 1,323 个预测，S50 为 0.070 / 0.080，高于我们，但精度更低（0.078 / 0.086，我们为 0.094 / 0.108）。
- **PR 曲线**：
  - 检测器的候选在约 1,100–2,200 个预测处用尽（CpG 岛数量有限）。
  - 我们最好的一个模型（chr20 的 g1b-123，τ 0.05）在 1,316 个预测时 S50 为 0.111，检测器在 1,133 个时为 0.082。
  - 我们最弱的模型低于检测器。

## 对论文和 M1 的含义（按计划第 5 节，灰区一行）

1. **稿件的 L1 头条不能作为模型的贡献**。检出的绝大部分可以由 CpG 岛加长度先验解释，这与 S3「检出随启动子 CpG 和跨度变化」的结果一致，现在有了直接对照。
2. **可以保留的只有一个收窄的主张**：模型能界定少量 CpG 规则找不到的非 CpG 岛型 lncRNA，S50 在两条测试染色体上都显著高于规则。但绝对量很小，而且实验 1 已经确认骨干见过这两条染色体的 CDS 标签，所以这一点还需要按 RESULT_M1_AUDIT 的方案 A，在骨干没见过的组装上验证。
3. **对 M1 的决策**：DECISION 的结果 D 要求「简单检测器接近我们，**而且**稀疏证据不胜过吸附基线」。前一半大体成立（灰区偏向撤回），后一半要等第 2–4 周的三条件实验。
4. **对后续方法的启示**：CpG 岛规则在高 CpG 一侧的跨度 L1 比我们高约 0.2。任何后续方法都应该把这种简单的启动子先验当作基线或组件，而不是指望骨干自己学到。

## 局限

- 跨度 L1 会随跨度变长而虚高，所以 L1 的比较只能说明「简单规则调到最有利时能到多少」。S50 不受这个影响。
- 检测器的 S50 配置用了 Tiberius。不用 Tiberius 时，chr18 上 S50 是我们的 90%（测试染色体上没有单独读这个配置）。
- 我们的 3 个模型方差很大，比值的置信区间较宽。
