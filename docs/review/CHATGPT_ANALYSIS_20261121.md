## 第二轮（思考 1 分 25 秒；提问是我们接受的三项纠正，加上两项必做分析、两处分歧）

**(1)–(3) 同意。** 并强调：S50 召回与长读长相当，绝不能写成与长读长注释质量相当。

**A. WTC11 端点精度：修改。** 建议冻结的读数：
- 主指标：双端 ±1 kb 准确率 = S50 一对一匹配中 5′、3′ 边界都在真值 ±1 kb 内的位点数 ÷ 全部 165 个真值位点（未匹配记为失败）。
- 次指标：同上，±100 bp。
- 描述：S50 匹配对的 |Δ5′|、|Δ3′| 中位数（列出匹配数；只在匹配子集上算会有选择偏差，所以不作主指标）。
- 真值沿用基因跨度定义，不在看预测后挑最匹配的 isoform。
- 判据：Δ1k = A(ev_farthest) − A(snap)，按位点配对自助。
  - Δ1k ≥ 0.05 且 CI 下限 > 0：支持「端点证据带来有实际意义的端点定位改善」（0.05 约为 165 个中多 8 个，是建议值，不是文献标准）；
  - 点估计 ≤ 0 或 CI 上限 ≤ 0：不支持，撤回「改善准确端点定位」的主张；主线收窄为「改善了粗粒度的跨度恢复」，冻结的 S50 结果不受影响；
  - 其余：证据不足。100 bp 只用于描述精度层级，不另设门槛。

**B. 被删的「不确定」预测：修改。**
- 约 544 是三个模型平均反推的数，要逐 seed 统计删除集合及分类比例；同时重叠编码和非编码的保留为「混合」类。
- 核心读数：被删且不属真值的预测中，与 rep2/rep3 的 protein_coding、lncRNA、其他转录本同链重叠的比例，并按 novelty 类别分解。
- 多数为编码：可以写「序列先验主要删掉了与编码转录本重叠的候选，在预设口径下没有提高 lncRNA 召回或精度」，但不能写「只起编码过滤作用」；也不能说它比 Tiberius 等现成编码过滤更有价值。
- 多数为 lncRNA：反对写成「删掉了真实但低支持的 lncRNA」，只能写「优先删掉了与未达高置信标准的 lncRNA 转录证据重叠的候选」。只有被删预测获得独立证据支持时，才能讨论误删。
