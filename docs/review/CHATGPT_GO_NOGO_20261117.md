## 第一轮要点

**结论：选 C。现稿不投，转入一个限时、限算力的里程碑。不建议直接上大模型。**

**按现有结果直接投稿，各刊的接收概率（它的主观估计）**：

| 期刊 | 概率 |

最可能被接收的是 Bioinformatics / NARGAB 一档。

**它作为审稿人会提的三条主要批评**：
1. **贡献与评价终点不一致**：论文号称联合注释，最好的新产出却是边界不确定的「lncRNA 相关区域」。S50 只有约 7% / 10%，lncRNA 结构不可用，编码结构靠 Tiberius；统一 GFF3 全部是 `unresolved`。
2. **「端点限速」没有因果识别**：
   - GENATATOR 分割模型没有基因间状态，外扩必然出错，所以「1 kb 容忍度」不能推广。
   - 参考端点（canonical）未必是唯一、稳定的生物学端点。chr20 上「有双端证据」组的比值是 1.9，紧贴 2 倍的阈值。
   - 局部模型（Puffin）失败，不等于端点不可预测：更长上下文、远端调控、更好的标签都没有排除。
3. **没有证明 DNA 语言模型带来了不可替代的增益**：
   - 检出靠 CpG 和跨度，缺少简单特征的对照。
   - 另外，GENERanno-cds 的训练数据和染色体划分没有充分公开，不能排除骨干见过 chr20 / chr9 的监督信息。这是需要审计的风险，不等于已经泄漏。

**真正有价值的核心问题**：注释时，哪些信息 DNA 能确定，哪些必须依赖细胞状态或实验数据？
- 由此，lncRNA 注释应当从「确定性的基因预测」转为「可选择性输出、能按证据更新的转录单位推断」：模型要知道什么时候能界定、什么时候该保持不确定，以及加入极少量哪种实验信息就能得到完整模型。
- 它认为 17 状态 CRF 和「十倍召回」都不是最有价值的资产。

**现在发会不会浪费想法**：会。理由不是想法会失效，而是会把最有独创性的问题过早包装成一篇不完整的论文；后续论文需要同一套评测和诊断，容易被看成增量工作。

## 第二轮（Claude 的整合方案 → 它的逐条意见）

**整体**：它认为整合方案比原来的更好（把零训练的排除性实验放到前面），但有三处必须修正。

| 项目 | 它的判断 | 修改 |
|---|---|---|
| (3) GENERanno 训练数据审计 | 同意，排第一 | 要分清三种情况：预训练见过序列、CDS 监督见过 chr20 / chr9 的标签、见过同源序列。结论只回答一个问题：现有 chr20 / chr9 能否称为严格的监督样本外测试？官方记录不全时，记为「无法核实」 |
| (1) 简单特征的检出对照 | 同意，改判据 | 以 S50 和「匹配精度 / 匹配预测数时的召回」为主，给出完整 PR 曲线。简单检测器的 L1 和 S50 都达到我们的 80% 以上 → 暂停「复杂模型有必要增益」的主张；L1 不到 50% 且 S50 明显更差 → 保留；其余为灰区。长度先验只在 chr18 上学，不能用真值跨度构造候选。chr20 / chr9 只能叫「固定规则的回顾性比较」 |
| (2) AlphaGenome | 同意做，反对原判据 | ① CAGE / PRO-cap 只能测起点，不能测终点；② all_folds 是样本内的，只能当乐观上限，应改用留出该区间的 fold 模型；③「取最大值优于取均值」不等于细胞类型依赖（最大值天然更极端），要在同一种实验内比较「匹配细胞类型」与「不匹配细胞类型」。判据：留出 fold 上低 CpG TSS 的 Loc1k ≥ 0.25，且优于 Puffin 和 CpG 对照 → 更强的序列模型确有可用信息；Loc1k ≤ 0.12 且置信区间排除实质改善 → 被测模型都没解决；介于两者之间是灰区 |
| 三条件实验 | 修改后同意 | 见下 |

**三条件实验的修改**：
- **数据**：LRGASP 的人类 WTC11。同一细胞系有 ssCAGE（GEO GSE185917）、QuantSeq（ENCODE ENCSR322MWL）、PacBio 长读长（ENCSR507JOF）、短读长（ENCSR673UKZ）。
  - 注意：WTC11 的 ssCAGE / QuantSeq 曾参与 GENCODE 的人工评审，所以真值不能再用 GENCODE canonical。改为：ssCAGE / QuantSeq 作为输入证据，独立的长读长重复作为验证。
- **新测试染色体选 chr12**，但 chr12 贡献过训练窗口。两种做法：
  - 严格：下一版训练排除 chr12 窗口，重训轻量头；
  - 低成本：只评估与训练窗口及其缓冲区不重叠的区域，称为「held-out regions」。
  - 冻结之前要先确认 WTC11 在 chr12 上可验证的 lncRNA 数量（统计功效），之后不能根据成绩改选染色体。
- **公平比较**：「只给端点证据」和「给完整转录组证据」是两种信息预算，分开比较。StringTie 需要 RNA-seq 比对，IsoQuant 需要长读长；AUGUSTUS hints 要写明允许哪些类型。
- **门槛分两步**：我们的解码器在真值跨度下 L2 也只有约 0.3%，所以第一阶段只看 S50（召回 ≥ 0.30、精度 ≥ 0.40）和是否优于同等证据下的简单对照。L2 ≥ 0.10–0.15 留到接入更强的结构模块之后再看。同时报告有证据子集占全部 lncRNA 的比例。

**简单检测器接近我们时还做不做方向 2**：做，但只做最小的证伪实验。两者检验的不是同一个命题。只有「简单检测器接近我们」，而且「稀疏证据在同等预算下不胜过吸附基线和现有工具」时，才进入 D（归档）。如果简单先验就够用、证据条件化又有效，论文的创新反而更清楚：不再依赖 1.2B 骨干。

**一句话**：整合方案更好；但 AlphaGenome 的样本内结果要降为诊断证据，独立验证和公平比较要重新定义。它支持按修改后的方案推进四周里程碑，现稿保持归档，不提前启动大骨干训练。
