## 1. 共识

**能投，以分析类文章投；不再训练模型。**

- **主线**：lncRNA 相关区域的检出，不等于转录单位的界定。建议标题：*Genomic sequence models detect lncRNA-associated regions but fail to recover transcription units*。
- **文章骨架（三部分）**：
  1. 宽松检出指标（L1）与转录单位界定（S50）之间的巨大差距；
  2. 用简单规则（CpG 岛规则）和独立序列模型（Puffin、PolyaID、AlphaGenome）分解这个差距；
  3. 用 WTC11 的端点证据说明哪些失败能由观测补偿，以及补偿后为什么仍达不到高精度注释。
  - 我们的联合注释模型只作为被评估的方法之一。
- **不能写的**：
  - 「DNA 本身缺少信息」：只能说在所评估的模型、真值与评测条件下。
  - 「端点是限速步骤」：现稿第 13 节（chr18）只给真值跨度时内含子链只有 0.3%，只给剪接点 16.8%，两者 34.1%。改为：端点误差是现有区间分割器端到端使用的前置瓶颈，但解决端点不等于解决结构。
  - 「几个端点读段就够」：100% 证据是全部 ssCAGE + QuantSeq，10% 时召回 0.172。
  - 「与长读长相当」：只是 S50 召回相当；严格精度 0.076，IsoQuant 0.176。

## 4. 原课题为什么没有成功（两方一致的梳理）

| 方面 | 结果说明了什么 | 归因 |
|---|---|---|
| 检出 | L1 约 0.30，但 CpG 岛规则加长度先验就能达到；低 CpG 的小优势在长颈鹿上未复现 | 模型没有建立独特的检出能力 |
| 界定 | S50 约 0.06–0.07，端点误差 kb 到十几 kb | 边界定位失败；真值端点本身也有不确定性 |
| 起点 | AlphaGenome 低 CpG 0.133（Puffin 0.083）；无 CAGE 支持的起点所有方法接近随机；匹配细胞类型后改善 | 序列信号弱、细胞状态、参考起点质量共同作用，份额分不开 |
| 终点 | 序列模型和 polyA 专用模型都不行 | 更可能是候选终止位点的选用，而不只是识别 motif |
| 结构 | 端到端 lnc 内含子链为 0；给真值端点也几乎为 0，给剪接点后才明显提升 | 端点和剪接都是瓶颈 |
| 加证据 | S50 0.125 → 0.436，但序列先验逐位点没有增益 | 观测本身有用；我们的融合方式没有证明序列模型提供额外信息 |

三种可能的原因：
- **问题本身不可解**：没有被证明。
- **方法没有解决任务**：成立。
- **评测与真值有问题**：成立，但不能用来开脱。L1 高估检出；WTC11 双重复真值偏向稳定表达的转录本；GENCODE canonical 端点不一定是某一细胞中的主转录本。
