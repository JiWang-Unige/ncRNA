## 对 Gemini 四个方向的评价
| Gemini 方向 | 评价 | 优先级 |
|---|---|---|
| 细胞条件化连续定位 | 强烈赞同问题定义，有条件赞同模型设计 | 保持高 |
| lncRNA 降解动力学 | 赞同科学问题，不赞同序列-only 模型 | 大幅下调 |
| SBI 化学探测系综去卷积 | 强烈赞同 | 上调为第 1 |
| 同线性 RBP 轮廓软对齐保守模块 | 赞同目标，对实现保留意见 | 保持高 |

**1. 细胞条件化定位**
- 75% → 59% 基本对，但那是原模型在「被排除的中间样本」上的表现（AUROC 0.5921），不是去掉中间排除后重训的结果；它证明了基准选择偏差，没有证明连续回归能解决问题（PMID 39296930）。
- 新意被压缩：
  - Tani 2026（PMID 42353306，DOI 10.3390/ijms27125593）：K562 139 个 RBP 的 eCLIP，R² 从 0.08 升到 0.25；控制丰度、内含子、外显子数后仍增 0.12；迁移到 HepG2 AUROC 0.71；梯度提升不胜线性模型。
  - Zuckerman & Ulitsky 2019（PMID 30745363）：剪接效率是定位的重要预测因子，最多解释 34% 方差。
- 设计问题：
  - RBP 表达不等于结合活性；
  - gene mean 有泄漏风险；
  - 未见细胞系无法估计 offset；
  - ≤ 30% 序列相同度不足以防泄漏（还要按 gene/locus 分组、做局部同源和 repeat 检查）。
- 关键改写：y_{g,c} = μ_g + α_c + δ_{g,c} + ε。真正要预测的是 gene × cell 交互 δ，也就是同一基因在不同细胞中的定位变化。主张要从「更准确预测定位」升级为「预测细胞环境引起的定位变化」。先用线性 cis × trans 模型，不急着上 cross-attention。

**2. lncRNA 降解动力学：不推荐**
- Saluki r = 0.77 依赖 coding frame 和剪接位点（PMID 36419176）。
- 直接负面证据：*Codon optimality predicts mRNA half-life but does not transfer to lncRNAs*（Mol Genet Genomics 2026，PMID 42760417，DOI 10.1007/s00438-026-02520-1）：
  - mRNA 序列特征 CV R² 0.174；HeLa lncRNA −0.050；
  - 33,285 个 lncRNA 的 k-mer 模型 0.0007；基因组语言模型 0.0002–0.0036。
- PRO-seq / RNA-seq 比值不等于半衰期真值。现有半衰期数据只覆盖约 10% 的注释 lncRNA（PMID 42931875）。
- 结论：从前 3 删除；最多做一次廉价的可检测性测试。

**3. SBI 系综去卷积：升为第 1**
- 最像一个独立的计算方法问题：输入是原始观测、可构造已知混合真值、核心是反问题。
- 必须比较的更新竞品：
  - DREEM（Nature 2020，PMID 32555469）、DRACO（Nat Methods 2021）、DANCE-MaP（Mol Cell 2022）；
  - SEISMIC-RNA（优化的 DREEM 流程，必须当基线）；
  - sm-PORE-cupine（Nat Methods 2026，直接 RNA 测序 + Bernoulli 混合）；
  - DeCoRE（2026，直接 RNA 测序解决结构异质性）。

  长读长系综分析已不是空白。
- 不赞同「Boltzmann 采样 + Set Transformer」：热力学只能作先验，不是体内真值。建议用 Bernoulli 混合似然 + 真实测序误差模型 + 后验不确定性；先做 DeepSets + 可微似然。
- 门槛要加：
  - 单一状态对照的虚假混合检出率 ≤ 5%；
  - 名义 90% 后验区间的实际覆盖率落在 85–95%。
- 去卷积不等于折叠动力学。

**4. 保守功能模块**
- LncLOOM（PMID 33430943）已证明思路；RBPNet（DOI 10.1186/s13059-023-03015-7）。
- 三个根本风险：
  - RBP 结合相似不等于功能同源（富 U / 富 C 区普遍存在）；
  - 人类训练的 RBPNet 跨物种未必可靠；
  - soft-DTW 过度灵活，会在随机序列里也找到「保守模块」。
- 改为「同线性 lncRNA 中功能基序 turnover 的系统发育检验」：允许基序序列变，检验结合功能是否被选择维持。
- R-scape 没检出共变不等于没有结构，可能只是统计效能不足（R-scape DOI 10.1038/nmeth.4066；螺旋级 DOI 10.1371/journal.pcbi.1011262，PMID 37450549）。
- 正例太少，AUPRC +0.15 不适合当主门槛；CASC15 元件未核实，不能当真值。

## 对 Gemini 其他事实的核查
- CASP16「21 个可接受折叠中 19 个有模板」基本正确（PMID 41165252，DOI 10.1002/prot.70072）。但不能推论所有 RNA 深度学习任务都没进步。
- 「BEACON 证明 LM 普遍无效」是过度概括（arXiv 2406.10391）。RNAGym 和 GraphFLA 不是同一种基准。
- LncRFM F1 0.374 与摘要一致（作者自报）。
- Dorado 可靠性问题属实。独立评估（NAR 2026，PMID 42306945）显示：PR-AUC 在平衡数据上为 0.84–0.91，接近真实类别比例时降到 0.04–0.09。
- miRNA FDP > 0.85：找到预印本 arXiv 2610.33960，具体阈值未核实。
- GPN-Star：本轮未核实，不用于排序。

## 新发现（影响立项）
- structRFM（Nature 2026，DOI 10.1038/s41586-026-11210-2）：结构引导的 RNA 基础模型，进一步压缩「结构感知 RNA LM」的新意。
- 上面列的 Tani 2026、PMID 42760417、Zuckerman 2019、SEISMIC-RNA、sm-PORE-cupine、DeCoRE、Dorado 独立基准。

## 更新后的前 3（主观评分，新意 × 可行性 × 影响，满分 125）
1. **不确定性感知的 RNA 构象系综推断**（90.0）。
   - 最小实验：用 DREEM 已知混合、腺嘌呤核糖开关、DANCE-MaP 7SK 数据，从真实突变读段矩阵构造已知比例的伪混合并降采样（500–5,000 reads，次要状态 1–50%）。
   - 基线：多次初始化的 Bernoulli 混合 EM、变分贝叶斯混合、SEISMIC-RNA。
   - 门槛：留出 RNA 家族、1,000–5,000 reads 下，状态比例 MAE 降 ≥ 15%，状态反应性 Pearson +0.08，虚假混合 ≤ 5%，90% 区间覆盖率 85–95%。
   - 期刊：Genome Biol / NAR / Bioinformatics；有强生物学应用可冲 Nat Methods。
2. **跨未见细胞环境预测 lncRNA 定位变化**（78.8）。
   - 数据：lncATLAS（PMID 28386015，6,768 个 lncRNA、15 个细胞系，非完整矩阵）。
   - 模型：低秩双线性 ŷ = f(x_g) + h(z_c) + u(x_g)ᵀv(z_c)。
   - 基线：gene mean、ridge、矩阵补全、含剪接特征的 LightGBM、双线性 ridge。
   - 划分：留基因 / 留细胞 / 双留 / 基因内 ΔCNRCI。
   - 门槛：留一细胞系 Pearson +0.08；基因内变化 r ≥ 0.30；聚类 bootstrap 区间不含 0；打乱 RBP 谱后性能要下降。
   - 风险：独立细胞系太少、变化主要是噪声。
3. **lncRNA 功能基序 turnover 的进化推断**（75.0）。
   - 基线：LncLOOM、PWM、局部比对、系统发育加权基序保守、SEEKR。
   - 不能用 RBPNet 预测当验证标签（循环论证）。
   - 门槛：模拟基准 5% FDR 下检出率 +20 个百分点；真实数据恢复未参与调参的已验证元件，且不能只靠 CHASERR。
   - 没有独立功能正例时，只能说「统计上保守的结合潜力」。

## 三个开放问题与最便宜的实验（约两周预研）
1. **系综推断受限于算法还是信息量？**（3–5 天）
   - 做法：真实读段混合 + 降采样，比较 oracle 似然（已知状态谱）、EM、贝叶斯混合、SEISMIC-RNA。
   - 读法：oracle 好、现有方法差 → 做 SBI；两者都差 → 数据本身不可辨识，改做不确定性；EM 接近 oracle → 不值得做复杂模型。
2. **定位的细胞依赖变化是真信号吗？**（2–4 天，只用 CPU）
   - 做法：lncATLAS + ENCODE 重复，方差分解为基因 / 细胞 / 交互 / 重复噪声；比较 gene mean、加性模型、RBP 条件双线性 ridge。
   - 读法：交互可重复且 RBP 有增益 → 启动，甚至升为第 1；交互真实但 RBP 无用 → 换剪接、染色质等其他上下文；主要是噪声 → 暂停。
3. **功能基序保守能否区分真直系同源与进化匹配的随机背景？**（4–6 天）
   - 做法：PWM 或 RBPNet 生成结合谱，对照组成匹配和系统发育模拟；不训练新模型。

## 不值得做（更新）
- 从零训练通用 RNA / lncRNA LM；
- 随机划分二级结构；
- 单序列 ab initio 3D；
- 序列-only 二元定位；
- 序列-only lncRNA 半衰期；
- 普通 miRNA 二元靶标；
- 基于修饰调用结果的普通分类器；
- 基于 embedding 的 lncRNA GO 功能分类。

## 结论
- 只立一个方法项目，首选稀疏、有噪声化学探测下的 RNA 构象系综推断。
- 想尽快出论文，先做定位预研。
- 追求长期原创，选功能基序 turnover，但立项前要确认有独立的功能验证数据。
- 共同原则：先证明数据中有可学习、可泛化、有生物学意义的信号，再决定要不要深度学习。
