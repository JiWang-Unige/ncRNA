## 最终前 3
1. **D / E 融合：跨未见细胞系的定位偏移分解**（7–10 天）。
   - 数据：lncATLAS RCI + ENCODE 表达、剪接效率、RBP 表达；严格留一细胞系。
   - 指标：去主效应后的交互残差 R²，并同时报告整体 R²。
   - Go：交互模型解释度比最优加性基线高 ΔR² ≥ 0.05，置换检验 p < 0.01，且能指认稳定的 RBP / 剪接交互特征。
   - No-Go：ΔR² < 0.02，或依赖单个离群细胞系。
   - 基线：基因均值 + 细胞系偏移的加性模型；只用 RBP 主效应的 Ridge / Lasso。
2. **B：跨区室 Δ 反应性（只用非插补值）**（10–14 天）。
   - 数据：GSE117840，按染色体或转录本分块交叉验证。
   - Go：比零变化和序列 / 折叠自由能差基线的相关系数高 ≥ 0.08，且转录本留出时稳健。
   - No-Go：可评估位点太少，或优势只来自深度 / 表达泄漏。
3. **A 聚焦子问题：系综不确定性校准与可辨识性诊断**（12–15 天）。
   - 做法：用 SEISMIC 模拟器生成已知双 / 三态系综，加少量真实高深度数据。
   - Go：能区分「统计不确定（加深可收敛）」与「不可辨识（加深也不行）」，90% 区间覆盖率在 85–95%。
   - 基线：SEISMIC 默认 EM + bootstrap / 似然比区间。

**淘汰**：
- 序列预测 lncRNA 半衰期；
- 不严格遮蔽 PCG 的泛泛深同源；
- 回到 E1、IDENT、DNA-only 基因预测。

## 能否一区（Gemini）
光在公开数据上把 R² 或 AUC 提高几个点很难上一区。D / E 或 B 至少要满足以下四条中的三条：
- 严格剥离混杂，并在留一细胞系或外源 RBP 扰动数据上验证；
- 可解释的机制假设，并在公开扰动 / CLIP / 定位数据中找到一致证据链；
- 诚实报告失败边界；
- 可复现、轻量、即插即用的开源工具。
