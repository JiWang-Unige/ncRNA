# ChatGPT 第 3 轮（仓库与跨领域）：要点存档（非逐字原文）

> 页面抽取（约 2.9 万字符），思考 1 分 34 秒。仓库信息为 ChatGPT 自报，标「not visible」的它没看到。原对话同前。

## 总判断
| 方向 | 数学本质 | 最大瓶颈 | 判定 |
|---|---|---|---|
| A 构象系综推断 | 潜变量混合推断 / 反问题 | 可辨识性、噪声、低覆盖 | 保留，主项目候选 |
| B 条件化反应性 | 条件谱预测 / 差异信号 | 跨环境可重复性、缺失值、实验混杂 | 保留，**最先做预研** |
| C 深同源 | 远程同源搜索 / 进化推断 | 真值、同线性泄漏、功能趋同 | 保留，但重构（并入基序 turnover） |
| D 定位变化 | 冷启动矩阵补全 / G × E 交互 | 独立细胞环境太少 | 有条件保留，降为次级 |

## A 构象系综推断
- 仓库：
  - SEISMIC-RNA：v0.26.0，2026-08-27，GPL-3.0，首选基线；需要 Python 3.13，CLI 有大量破坏性变更。
  - DRACO：GPL-3；Clang ≥ 19 与旧 dlib 冲突。
  - DANCE-MaPper：MIT；依赖 Python 2.7。
  - sm-PORE-cupine：GPL-3，v0.1.0；需要 HPC。
- **新意受压**：SEISMIC-RNA 2026 版已支持导入 RNA Framework / DRACO、按化学试剂的模拟与过滤、突变碰撞偏差校正、自动发现异质区域、基于 bridge pairs 的 FDR、结构域独立性检验、多次 EM 初始化和模拟数据生成。所以「模拟 → 训练网络 → 胜过 DREEM」已经不够新。
- DeCoRE（Sci Adv 2026，PMID 42826179，DOI 10.1126/sciadv.aef0670）用 UMAP + GMM / DBSCAN，有时要人工指定簇数。说明自动模型选择和校准的不确定性仍有空间。
- 基准数据：DRACO 模拟的 1/2/3 构象、7SK DMS-MaP + NMR（PRJNA1004643）、sm-PORE-cupine RNA004（GSE304703）与 SHAPE-MaP（GSE309111）、2026 msDMS-MaP（GSE285333，PMID 42019497，增加 N7-G 信号，用于 7SK snRNP 异构体）。
  - 可提出的问题：新增一种探测信号能把可辨识性提高多少？
- 跨领域：
  - cryoDRGN（冷冻电镜构象异质性，Nat Methods 2021，DOI 10.1038/s41592-020-01049-4）：编码器 + 显式观测模型；要换成带掩码的 Bernoulli 似然。风险是单条读段信息量极少。
  - ADMIXTURE（Genome Res 2009，DOI 10.1101/gr.094052.109）：借它的似然优化、模型选择和 bootstrap；进一步做多条件联合混合（共享状态谱，各条件状态比例不同）。
- 最便宜实验（3–5 天）：用真实单状态富集样品构造读段级伪混合，比较 oracle 似然、EM、SEISMIC-RNA、贝叶斯混合。
  - SEISMIC 接近 oracle → 放弃复杂网络；oracle 也做不到 → 改做检测限、不确定性和弃权。
- **创新点改为：可辨识性、校准、多条件联合推断，不再是聚类精度。**

## B 条件化反应性（本轮最看好的新增方向）
- 数据与仓库：
  - GSE117840 / RNA_Structure_Dynamics：HEK293 和小鼠 ES 的染色质 / 核质 / 胞质 icSHAPE。生物学最近的工作是 Sun et al., NSMB 2019，DOI 10.1038/s41594-019-0200-7。
  - icSHAPE-pipe v2.0.1；StructureImpute（非商业）；PrismNet（许可证说明前后矛盾）；RASP v2.0。
- **泄漏警告**：RASP v2.0 用 HEK293 全细胞 / 体外 / 区室 icSHAPE 训练过 StructureImpute 元模型，还插补了 59 个数据集。用它的权重或插补值都会造成污染，必须只用实验观测值并保留缺失掩码。
- 目标是 Δr（同一核苷酸在两个环境之间的变化），不是绝对反应性。区室结构差异本身已不新，新在跨转录本、跨条件的定量差异预测。
- 跨领域：
  - BPNet（Nat Genet 2021，DOI 10.1038/s41588-021-00782-6）：共享编码器 + 各条件残差输出头，损失同时约束绝对值和差异；
  - scGen（Nat Methods 2019）：r_target = r_ref + Δr 的残差思路，但要保留核苷酸坐标。

  风险：RBP 结合、修饰、异构体组成都会改变反应性，但不一定改变二级结构。
- 最便宜实验（2–4 天）：同一 RNA 在两个区室都有测量的区域，比较重复间变异与区室间差异。
  - 基线：不变、均值偏移、ridge / LightGBM、小型条件 CNN；评价按基因留出。
  - Go：重复支持真实变化，差异 Pearson ≥ 0.30，比最强简单基线高 0.05。
  - 参考谱已接近实验重复上限时停。
- 风险：几百万个核苷酸标签不等于几百万个独立条件。

## C 深同源 → 并入基序 turnover
- 仓库：
  - lncHOME（Zenodo）；
  - lncrna_PutOrtho（13 物种工作流，MIT，有测试数据，依赖 Ensembl API）；
  - LncLOOM（MPL-2.0，v1 是 Python 2，需用 v2）；
  - RBPNet（MIT；3 个 open issue：#9 Python 版本安装问题，#8 缺 TARDBP 模型，#7 自训模型的相关性偏低）。
- **lncHOME 已经做了大部分初始构想**：同线性 + RBP 结合位点保守 + Cas12a 敲除 / 跨物种救援，筛出 75 个影响增殖的 coPARSE-lncRNA（DOI 10.1038/s41588-023-01620-7）。用 RNA-FM / RBPNet 替换其表示不足以构成方法贡献。
  - 真正的问题是：**去掉邻近 PCG 信息后，RNA 本身还有多少进化证据？**
- 13 物种集是计算推断的同源关系（严格标准下每物种约 200 个，宽松下约 5,000 个），不是实验真值。评价分三层：银标准、功能验证集、困难诱饵（按 TE / 长度 / GC / 剪接 / 基因组上下文匹配）。
- 跨领域：
  - 蛋白远程同源（嵌入局部比对 eLife 2024、PLMSearch Nat Commun 2024，以及 Genome Biol 2026 的远程同源基准——现有方法在内在无序蛋白上普遍失败，这是更贴切的类比）；
  - **TF 结合位点 turnover 的系统发育模型**（CRETO，GBE 2009，PMID 20333180）：比较中性 turnover 与「选择维持结合潜能」两个假设。
  - 风险：选择可能作用在 DNA 增强子或转录本身，而不是 RNA 分子。
- 最便宜实验（4–6 天）：
  - 设置：人–鼠 / 人–鸡 / 人–斑马鱼三个距离层；三种设定（位点内检索、遮蔽锚点的全基因组检索、只用锚点的上界对照）。
  - 不训练模型，先比 BLASTn、k-mer、LncLOOM、RBP 基序谱比对、冻结 RNA LM 局部嵌入。
  - Go：遮蔽锚点的全基因组检索 MRR 比最强纯序列基线高 0.05，且在功能验证集上一致。

## D 定位变化 → 降为低成本预研
- 仓库与数据：
  - lncATLAS：4 个 open issue，含 #8 Docker 构建失败、#7 下载后 biotype 列会变；建议直接用原始表。
  - lncLocator 2.0；
  - RNAlight（k-mer + LightGBM，GPLv3 + 研究用途条款，适合改成回归基线，DOI 10.1093/bib/bbac509）；
  - ENCODE 分级数据；
  - Tani 2026（代码要向作者索取；文中列出 ENCODE 分级文件编号，可廉价复现）。
- 跨领域：
  - 归纳矩阵补全（IMCHGAN，TCBB 2021）：这是双侧冷启动，必须用可独立获得的细胞协变量，不能只学细胞 ID 嵌入；
  - **作物育种的基因型 × 环境反应规范模型**（Jarquín 2014，PMID 24337101）：K_interaction = K_RNA ⊗ K_cell，用高斯过程或核岭回归，天然带方差分解和不确定性，适合环境数少的情形。
  - 风险：细胞谱系、癌症状态和批次可能同时影响 RBP 表达和定位。
- 最便宜实验（1–3 天，只用 CPU）：比较 gene mean、加性 ridge、双线性 ridge、反应规范核模型。
  - Go：留出细胞系的基因内变化 Pearson ≥ 0.30；打乱 RBP 后性能下降；不是由单个细胞系驱动。
  - 按细胞系层级做不确定性分析。

## 最终排序与整合
- 排序：**A > B > C > D**（研究价值）。执行顺序是 D、B 先做，因为验证更便宜。
- 主观评分（新意 / 可行性 / 影响 / 真值质量）：A 4.5 / 4.0 / 5.0 / 4.0；B 4.5 / 4.5 / 4.5 / 3.5；C 5.0 / 3.0 / 5.0 / 2.5；D 3.5 / 5.0 / 4.0 / 2.5。
- **A + B 的数学联系**：群体反应性 r̄_{i,c} = Σ_k π_{k,c} r_{i,k}。区室间的反应性差异，部分可能来自系综组成的变化。
  - 长期方向：从异质探测观测中推断依赖环境的构象系综。
  - 但群体 icSHAPE 通常不足以唯一反推系综权重。顺序应是：先用 A 建立单分子推断，再用 B 检验环境依赖变化的统计规律，有匹配的多条件单分子数据时才验证统一模型。
- 只长期投入一个：A。若 B 的预研信号强，B 可升为主项目，A 作后续机制研究。
- 不训练大型 RNA LM；现有公开代码和数据足以完成第一轮判死实验。
