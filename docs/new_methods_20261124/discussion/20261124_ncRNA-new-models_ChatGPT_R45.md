## 结论：最终排序变为 B > A > C > D

## 对我们过去十个月的评价
- **三种反复出现的失败模式**：
  - 复杂模型学到的是简单代理（CpG 规则达到模型 S50 的 70–82%）；
  - 评价目标不等于生物学目标（AUTH 的区段真实性迁移不到 E1 的分子配对）；
  - 新算法解决的困难在真实数据里不占主导（IDENT 的 449 个诊断全是单观测）。
- 「不缺模型创新，缺的是这些技术解决的困难成为现实瓶颈」。下一次立项的第一道门槛应是：**真实数据上存在足够多、现有方法确实解决不了、而新模型有望解决的实例**。不能先做完精巧算法再找应用。
- **数字口径更正**：
  - AUTH precision 0.488 排除了 uncertain；含全部预测时 strict precision 只有 0.157。H1 是 0.327（strict 0.134）。
  - E1 冻结的 E2 是五特征组内排序基线，「最强端点」是后续检查。
  - IDENT 的 0.22% 是 2,245 次「观测–目标」试验中出现 5 次，不是新增读段的 0.22%。
  - GENERanno 主干在人类全基因组 CDS 上监督训练过，所以以前的「留出染色体」只对头部和语法严格成立。
- **最值得保留的**是预注册、强基线、独立验证、失败即停的流程。下次要把这套流程提前到模型开发之前。

## 结合我们的结果重估 A–D
- **A（构象系综）：小幅削弱，仍值得做。**
  - IDENT 的教训是不要把数学上的不可辨识自动当作有应用价值的问题；A 也可能退化成「容易的现有 EM 已解决、困难的信息不足、中间可改进区间很小」。
  - **新发现竞品 MERGE-RNA**（NAR 2026-10，PMID 42770328，DOI 10.1093/nar/gkag917）：物理观测模型 + 最大熵系综精修 + 多实验联合拟合 + 可迁移参数，已用群体探测谱恢复腺嘌呤核糖开关的配体依赖构象转变。这削弱了「物理约束系综建模 / 多条件推断」的新意。
  - 剩下的问题：**控制热力学先验后，单分子读段的突变共现究竟比群体谱多提供多少信息？**
- **B（条件化反应性）：明显加强，升为第 1。**
  - 与 DNA-only 失败的教训一致（序列内在信息 ≠ 细胞环境信息），而且有核苷酸分辨率的实验观测。
  - 数据核实（Sun et al. NSMB 2019，PMID 30886404，GSE117840）：HEK293 与小鼠 ES 的染色质 / 核质 / 胞质，每个区室 2 个 DMSO + 2 个 NAI-N₃ 重复，每个约 2 亿读段。组合得到的四套反应性共享文库，不是四个独立生物学重复。
  - 必须纳入的竞品：dStruct（DOI 10.1186/s13059-019-1641-3）、diffBUM-HMM（10.1186/s13059-021-02379-y）、2022 差异结构分析（10.1038/s41467-022-31875-3）、StructureImpute、PrismNet。它们都需要目标环境的测量；**我们的问题是目标区室没有测量时，能否预测差异反应性**，这足以构成潜在的方法创新。
- **C（深同源）：生物学动机加强，方法可行性没有加强。**
  - 仓库 RESULT_S4：UCSC 全基因组比对链在鸡、斑马鱼测试染色体上的覆盖率只有 11.1% / 2.8%，命中真值的预测可映射比例仅 2–5% / 0–2%。说明核苷酸比对对远缘 lncRNA 确实受限，但不能证明 RNA LM / RBP 谱能恢复丢失的进化信息。
  - 「功能相似」不等于「共同起源」（与 E1 的「找到区域 ≠ 找到配对」同构）。组织表达保守可以作独立表型，但不能当直系同源真值。
  - lncHOME 的「75」是 CRISPR 筛选中影响增殖的 coPARSE-lncRNA 数，不是 75 个都做了跨物种救援。
  - 重新定义为「RNA 内在特征检索 + 功能保守」，不宣称深度直系同源发现。
- **D（定位变化）：明显削弱，不作主项目。**
  - 我们的 ΔR² 0.13 / 0.11 / 迁移 0.098 支持的是基因内在定位 μ_g 可预测，没有给出 gene × cell 交互 δ_{g,c} 的可预测性。
  - 56–62% 剪接效率缺失，完整病例分析会偏向高表达的 lncRNA。
  - **新竞品**：
    - Tani 2026（Mol Genet Genomics，PMID 42645529，DOI 10.1007/s00438-026-02510-3）：lncRNA 定位是异构体层面的性质，被基因层面平均掩盖；98 个合格基因中 21 个（最严格 8/54）有被掩盖的差异。所以基因层面的「定位变化」可能只是异构体比例变化。
    - Tani 2026-11 已发表「半衰期 × 定位」框架（观点文章，PMID 42982678）。

    **反对把 D 和半衰期合并。**
  - 最多再做一次 2 天的交互信号审计（方差分解 + 反应规范核），不行就不再换架构挽救。

## 最终前 3 与第一个判死实验（门槛是建议值，需在预注册前确认可实施）
**1. B：预测依赖环境的 RNA 反应性变化（3–5 天，GPU 不超过约 12 小时）**
- 数据：GSE117840 HEK293 icSHAPE（主），RASP v2.0、小鼠 ES 区室数据（辅）。
- 任务：主任务核质 → 胞质；次任务染色质 → 核质、体外 → 体内。
- 标签：两个条件都实际观测到的反应性，Δr = r_target − r_ref。按基因 / 位点留出，排除局部同源和重复序列。
- 两个子任务分开：B0-S（序列 + 目标区室身份）；B0-E（序列 + 参考区室的实测反应性 + 目标区室身份），后者更可能成功。
- 基线：
  - 零变化；
  - 区室均值偏移；
  - 只用参考反应性回归（防止把均值回归当规律）；
  - LightGBM（参考反应性、局部 k-mer、GC、配对概率、转录本结构、合法协变量）；
  - 小型 1D CNN（不用 RNA LM）。
- 防伪信号：同一个带噪参考值同时出现在输入和差值标签里时，模型会学到技术噪声。尽量用独立参考重复构造输入和评价目标。dStruct / diffBUM-HMM 只用于定义高可信差异区和测量上限。
- 门槛：
  - G0：≥ 300 个合格 lncRNA 基因、≥ 30,000 个共同观测核苷酸；不足就转为通用 RNA 方法，单独评 ncRNA 子集，不能用 mRNA 掩盖；
  - G1：独立重复构造的差异谱之间 Pearson ≥ 0.40，否则停；
  - G2：留出基因上差异 Pearson ≥ 0.30 且 ΔR² > 0；
  - G3：比最强简单基线 +0.05，基因块 bootstrap CI 下限 > 0；
  - G4：至少一个独立数据集或区室转换上方向一致。
- 通过后要做的是「带校准预测不确定性的条件化反应性残差模型」，不是 RNA BERT。

**2. A：量化并利用单分子信息（4–6 天，以 CPU 为主，不训练网络）**
- 三层 oracle 差距基准：
  - 数据：DREEM 实验混合、DANCE-MaP 腺嘌呤核糖开关、7SK；外部测试 GSE309111、GSE285333；
  - 网格：深度 500 / 1,000 / 2,000 / 5,000；次要状态比例 5 / 10 / 20 / 50%。
- 基线：已知谱的群体似然、已知谱的读段级似然、多次初始化 Bernoulli EM、贝叶斯混合、SEISMIC-RNA，以及可比任务上的 MERGE-RNA。
- 三个条件必须同时满足：
  - 至少 3 个独立 RNA 体系有实验混合比例或其他独立结构证据；
  - **≥ 25% 的低覆盖条件存在可利用的 oracle 差距**（读段级 oracle 的比例 MAE ≤ 0.05，而最强现有方法 ≥ 0.10）；
  - 差距不由单个家族或特定模拟方案独占。
- 读法：群体似然 ≈ 读段级似然 → 研究群体模型；EM 接近 oracle → 不做摊销模型；oracle 也失败 → 只能谈实验设计价值。

**3. C：带进化校准的 RNA 内在检索（5–7 天，GPU 不超过约 24 小时）**
- 正例：13 物种严格子集；功能验证：lncHOME 中有独立实验支持的；层级：人–鼠 / 鸡 / 斑马鱼。
- 主任务：遮蔽锚点的全基因组检索；次任务：同线性区内排序。评价 MRR、Recall@10、经验诱饵 FDR。
- 基线：BLASTn / 局部比对、k-mer、TE 组成、剪接结构、LncLOOM 式基序分、简单 RBP 基序谱比对；冻结 RNA LM 只做局部相似度，不先训练对比网络。
- 门槛：
  - G0：≥ 2 个距离层，各 ≥ 100 个独立银标准查询，且功能验证集可单独评价（先做功效评估）；
  - G1：控制长度、GC、TE 后仍显著高于诱饵；
  - G2：MRR +0.05，同源组块 bootstrap CI 下限 > 0；
  - G3：更远缘层级也成立；
  - G4：未参与调参的功能验证集上一致改善。

## 能否达到 JCR 一区
**可以，但目前没有任何方向已显示足够证据。**有潜力的问题我们一直都有，缺的是被证明有效的新方法。
- **B**：需要严格的差异反应性基准；留出 RNA 上显著超过「只用参考」和序列基线；至少一个独立数据集外部验证；对已知 RBP 相关结构变化或其他独立实验现象有解释力。
  - 可能的核心主张：「细胞环境使 RNA 反应性变化可以在内在序列和参考结构之外被迁移预测」。
  - 目标 NAR、Bioinformatics；有转录组尺度的生物学发现才考虑 Genome Biology。
- **A**：要发现一个真实且广泛存在、现有方法丢失了可提取信息的区间，并给出校准的不确定性、更低检测限或更可靠的状态恢复。这是最具纯计算方法论文潜力的。
- **C**：要回答「是否只是复现 lncHOME」「是否学到的是长度、GC、TE 或基序趋同」「没有湿实验如何证明生物学意义」。能用现有救援或扰动数据回答，才有 Genome Research / Genome Biology 的可能。
- **D**：当前证据不足，不建议投高档期刊。
