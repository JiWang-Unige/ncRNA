# What we have tried since 2026-11-23 (addendum to the earlier attempts summary)

Repository (code, frozen protocols and results, mostly in Chinese): https://github.com/JiWang-Unige/ncRNA. Earlier history (Jan–Nov 2026, DNA-only lncRNA gene finding with genomic LMs, HMM/CRF grammars, AlphaGenome/CpG baselines, sparse endpoint evidence) is summarised in `ATTEMPTS_SUMMARY_EN.md` in the deep-research folder: the main lesson was that DNA-only priors add nothing over evidence rules and that endpoints and splicing are both bottlenecks.

All tests below used pre-registered gates frozen before reading results.

1. AUTH — authenticity of cheap endpoint evidence (WTC11 CAGE starts + QuantSeq ends -> candidate transcripts): an 18-feature L2 logistic model raised precision from 0.182 (rule) / 0.300 to 0.488 at recall 0.330; transferred to H1 with FANTOM5-style CAGE (0.327 vs 0.149 / 0.201). IsoQuant on full long reads is still better. A short analysis paper is ready as a fallback.
2. E1 — pairing TSS and TES ends of the same molecule from separately measured ends: STOP. Every model including AUTH was no better than "take the strongest end" (0.705); AUTH learns region detectability, not end pairing. Method rankings reversed between span-matching and molecule-level evaluation.
3. IDENT — evidence-constrained transcript identifiability with counterexample-guided sufficient-observation diagnosis (MILP + independent exhaustive oracle; 617 synthetic instances, 0 failures). On real WTC11 PacBio (chr16/chr22 dev set) it was STOPPED before the frozen test: with open transcript ends, 59% of candidate intron chains are nested in longer ones; a parsimony bound (delta=1) gave exactly the same states as no bound; all 449 diagnoses needed a single observation (the global multi-observation cover never activated); diagnostic observations appeared in only 0.22% of added reads; same-library quantitative constraints added only 6 non-parsimony identifications. We also found the ENCODE "filtered" WTC11 alignments are TranscriptClean-corrected against GENCODE v29 (98% of junctions annotated).
4. RNA fate / localisation (K562, HepG2, ENCODE nuclear/cytoplasmic fractionation, ~715 / 629 lncRNAs): after confounders (expression, length, exon count, splicing efficiency, intron retention, promoter type...), sequence features (mostly low-order k-mer composition) still add Delta R^2 = 0.128 (K562) and 0.108 (HepG2), 0.098 for K562->HepG2 transfer. Caveat: splicing efficiency is missing for 56–62% of multi-exon lncRNAs. This is the same class of result as Tani 2026 (RBP occupancy, Delta R^2 0.12), so judged not novel enough as a static-localisation paper.
5. Cheap checks of two other directions: (a) using published lncRNA functional-screen hits to evaluate annotation — narrow (CASPR 2020 already links TSS annotation quality to hits; the largest Cas13 screen was retracted for off-targets); (b) layered annotation benchmark on 57 public LRGASP submissions — method rankings do reverse between reference-match and CAGE/polyA-support layers (choosing by the usual metric loses end support for ~370–520 lncRNA loci on PacBio), but the effect is not lncRNA-specific and LRGASP already reported it qualitatively.
6. Small structured ncRNA tools (tRNA/Rfam): tRNA is essentially solved; Rfam-family labels too few for a new learned detector; side line closed.

Resources: one shared RTX 4090 24 GB (plus occasional 3090), 32-core server, small cloud budgets; public data only; no wet lab.
Goal: a genuinely new model or method for studying ncRNA, aiming at a JCR Q1 journal (e.g. Genome Biology, NAR, Bioinformatics, Genome Research).
