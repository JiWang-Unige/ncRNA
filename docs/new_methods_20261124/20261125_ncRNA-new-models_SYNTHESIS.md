## 1. 一句话结论

两家一致认为：**不该再训练通用 RNA 基础模型，也不该在随机划分上刷分；该改变问题本身——预测「同一条 RNA 在不同细胞环境下的变化」，并把实验测量当作有噪声的观测来建模。**
- 最稳的共识首选是 **B：预测 RNA 在细胞区室间的结构反应性变化**（两家都排在前 2）。
- 分歧最大的是 **D：跨细胞系的 lncRNA 定位变化**（Gemini 第 1，ChatGPT 第 4）。它可以用一个 2 天的低成本审计判定。

## 2. 最终排序

|---|---|---|---|---|

**淘汰**（两家一致或证据明确）：
- 从零训练通用 RNA / lncRNA 语言模型；
- 随机划分的二级结构预测、单序列 3D 预测；
- 序列-only lncRNA 半衰期（PMID 42760417），以及定位 + 半衰期联合（Tani 2026-11 已发表框架，PMID 42982678）；
- 结构化小 RNA 致病变异预测（Gnocchi 是 1 kb 窗口，真值少）；
- 通用 RNA–RNA 潜变量互作模型；
- 抗泄漏基准作主线；
- 序列-only 二元定位、二元 miRNA 靶标；
- 回到 DNA-only 基因预测、E1、IDENT。

## 3. ChatGPT 对我们十个月工作的总评（值得记住）

- 三种反复出现的失败模式：
  - 复杂模型学到的是简单代理；
  - 评价目标 ≠ 生物学目标；
  - 新算法解决的困难在真实数据里不占主导。
- **下一次立项的第一道门槛**：先证明真实数据中存在足够多、现有方法解决不了、新模型有望解决的实例，再开发模型。
- 最该保留的是预注册、强基线、独立验证、失败即停的流程，要把它提前到模型开发之前。
- 数字口径更正：
  - AUTH 的 0.488 排除了 uncertain，全部预测时 strict precision 为 0.157；
  - IDENT 的 0.22% 是 2,245 次试验中出现 5 次；
  - GENERanno 主干在全基因组 CDS 上监督训练过。

## 4. 建议的两周预研（都不训练大模型）

### B0：区室间反应性变化是否真实、可预测（3–5 天，GPU ≤ 12 小时）
- 数据：GSE117840（Sun et al., NSMB 2019，PMID 30886404），HEK293 染色质 / 核质 / 胞质 icSHAPE，每区室 2 个 DMSO + 2 个 NAI-N₃。只用实测值，**不用 RASP / StructureImpute 的插补值或权重**（它们在这些数据上训练过）。
- 任务：主任务核质 → 胞质；分 B0-S（序列 + 目标区室）和 B0-E（加参考区室实测值）两个子任务。按基因 / 位点留出。
- 基线：零变化、区室均值偏移、只用参考值回归、LightGBM、小型 1D CNN。用独立参考重复构造输入和评价目标，避免模型学到参考值里的噪声。
- 门槛（两家方案综合，需在冻结前确认可实施）：
  - G0：≥ 300 个合格 lncRNA 基因、≥ 30,000 个共同观测核苷酸；否则转为通用 RNA 方法，单独报告 ncRNA 子集。
  - G1：独立重复构造的差异谱 Pearson ≥ 0.40（信号真实）。
  - G2：留出基因上差异 Pearson ≥ 0.30。
  - G3：比最强简单基线 +0.05，基因块 bootstrap CI 下限 > 0。
- 下载：GSE117840 处理后数据（大小待查），需作者批准。

### D0：定位交互信号审计（2 天，只用 CPU）
- 数据：lncATLAS 连续 RCI（15 个细胞系，非完整矩阵），加 ENCODE 细胞系表达 / RBP / 剪接协变量。复用 `13_RNA_fate/` 的管线。
- 做法：方差分解 y = μ_g + α_c + δ_{g,c} + ε（重复噪声用 ENCODE 重复估计）；比较基因均值、加性 ridge、双线性 ridge、反应规范核（K_RNA ⊗ K_cell）。严格留一细胞系；打乱 RBP 谱作对照。
- Go：留出细胞系的基因内变化 Pearson ≥ 0.30（ChatGPT 标准），或交互 ΔR² ≥ 0.05 且置换 p < 0.01（Gemini 标准）；不能由单个细胞系驱动。
- No-Go（交互 ΔR² < 0.02，或主要是重复噪声）：D 永久关闭，不再换架构挽救。
- 附带检查：异构体组成是否解释基因层面的定位变化。
- 下载：lncATLAS 表格（MB 级），需作者批准。

### A0（备选，B0 不过时做）：oracle 差距审计（4–6 天，CPU）
- 用 DREEM 实验混合、DANCE-MaP 腺嘌呤核糖开关、7SK，外部数据 GSE309111 / GSE285333。比较已知谱的群体似然、读段级似然、EM、贝叶斯混合、SEISMIC-RNA、MERGE-RNA。
- 门槛：≥ 3 个独立 RNA 体系；≥ 25% 的低覆盖条件存在可利用差距（读段级 oracle 比例 MAE ≤ 0.05，而最强现有方法 ≥ 0.10）。

## 5. 能否达到 JCR 一区（两家一致）
- **能，但目前没有任何方向已经显示出足够证据。**光在公开数据上把相关系数提高几个点不够。
- 至少还需要：
  - 严格的混杂剥离；
  - 独立数据集或外部扰动数据上的验证；
  - 可解释的机制（例如哪些 RBP / 基序驱动了结构或定位变化）；
  - 诚实报告失败边界；
  - 可复现的开源工具。
- B 的可能主张：「细胞环境使 RNA 反应性变化可以在内在序列和参考结构之外被迁移预测」，目标 NAR / Bioinformatics，有转录组尺度的生物学发现再考虑 Genome Biology。
